# 性能记录与后台任务

[返回项目入口](../README.md) · [使用指南](使用指南.md) · [开发指南](开发指南.md)

本批交付后台任务、拾取缓存和可观察性基础，没有运行性能测试或承诺帧率。请使用实际图纸按同一环境、视图和操作记录结果，再决定静态 GPU 缓冲、更多几何缓存及索引的优先级。

## 操作与状态

打开 DXF/DWG/项目时，当前工作先保留，底部显示读取、离散、采样、分析和轨迹阶段。候选准备完成后才处理未保存确认并安装。无单位图纸在主线程询问毫米/英寸，确认后交给后台继续。新建空图纸和关闭也会使旧任务失效。

CAD 编辑仍先提交正式图纸并更新显示，加工采样、拓扑/分析和轨迹在后台跟进。可以继续编辑；新请求替代尚未开始的旧请求，已运行结果只有在会话、图纸 revision、几何/属性、配置、安排和范围版本全部匹配时才能应用。修改或撤销后，即使文档 revision 回到旧值，会话版本也能拒绝旧结果。工件及 CAM 坐标和算法未改为显示坐标。

底部状态栏提供“取消后台任务”“重算当前加工”和“性能记录”。取消立即撤销本次结果/后续动作的应用资格；后台在当前阶段结束时检查退出，不能强行中断第三方解析器或单次计算内部循环。状态会说明仍在退出阶段；后续只保留最新一个等待任务，单个工作线程不无限并发堆积快照。

加工源数据过期时，CAM 拾取/编辑和旧计划编号暂停，CAD 可继续编辑。配置输入变化使旧轨迹失效。普通导出、快速导出、校验及轨迹查看在需要时排队重算，完成后自动继续；输入改变、取消或任务失败会取消相应后续动作，不输出旧结果。导入遗漏确认、安排待处理和原有轨迹校验仍然有效。

项目保存若需要当前加工安排，会先等待其重算；保存成功后才继续先前的新建、关闭、退出或文件替换。取消保存对话框、保存失败或期间修改输入，都不继续破坏当前工作。加载完成时若还有未确认 CAD 命令，候选等待命令完成/取消；提交了新的正式输入则丢弃旧候选，不覆盖刚做的编辑。

## 拾取和画布

拾取投影缓存绑定会话、几何/属性版本、浮动原点、相机矩阵和逻辑视口。鼠标移动时复用投影，对 64 像素网格候选做原有线段距离/深度排序；重叠候选仍可 Tab 循环。单段跨格过多或总格引用达到预算时回退到全局候选检查，避免索引膨胀和漏选。新建/打开/编辑/改层可见性/相机变化都会使对应缓存失效。

框选复用缓存，窗口模式要求实体全部可见路径完整位于矩形内；交叉模式仍按实际线段相交判断。CAM 窗口按整个单元的可见成员判断。TEXT 可按投影框内部点选，字形显示仍属于近似字体渲染。

GUI 使用独立的全窗口相机，世界渲染视口使用侧栏、顶栏和底栏之外的画布，适应视图也使用该区域；逻辑尺寸经窗口缩放系数转为物理视口，并在窗口缩小时钳制到有效范围。侧栏宽度限制为窗口的一部分，底部命令栏和任务栏分别贴底布局。尚未执行多显示器/缩放比例的 GUI 验收。

## 如何记录

通过“视图 → 性能记录…”或底部按钮打开。面板记录用户操作，不自动打开样本或运行基准：

| 项目 | 实际含义 |
|---|---|
| 读取与转换 | 打开图纸/项目的候选读取总耗时；原始 DXF/DWG 另列解析读取、导入转换，单位确认后的解析单列 |
| 显示离散 / 编辑显示离散 | 初次后台离散或编辑后主线程显示更新 |
| 后台快照 | 在 UI 线程复制不可变输入的耗时，仍可能阻塞大图 |
| 加工采样、拓扑、加工分析、轨迹 | 各阶段 CPU 墙钟耗时；采样复用显示元数据，不再重复做显示离散 |
| 拾取投影与索引 / 拾取查询 | 缓存重建及最近一次候选查询；同时列出候选/总线段数 |
| 绘制 CPU 提交 | 主线程生成 Gizmo 数据的耗时，不是 GPU 时间或 FPS |
| 路径点容量 | 已应用的显示+加工点数组容量，单位 MiB；不是进程 RSS，不含原生文档、历史、索引、临时快照、字符串或 GPU |
| 丢弃次数 | 被取消或输入版本过期而未应用的结果/请求数，不代表计算错误 |

“复制当前记录”可将这些值复制为文字。每项显示最近一次记录，不是统计平均值或严格整次操作分解；取消阶段可能未完成全部记录。实际内存请同时用任务管理器记录进程工作集，不能把点容量当作总内存或稳定上界。

用户验收应记录图纸/配置、图元/点数、视图、窗口和 DPI、机器环境及相同操作。分别比较首次加载、静止鼠标拾取、相机移动后的缓存重建、批量编辑及撤销。检查结果正确性和版本衔接后，再评价响应时间与峰值内存；本批没有实际样本测量结果。

## 当前边界

核心编辑事务、编辑后的显示离散、CAD 诊断、文件保存/输出及恢复快照仍有同步工作；后台快照也需要复制内存。相机变化时投影索引重建、绘制及部分捕捉/标签仍遍历几何。没有静态 GPU 几何缓存、GPU 计时、进程内存自动测量、基准回归或任意障碍/机床仿真。后台任务只改变计算调度和结果应用，不替代 DXF/项目往返、NC 覆盖或实机验证。
