# CAD 交互改造计划

制定日期：2026-10-25。以 AutoCAD 2024 用户的常用操作习惯为参考，沿用现有 Rust / Bevy / egui 与原生 CAD 编辑事务。用户负责交互验收，开发过程负责完整应用构建；构建不替代交互验收。

当前进度：第一至六批的下列基础范围已实现，完整构建通过；动态输入、连续修改及实际交互由用户验收。椭圆/样条结构修改和复杂偏移拆圈仍不在本批范围。

## 第一批：功能区与工作区布局

- [x] 顶部“默认”功能区，包含绘图、修改、图层、特性、实用工具五组。
- [x] 使用统一线条图标和中文文字；高频项直接显示，其他项通过下拉菜单展开；窄窗口切换紧凑菜单。
- [x] 绘图包含直线、多段线、矩形、圆、圆弧、椭圆、样条；孔模板保留入口。
- [x] 修改包含移动、复制、旋转、镜像、缩放、删除、偏移、修剪、延伸、圆角、倒角及阵列。
- [x] 图层下拉显示颜色与状态，选中对象时可修改所属图层；无选择时切换当前图层。提供图层管理入口。
- [x] 特性支持颜色快捷修改与详细特性面板；无选择时设置新图元颜色，多选时显示混合值。
- [x] 实用工具集中提供距离、角度、坐标及所选曲线长度；注释与块专用面板暂缓，保留已有入口。
- [x] CAD 详细设置改为右侧可收起面板，区分特性、图层、工具；CAM 保留原有布局。
- [x] 命令提示固定在底部，历史可展开；捕捉、栅格、正交、极轴与工作平面集中到状态栏。
- [x] 画布视口、拾取、文字裁剪、视图立方体随面板变化同步，面板操作不穿透画布。

第一批边界：修剪/延伸仍为既有参数方式，圆角/倒角仍要求端点相接直线，功能区选择这些工具会打开参数面板，设置并预览后才提交。动态输入、命令确认及选择习惯已分别由第二、三批实现。快捷颜色提供随层、随块与常用 RGB，任意 RGB/ACI 在详细特性中设置。

## 第二批：动态输入

- [x] 画布直接键入命令，光标旁显示输入与命令候选，支持常用命令别名。
- [x] 根据命令阶段显示坐标或长度、角度、半径字段。
- [x] Tab 切换字段，已输入值可锁定；不输入时跟随鼠标与捕捉点更新。
- [x] 鼠标旁与底部共用命令状态和输入，切换焦点不丢失内容；底部提供完整提示与错误原因。
- [x] 首点默认绝对坐标，动态输入后续点默认相对坐标；支持 # 绝对、@ 相对与距离<角度；底部直接输入坐标仍默认绝对。
- [x] F12 和状态栏开关控制动态输入；浮层靠近边缘自动避让。
- [x] 处理 Tab 与捕捉候选循环的优先级，保护文字编辑与复制粘贴快捷键。

第二批边界：动态字段包括 WCS X/Y/Z、工作平面长度/角度、圆半径、旋转角度和缩放比例；其他命令参数继续使用工具页。切换“坐标/长度角度”会清除当前尺寸锁定，按钮有提示；F12 或切换输入位置保留文字及绝对/相对坐标含义。画布不足 340×260 逻辑像素或无法避让光标时回到底部输入。本批仅处理动态输入；确认次数、Esc 与选择语义由第三批统一。

第二批交付：上一批提交为 `f2d89e2`；本批复用同一输入草稿、命令步骤、取点约束和原生事务。仅完成构建与静态检查，未运行 GUI 或功能测试。

## 第三批：命令操作习惯

- [x] 同时支持先选对象和先启动命令两种方式。
- [x] 移动/复制最终目标点、圆/矩形最终必要点确认后完成，减少多余回车。
- [x] 直线/多段线连续绘制，U 撤回、C 闭合、回车结束；Esc 保留已确认部分。
- [x] 空闲 Enter/空格重复命令；Esc 按当前步骤取消；右键提供当前选项和确认。
- [x] 对齐追加选择、Shift 移除、窗口/交叉选择及撤销分组。
- [x] 中键平移、Shift+中键旋转，滚轮以鼠标位置为缩放中心。

第三批交付：上一批提交为 `7cb9055`。移动/复制/删除与常用变换支持先选或后选；圆、矩形、圆弧、椭圆、移动/复制、粘贴、夹点及测量在最终必要点确认后提交，旋转/缩放输入数值后确认即提交。文字仍保留工具页参数与最终确认。

连续直线、多段线和有效样条在结束时一次写入；U 撤回当前草稿末点，C/Enter/空格完成，Esc 保留已确认且能成形的部分；点数不足时取消。右键可显式“放弃整次未提交绘图”。整次绘制只占一条历史，尚未结束的草稿不会被自动恢复快照保存；切换 CAD/CAM 仍会放弃未结束草稿。曲线整理工具仍要求预选对象，其图形化流程留到第四批。

CAD 默认追加选择，Shift/Alt 移除、Ctrl 切换；CAM 保持原有 Shift 追加及 Ctrl 重排。Space 在命令输入框执行确认，其他文字控件保留空格；空格分隔坐标仍可整体粘贴后 Enter。UCS 支持先输入 UCS、再输入 XY/YZ/ZX/3P。只完成构建及静态检查，未执行 GUI 或功能测试。

## 第四批：常用工具图形交互

- [x] 修剪与延伸支持边界和目标点选，替代常用场景中的参数区间/固定长度输入。
- [x] 圆角/倒角支持半径或距离后依次选边并预览。
- [x] 偏移支持距离、对象和偏移侧点选。
- [x] 阵列通过画布预览与动态参数输入调整。
- [x] 夹点编辑显示尺寸并支持直接输入数值。

第四批交付：在 `9ff29e2` 之后开展。顶部/菜单/命令行的 TRIM、EXTEND、OFFSET、FILLET、CHAMFER 使用图形化流程；右侧“曲线整理（参数方式）”保留原有批量参数操作。第四批交付时每次处理一个目标或一对直线；第五批扩展了修剪/延伸/偏移的连续处理。悬停只预览，最终点击提交，一次撤销恢复本次点击。

修剪/延伸目标和边界覆盖直线、圆/圆弧及多段线，延伸限开放曲线；按真实交点和点选区间/端点决定结果，边界只用自身有效范围。圆角/倒角支持有唯一共面交点的两条直线，包括需要延长到交点的情况；点选保留侧，保留两条线各自属性和方向，连接边继承第一条线属性。图形化偏移保留原件，使用轮廓侧确定正负距离，继续沿用已有偏移失败检查。

矩形阵列动态输入为列数/行数，环形阵列为数量；间距拾取沿用工作平面 U/V，角度和其他参数在右侧设置。夹点动态输入显示位移/角度，圆与圆弧半径夹点显示实际半径并接受数值；固定目标的属性预览也能继续修改坐标或半径。字段、光标和底部仍共用草稿。

## 第五批：连续修改与命令内撤回

- [x] 修剪/延伸保留边界，偏移保留距离，提交一次后继续选择下一个目标。
- [x] 最终点击提交本次修改；等待目标时 Enter/Space 结束，Esc 丢弃当前预览并保留已完成结果。
- [x] U/空输入时 Ctrl+Z 只撤回本命令最近一次修改，核对原生事务 ID，不能撤销命令开始前的操作。
- [x] 边界被裁分/删除时跟随真实结果更新；撤回时恢复对应边界身份。
- [x] 失败目标不产生历史、不结束命令，可重新点选；偏移可在命令内用 D 修改距离。
- [x] 更新动态提示、右键菜单、使用指南与人工验收步骤，完成完整构建。

第五批在 `22b2446` 之后实施：TRIM/EXTEND/OFFSET 每次成功点击独立提交一条事务，保持命令活动；U 先核对原生栈顶事务 ID，再复用原有撤销与 CAD/CAM 上下文恢复，不会越过本命令历史。既有原生历史预算仍为 100 条，超出可用范围明确停止撤回，不合并为一条长期占用的文档事务。连续绘图的一次撤销语义不变。

等待目标时 Enter/Space 结束，而非提交悬停目标；最终点击仍提交当前修改。偏移的侧点阶段 Enter 确认当前侧点，N 丢弃当前预览并重选对象，D 更改距离；右键可随时结束并保留已完成结果。U 不回退工具尺寸，只撤回几何修改；命令内不提供重做，退出后可用原有全局重做。边界角色按裁分/删除和撤回更新，未选中的保留边界以蓝色提示，不修改图元实际颜色。

本批不扩展椭圆/样条或偏移几何内核，圆角/倒角仍为单次一对直线。仅确认完整构建和静态检查，GUI/保存往返由用户验收。

第六批在 `58fb06b` 之后实施。旋转默认以鼠标方向作为角度增量；R 的新方向则是绝对角度，以新旧之差旋转。参照缩放使用正长度比；镜像默认两点定轴，在独立末步 N/Enter 保留源对象、Y 原位反射。自定义轴及镜像平面仍在工具页，预览与提交共用矩阵参数并复用原生批量事务。仅完成完整构建及静态检查，实际交互和文件往返待用户验收。

## 实现与验收路径

输入入口（功能区、键盘、动态输入或底部命令行）→ 同一命令步骤 → 临时预览 → 原生编辑事务 → 显示与 CAM 同步。界面调整不新增独立几何副本或另一套编辑提交路径。

每批完成后更新复选框与实际边界，执行 `cargo build --workspace --offline`。交互验收由用户进行：

1. 宽/窄窗口与高 DPI 下，功能区图标、文字与下拉菜单可用，收起特性面板后画布扩展，CAD/CAM 切换布局正确。
2. 图层、颜色快捷修改支持单选、多选和混合值；锁定层、隐藏层限制沿用现有事务；撤销可恢复。
3. 鼠标旁输入画矩形、输入半径画圆、相对坐标复制；在两处输入间切换，提示和最终坐标一致。
4. 两种顺序启动移动、连续画线后取消、边界修剪、夹点输入；检查确认次数、Esc 与撤销行为。
5. 面板、菜单、命令行操作不触发底层选择/绘制；文字、拾取和视图操作限定在实际画布。

## 第二批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. 空闲画布输入 L、C、CO、RO、SC、DI，确认首字符不丢失、候选与别名正确；输入过程中 ↑↓、Tab、Enter 各自只处理一次。
2. XY 平面首点输入 #20,30,0；后续光标表达式 10,0 应解释为相对点 (30,30,0)，底部无前缀 10,0 应解释为绝对点 (10,0,0)。输入未提交时切换两处输入及 F12，确认 #/@ 和最终点含义保持。
3. 锁长度 100，移动鼠标检查角度仍更新；再 Tab 锁角度 30，检查预览与确认点一致。切到坐标模式后分别锁 X/Y/Z，验证未锁字段跟随鼠标；捕捉候选不能同时因 Tab 改变。
4. 圆半径输入 10，旋转角度 45、缩放比例 2，检查鼠标不动时编辑数值也更新预览；最终确认按第三批当前流程。
5. 悬停光标输入框或转到底部输入，检查未锁数值不归零；试验空字段、负长度、非法半径及清除锁定。编辑其他面板文字时输入、复制粘贴不触发 CAD 命令。
6. 画布四边、高 DPI、收起/展开面板与小窗口情况下，检查浮层换侧/底部回退、焦点和拾取互不穿透。

## 第三批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. 分别先选对象再 MOVE/CO/RO/SC/E，以及先执行命令再追加选择；Shift 移除、Ctrl+A 全选，确认选择后走完修改。锁定层或提交错误应整批失败并允许取消。
2. 圆、矩形、圆弧、椭圆最后一点或数值确认后应直接出现正式图元；移动/复制目标点确认后结束。旋转/缩放输入数值后只确认一次。
3. LINE/PLINE 点击三个点，U 撤回末点，补点后分别用 Enter、Space、C 或 Esc 结束；检查未确认的鼠标预览没有混入结果，一次撤销/重做恢复整次命令。只有一个点时结束不创建对象。
4. 在动态输入和底部输入使用 L+Space、M+Space、坐标+Space，检查无重复提交；普通文字输入空格正常。UCS+Space、3P+Space 后应进入三点建系。
5. 第一次 Esc 取消当前步骤或保留有效连续绘图，下一次 Esc 清除选择；右键提供确认、U/C、取消及整次放弃。点击菜单外只关闭菜单，不在画布落点。
6. 在画布中心及边角缩放，观察鼠标下图元的位置保持；改变相机角度、面板宽度及 DPI 后重复检查，中键平移和 Shift+中键旋转仍可用。

## 第四批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. XY 平面直线从 (0,0) 到 (100,0)，以 x=30、x=70 的有限竖直线为边界，在中段点选修剪；预览应保留 0～30 和 70～100。确认后检查属性、一次撤销及 DXF 保存。
2. 半径 10 的圆以穿过圆心的竖直线为边界，点选右半圆修剪，检查剩余左半圆；闭合多段线从参数缝附近修剪，检查没有额外碎片或错误闭合边。
3. 直线从 x=0 到 50，以 x=80、y=-10～10 的有限线为延伸边界，选择末端应到 80；把边界改为 y=10～20，应提示没有有效交点。开放多段线只延伸所选首/末段，圆弧不得延伸成整圆。
4. 两条不相接但共面相交的直线分别点击所需保留侧，用半径 5 圆角或距离 5 倒角；确认连接边方向、两条原线各自颜色/图层保留。异面、平行、过大半径均应失败且原图不变。
5. 直线两侧、圆内外侧及闭合多段线内外侧分别偏移，检查距离和原件保留；改变工作平面后测试空间直线，无法处理时明确提示。
6. 矩形阵列光标输入 3 列、2 行，拾取 U/V 间距 20/30，确认总共六份；环阵输入数量并在右侧设分布角。零、小数、超过数量/总结果预算的输入不能部分提交。
7. 拖动圆半径夹点或在属性中预览夹点，直接输入半径 5；端点/圆心夹点切换到坐标输入，确认预览及提交结果一致。固定预览后继续改值应生效，Esc 不写回。
8. 同时有多个重叠对象时用 Tab 切换点选候选；捕捉、光标文本和右键菜单不应触发额外选点。锁定层或不支持的源类型失败后仍可 Esc 取消。

## 第五批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. TRIM 选择边界后连续处理三条目标线，确认每次点击已写入且不重新启动命令；鼠标停在另一个有效目标上按 Enter，应结束且不额外修剪。Esc 结束同样保留此前结果。
2. 先做一次与本命令无关的移动，再进入连续修剪。连续两次修剪后按 U 两次只恢复这两次修剪，再按 U 不能撤销之前的移动。空输入 Ctrl+Z 和右键 U 应走相同路径；输入非空时 Ctrl+Z 仍编辑文字。
3. 边界集包含待修剪对象时，修剪导致拆分/删除，继续用结果片段作边界；U 后检查原边界身份和蓝色标记恢复，没有引用已删除对象。
4. EXTEND 连续延伸多个目标，U 只撤回最后一次；无有效交点、锁定或不支持的目标不增加历史，仍可选择下一个目标。
5. OFFSET 输入距离后连续选择源对象和侧点，确认距离保留；D 改距，N 在侧点阶段丢弃当前预览后重新选对象。已有尺寸锁定时键入 D/N 也应识别为选项。
6. 在一次连续命令中混合成功、失败、U 后继续修改，检查每次一条原生事务，CAM 过期/重算及撤销上下文恢复仍正确；结束后保存 DXF/项目并重新打开，由用户检查实际结果。
7. 如检查历史预算，连续修改超过 100 次再连续 U，不得跨出实际可用历史；命令内结束、切换输入位置或右键操作不应额外提交悬停目标。

## 第六批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. XY 平面选直线 (0,0)→(20,0)，RO 取基点 (0,0)，鼠标指向 +Y 或输入 90，结果应为 (0,0)→(0,20)。用先选/后选两种方式执行，C 切换复制应保留原线，一次撤销恢复整批。
2. 30° 方向的直线以原点为基点 RO→R，输入原角度 30，再输入新方向 90，应旋转 60°；改用两点拾取原方向，检查结果一致。原方向可取自其他对象，不从源对象自动猜测。
3. 长 20 的直线 SC→基点→R，输入原长度 20、新长度 50，应长 50。改用参照两点及鼠标新长度，并混合多选圆弧/多段线，基点应固定、属性应保留。
4. 直线 (10,0)→(20,0) 执行 MI，轴两点 (0,0)/(0,10)，末步 Enter/N 应同时存在原线和 x=-10～-20 的镜像线；Y 应只有镜像结果。末步 Esc 不修改源图，撤销应恢复原状态。
5. 在角度/长度字段锁定后直接输入 R/C，分别从光标输入、底部命令行及右键切换；再由数值切为 #/@ 坐标，检查预览和最终结果一致，无旧参数残留。F12、Tab、悬停输入框不应额外提交。
6. 在 YZ/ZX、三点工作平面和自定义旋转轴下重复旋转；高级镜像平面/法向应继续生效。零参照、相同镜像轴点、零自定义轴和非法比例不提交；锁定层失败不得部分修改。
7. 提交变换后核对 CAM 更新/待处理安排、撤销重做与 DXF/项目保存重开。此流程继续使用原生事务；本批不声称已运行文件或加工验收。
