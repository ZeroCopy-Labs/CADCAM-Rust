# CAD 交互改造计划

制定日期：2026-10-25。以 AutoCAD 2024 用户的常用操作习惯为参考，沿用现有 Rust / Bevy / egui 与原生 CAD 编辑事务。用户负责交互验收，开发过程负责完整应用构建；构建不替代交互验收。

当前进度：第一至十三批的下列基础范围已实现，完整构建通过；动态输入、连续修改及实际交互由用户验收。椭圆/样条结构修改和复杂偏移拆圈仍不在本批范围。

第三批交付：上一批提交为 `7cb9055`。移动/复制/删除与常用变换支持先选或后选；圆、矩形、圆弧、椭圆、移动/复制、粘贴、夹点及测量在最终必要点确认后提交，旋转/缩放输入数值后确认即提交。文字仍保留工具页参数与最终确认。

连续直线、多段线和有效样条在结束时一次写入；U 撤回当前草稿末点，C/Enter/空格完成，Esc 保留已确认且能成形的部分；点数不足时取消。右键可显式“放弃整次未提交绘图”。整次绘制只占一条历史，尚未结束的草稿不会被自动恢复快照保存；切换 CAD/CAM 仍会放弃未结束草稿。曲线整理工具仍要求预选对象，其图形化流程留到第四批。

CAD 默认追加选择，Shift/Alt 移除、Ctrl 切换；CAM 保持原有 Shift 追加及 Ctrl 重排。Space 在命令输入框执行确认，其他文字控件保留空格；空格分隔坐标仍可整体粘贴后 Enter。UCS 支持先输入 UCS、再输入 XY/YZ/ZX/3P。只完成构建及静态检查，未执行 GUI 或功能测试。

## 第五批：连续修改与命令内撤回

- [x] 修剪/延伸保留边界，偏移保留距离，提交一次后继续选择下一个目标。
- [x] 最终点击提交本次修改；等待目标时 Enter/Space 结束，Esc 丢弃当前预览并保留已完成结果。
- [x] U/空输入时 Ctrl+Z 只撤回本命令最近一次修改，核对原生事务 ID，不能撤销命令开始前的操作。
- [x] 边界被裁分/删除时跟随真实结果更新；撤回时恢复对应边界身份。
- [x] 失败目标不产生历史、不结束命令，可重新点选；偏移可在命令内用 D 修改距离。
- [x] 更新动态提示、右键菜单、使用指南与人工验收步骤，完成完整构建。

第五批在 `22b2446` 之后实施：TRIM/EXTEND/OFFSET 每次成功点击独立提交一条事务，保持命令活动；U 先核对原生栈顶事务 ID，再复用原有撤销与 CAD/CAM 上下文恢复，不会越过本命令历史。既有原生历史预算仍为 100 条，超出可用范围明确停止撤回，不合并为一条长期占用的文档事务。连续绘图的一次撤销语义不变。

等待目标时 Enter/Space 结束，而非提交悬停目标；最终点击仍提交当前修改。偏移的侧点阶段 Enter 确认当前侧点，N 丢弃当前预览并重选对象，D 更改距离；右键可随时结束并保留已完成结果。U 不回退工具尺寸，只撤回几何修改；命令内不提供重做，退出后可用原有全局重做。边界角色按裁分/删除和撤回更新，未选中的保留边界以蓝色提示，不修改图元实际颜色。

第五批不扩展椭圆/样条或偏移几何内核；当时圆角/倒角为单次一对直线，第十二批已扩展为连续边对。仅确认完整构建和静态检查，GUI/保存往返由用户验收。

## 实现与验收路径

输入入口（功能区、键盘、动态输入或底部命令行）→ 同一命令步骤 → 临时预览 → 原生编辑事务 → 显示与 CAM 同步。界面调整不新增独立几何副本或另一套编辑提交路径。

每批完成后更新复选框与实际边界，执行 `cargo build --workspace --offline`。交互验收由用户进行：

1. 宽/窄窗口与高 DPI 下，功能区图标、文字与下拉菜单可用，收起特性面板后画布扩展，CAD/CAM 切换布局正确。
2. 图层、颜色快捷修改支持单选、多选和混合值；锁定层、隐藏层限制沿用现有事务；撤销可恢复。
3. 鼠标旁输入画矩形、输入半径画圆、相对坐标复制；在两处输入间切换，提示和最终坐标一致。
4. 两种顺序启动移动、连续画线后取消、边界修剪、夹点输入；检查确认次数、Esc 与撤销行为。
5. 面板、菜单、命令行操作不触发底层选择/绘制；文字、拾取和视图操作限定在实际画布。

1. XY 平面 C→圆心 #0,0,0→半径 20，应为半径 20；改用 D→20 或直接 CIRCLED，应为半径 10。D 模式鼠标指定距圆心 20 mm 的点，结果也应为半径 10。
2. C→2P，点 (0,0,0)/(20,0,0)，应为圆心 (10,0,0)、半径 10；从功能区、绘图菜单和 CIRCLE2P 入口重复。端点支持捕捉、#/@ 坐标及沿鼠标方向的长度输入。
3. C→3P，点 (10,0,0)/(0,10,0)/(-10,0,0)，应为圆心原点、半径 10 的完整圆。输入三点共线或重复点，不能增加图元/历史；失败后重新指定第三点应可继续。
4. 画布动态输入分别按 2 再 P、3 再 P，确认识别方式选项，而非把 P 追加到数字坐标；尺寸已锁定时输入 R/D，圆心保留、锁定清除。混合光标/底部输入、F12 及鼠标确认，预览和最终半径应一致。
5. U 撤回圆心/直径端点/圆周点，点数归零后切换其他画圆方式；取圆心后不允许直接改成 2P/3P。Esc、点数不足时 Enter 不创建对象，不撤销命令前的正式编辑。
6. 在 YZ/ZX 及三点工作平面复核法向、坐标和原生圆，异面捕捉应拒绝或由显式投影处理；当前层颜色/锁定、一次撤销重做、CAM 更新及 DXF/项目重开由用户验收。

## 第九批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. XY 平面 REC/RECTANG→首角点 #10,20,0→D→100→50。鼠标在首点右上方时，应预览对角点 (110,70,0)；左上为 (-90,70,0)，左下为 (-90,-30,0)，右下为 (110,-30,0)。分别确认，核对边长及闭合原生多段线。
2. 输入完宽度后，先不确认，在四个象限移动鼠标/捕捉点；尺寸始终为 100×50。鼠标停在轴线上时相应方向取正；点击/Enter/Space 应只提交一次，不因刚输完尺寸就写入。
3. 放置阶段光标输入无前缀 -1,1 应相对第一角点选左上；底部无前缀 0,30 应按绝对点选择同一象限。混合 #/@、三维坐标、F12 与右键确认，检查预览和最终角点一致；没有有效预览时空确认不创建图元。
4. U 从放置退回宽度，再 U 回长度，再 U 回普通对角点，再 U 撤回首角点；之后可重新取点或 D。已有数值锁时 D、右键 D/U 仍正常，不使用旧的长度/宽度或错误提示。
5. 零、负、NaN/无穷及非法文字不推进尺寸阶段；异面放置拒绝且无部分图元。Esc 后重新绘制矩形，不继承尺寸或阶段；原有未使用 D 的两对角点流程保持可用。
6. YZ/ZX/三点工作平面下复核 U/V 长宽与法向；最终结果的当前图层/颜色、锁定层失败、一次撤销重做、CAM 更新及 DXF/项目保存重开由用户验收。

## 第十批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. XY 平面 REC→首角点 #10,20,0→R→90→D→100→50。在旋转后 +U/+V 象限选择点 #9,21,0，应形成角点 (10,20)/(10,120)/(-40,120)/(-40,20) 的矩形，首角点固定、边长为 100 与 50。
2. 先 D 输入 100/50，再 R 输入 90，尺寸应保留；从长度或宽度收集阶段进入 R，确认角度后应回到之前的尺寸阶段。选择旋转后的四个象限，检查预览和最终角点一致。
3. R 输入 90 后再 R 输入 30，应为最终 30°，不是 120°；R 输入 0 恢复原方向，负角与超过 360° 的等价角应一致。非法、NaN/无穷不改变之前角度。
4. 不用 D，首角点原点→R 45→对角点 #100,50,0，四角应约为 (0,0)/(75,75)/(100,50)/(25,-25)，边方向为 45° 与 135°，不把给定坐标再旋转一次。
5. 光标、底部、右键与工具页输入同一角度；已有数值锁时键入 R，空确认保留当前角度，U 退出未确认的角度输入并保留之前有效角度/尺寸。F12 与 #/@ 坐标切换不改变原坐标语义。
6. U 退回并撤去首角点，再重新取点时角度应为 0；Esc、重新启动或 CAD/CAM 切换后不继承旧角度。YZ/ZX/三点平面下复核方向、法向、颜色/图层、一次撤销重做及 DXF/项目重开；由用户执行实际验收。

## 第十一批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. XY 平面 ARC→C，圆心 #0,0,0、起点 #10,0,0、方向点 #0,20,0。应为半径 10、起点 (10,0)、终点 (0,10) 的逆时针 90° 圆弧；实际端点不必经过方向点 (0,20)。ARCCE 及菜单入口应一致。
2. 同样圆心/起点，方向点 #0,-20,0，应为逆时针 270°、终点 (0,-10) 的优弧。改用 A 扫角 -90，应到同一端点但为顺时针劣弧；核对预览和原生 ARC 方向。
3. ARCCA 取圆心和起点后应等待角度，未确认不增加图元/历史；光标或底部输入 45/-90/270，预览应随值变化。空确认使用默认 90°，右键确认使用当前输入；一次撤销恢复整次创建。
4. 圆心方式取点后 E/A 切换，圆心和起点保留；扫角步骤 U 撤回起点，再 U 撤回圆心。点数归零后改 3P，逐字输入 3 再 P 也应识别选项；原三点方式经过中间点、可顺/逆时针的行为保持。
5. 圆心与起点重合、终点方向指向圆心或与起始方向相同、零扫角、±360°、更大角度及 NaN/无穷不得提交。错误后可重选当前点或重新输入角度，Esc 不创建部分结果，也不撤销之前的正式编辑。
6. 终点方向阶段的 @ 坐标以圆心为参考，# 为绝对；光标无前缀坐标默认相对，底部无前缀默认绝对。F12、候选循环与菜单切换不混入额外点；YZ/ZX/三点工作平面的法向/角度由用户核对。
7. 新旧方式混合当前颜色/图层、锁定层失败、撤销重做、CAM 更新及 DXF/项目保存重开，检查实际圆弧端点和方向。新构造结果应是原生 ARC，非显示折线。

## 第十二批人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. 画水平线 (0,0)→(40,0)，左竖线 (0,0)→(0,40)，右竖线 (40,0)→(40,40)。FILLET 输入半径 5，先处理左角，再重新选更新后的水平线与右竖线处理右角。应连续完成两对，水平线两端分别退到 x=5、x=35，不因第二次使用旧几何恢复左端。
2. U 只撤回右角，左角及第一次修剪的水平线保留；再次 U 恢复左角，再 U 不撤销进入本命令前的编辑。空输入 Ctrl+Z、右键 U 走相同流程，每次恢复两条原线与本次连接圆弧。
3. CHAMFER 用相同图形、退让距离 5 连续处理两个角，检查每次为独立直线连接边，原线方向、颜色/图层各自保留，连接边继承第一条；一次 U 只恢复最近一对。
4. 选第一条后，鼠标悬停有效第二条时按 Enter/Space，应结束且不提交本对；在等待第一条时结束、Esc 或右键结束同样保留先前成功操作，不多生成连接边。
5. FILLET 中 R 改半径、CHAMFER 中 D 改距离，输入后重新选第一/第二条；已有尺寸锁时短选项仍可识别，右键参数确认使用共享输入。N 清除当前第一条和预览后重选，不增加历史；OFFSET 的 D/N 原流程保持。
6. 同一条边、非直线、平行/异面、过大尺寸或锁定层等失败不增加历史，不丢失之前成功结果。几何预览失败可重选第二条或 N；原生提交失败应返回第一条。改参后可继续成功操作。
7. 改尺寸后 U 撤回上一几何操作，尺寸应继续使用新值；命令内无重做，结束后全局重做复用原生历史。预算超出 100 条时不能跨出核心有效历史；CAM 更新、撤销上下文及 DXF/项目重开由用户核对。

## 第十三批及整轮人工验收补充

以下为待用户执行的步骤，不是已经运行的功能测试：

1. 空闲时在光标/底部输入相同完整命令、别名及前缀（如 CI），确认都启动同一工具；在 C 前缀下改变候选后继续键入 CO，候选应回到 COPY，不沿用之前索引。空输入且无草稿才重复上次工具，未知文字仍提示错误。
2. 光标锁定数值后切到底部，保留 #/@ 含义；从底部切回光标、F12、窄窗口回退后再确认。侧栏/右键确认当前输入与 Enter/Space 应采用同一草稿；矩形尺寸/角度、圆半径、圆弧扫角及阵列数量分别检查。
3. LINE/MOVE/复制/矩形取点时输入显式 #/@/极坐标，先看预览，再把鼠标移向另一个位置并点击。最终点应使用输入坐标；非法 #abc,0 或 @10<abc 不得悄悄采用点击位置。检查真实捕捉和原点/平面切换的既有范围。
4. ARRAYRECT 在底部修改列/行，环阵修改数量，确认前应更新预览；旋转/缩放、圆弧正负扫角在两处输入的预览与提交一致。粘贴用完整命令、前缀及空输入重复，均读取当前系统剪贴板而非旧缓存。
5. 连续 LINE/PLINE 取两点后留一个未确认坐标草稿：普通确认提交该输入；工具页“结束取点”或 Esc 只保留此前有效已取点部分；显式放弃草稿不创建对象。有效连续绘图的结束仍只占一条历史。
6. 连续复制、修剪/延伸/偏移、圆角/倒角在等待目标时空确认只结束；有输入时按当前阶段处理。第二条线悬停预览不能因空 Enter 而提交；Esc 和右键结束保留既有结果，U 不跨入命令前历史，文字非空时 Ctrl+Z 仍编辑文字。
7. CAD 有活动命令时打开配置/导入报告/性能/轨迹窗口，在其控件中输入、Enter/Space/Esc/F3/F8/Tab/Ctrl+Z；不能触发后台 CAD 命令键盘或抢回底部焦点。关闭后草稿与锁定仍在，没有排队的 Enter 重放；右键 Esc 只先关菜单。
8. 高 DPI、窄窗口、收起侧栏、CAD/CAM 切换、中文图层和实际大图下复核菜单、候选、光标浮层与画布拾取。不同文本框的空格、复制粘贴、撤销保持文字行为；图纸颜色/图层/几何、历史、DXF/项目往返及 CAM/NC 正确性仍由用户验收。

整轮验收记录建议标注入口、输入顺序、当前工作平面、预期/实际结果及是否已写入正式图纸；发现问题后按具体复现步骤修复，不把构建通过视作功能验收完成。
