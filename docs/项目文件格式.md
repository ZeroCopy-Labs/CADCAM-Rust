# CAD/CAM 项目文件格式

[返回项目入口](../README.md) · [使用指南](使用指南.md) · [架构](架构.md)

当前版本为 `format = "CADCAM-Rust"`、`version = 1`，扩展名 `.cadcam`，文件编码 UTF-8 JSON。尚无旧版本迁移器，不支持的格式或版本拒绝打开；旧版本 1 中原先未识别的基础 TEXT 允许新增身份迁移，保留已有引用，打开后项目标为待保存。不要把文件当作普通 DXF 导入其他 CAD。

## 正式保存内容

| 字段 | 内容 |
|---|---|
| `drawing.dxf_base64` | 当前原生图纸序列化的 ASCII DXF 字节，Base64 编码；保留源单位和旧版本代码页，不把 GBK 等字节误当 UTF-8 |
| `drawing.ids` / `drawing.layers` | 原生句柄到稳定图元 ID、图层身份键到 ID；保留已分配身份，避免重开后复用旧引用 |
| `drawing.entities` / `drawing.current_layers` | 当前图元句柄/ID/类型及图层 ID/名称，恢复时校验集合对应关系 |
| `drawing.source` / `drawing.unit` | 原始来源名称/路径/格式/版本与源单位；工作区继续统一毫米 |
| `drawing.report` | 导入遗漏、块源映射、解析完整性及警告，不因项目保存而抹掉遗漏 |
| `machining` | 截面、显式清除、人工断面指定/取消、配对、修边、手动顺序、旋转策略和待处理项 |
| `profile` | 完整 G-code 配置快照，规则结构与现有 TOML 配置共用同一类型 |
| `excluded` | 明确排除 CAM 的参考图元 ID；不依赖图层隐藏 |

区位、加工方向及起点仍由策略派生；没有新增独立人工起点数据。采样、自动候选、拓扑、分组和轨迹不作为缓存写入项目。撤销/重做历史、相机、选择、工作平面和未确认预览不持久化。导入范围“已核对”也不保存，重开需要重新确认。

## 保存与打开

1. 从当前正式原生文档生成 DXF 快照和身份表，合并加工选择、工艺及范围为 JSON。
2. 写出前解析序列化内容并重新读取内嵌 DXF，检查其身份、图层及单位可恢复；失败不覆盖已有项目。
3. 同目录临时文件写入并同步，已有项目先备份为 `<文件名>.bak`，再替换目标；成功后才更新项目路径和保存点。
4. 打开先在候选状态解析版本、图纸/身份和加工引用；成功并处理当前未保存工作后才替换会话。来源文件仅用于追溯，缺失时提示并用内嵌图纸；配置差异提示后采用项目配置，不写全局配置文件。
5. 重新建立显示和加工采样、CAM 拓扑/分析及轨迹。采样不支持或工艺/安排有错误时仍可编辑项目，G-code 保持阻止输出。

项目保存点与 DXF 保存点独立。来源路径在 DXF 另存为后改变，也视为项目修改。项目载入不能证明原始外部 DXF 内容仍相同；打开后的 DXF 保存状态独立标记，避免把内嵌快照误认为已经写回外部文件。`.cadcam.bak` 可从打开入口恢复，必须另存为项目，不直接覆盖备份。

## 支持边界

内嵌 DXF 仍由 acadrust 读写，保存前的身份/类型/单位校验不证明任意原生附属记录及几何完全无损，也不证明最终 NC 或加工正确。不重新展开保留的失败 INSERT；未支持的图元仍留在原生记录/导入报告中。解析期已经丢失的数据不能恢复。基础块映射保存的是追溯报告，不恢复块级联动。

项目读取/加工重算使用后台候选及版本校验，支持取消应用；保存及保存前回读仍在主线程。JSON/Base64 和快照会增加文件大小、内存及耗时，没有压缩或性能保证。自动恢复仍只保存 DXF，不保存未写入项目的 CAM 修改。基础文字/标注随原生 DXF 及角色保存，关联关系和测量结果/剪贴板缓存不写入项目。当前只确认项目构建；项目往返、故障恢复、轨迹显示及最终 NC 由用户验收。
