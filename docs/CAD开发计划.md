# CAD 开发计划与清单

整理日期：2026-10-25。本文根据当前源码与 AutoCAD、FreeCAD 的官方资料制定，描述后续计划；复选框未勾选的内容不代表已经实现。当前能力以 [README](../README.md)、[使用指南](使用指南.md)及[已知限制](已知限制.md)为准。

当前进度：CAD-01～CAD-14 已完成本轮基础范围的实现和完整应用构建，用户功能验收待进行。本批接入独立加工采样和直线/圆弧/多段线的曲线整理。参数修剪、定长延伸、两直线倒角/圆角及样条采样范围见使用指南；交互式裁剪边界、椭圆/样条结构编辑等仍待扩展。下一批为 CAD-15 图纸诊断与 CAD-16 块/导入往返。

## 目标与范围

先做适合方管激光加工的精确 CAD 工作区：能可靠打开图纸、精确绘制和批量编辑二维及三维线框、保存 DXF，并把当前图纸准确传递给 CAM。保留现有 Rust + Bevy + egui 架构，沿用已有原生文档读写能力，按阶段补齐基础。

首轮范围包含常用绘图、变换、捕捉、工作平面、图层、曲线修剪、图纸整理和 CAD/CAM 状态同步。完整实体建模、通用布尔运算、装配、全功能参数约束求解器、完整 DWG 写出和布局出图系统放在后续评估，不作为完成首轮 CAD 的前提。

参考成熟软件的功能划分和交互机制，形成自己的实现。发布前整理现有依赖及新增依赖的许可证和分发要求；独立开发不作为全部依赖均已完成许可证核对的声明。

## 共同开发约定

每个编辑功能沿同一条流程完成：

```text
菜单 / 工具按钮 / 快捷键 / 命令输入
  → 收集选择、工作平面和参数
  → 临时预览（不修改正式文档）
  → 确认后提交一个文档事务
  → 更新领域快照、显示、属性及受影响的 CAM 数据
  → 记录撤销/重做，并能保存为 DXF
```

- 同一功能的不同入口调用同一处理路径，避免按钮和命令栏各算一套。
- 操作现有图元的命令支持单选和适用的混合批量选择；几何关系工具明确支持的图元组合及批量规则。
- 批量操作预先检查适用性；不支持的对象明确提示，不发生用户不知情的部分修改。
- `Esc` 取消、不改变正式文档；一次拖动或一次批量确认占一条历史。无变化操作不占历史。
- 计算坐标保持 `f64`；显示用数据不能反写为原始几何。界面显示值与保存值的精度分别管理。
- 每阶段修订对应使用指南和限制说明，逐项勾选实现状态，并单独记录用户验收状态。
- 开发方按当前约定负责完成应用构建，默认执行 `cargo build --workspace --offline`；功能验收由用户执行。下列场景是交给用户的验收清单，不代表已经运行，不擅自扩大为自动测试或机床验证工作。

## 阶段总览

| 顺序 | 阶段 | 交付结果 | 主要依赖 |
|---|---|---|---|
| 1 | 文档、事务与文件可靠性 | 编辑可撤销/重做，保存不丢数据，单位明确 | 现有原生文档和编辑入口 |
| 2 | 精确交互与坐标基础 | 能准确选中、取点、输入坐标和取消命令 | 阶段 1 的提交机制 |
| 3 | 常用绘图、变换与图层 | 完成日常补图和批量编辑 | 阶段 2 的取点与预览 |
| 4 | 曲线整理、拓扑与导入完整性 | 轮廓能可靠修整，CAD/CAM 几何精度分离 | 阶段 1～3 的文档及工具 |
| 5 | CAD/CAM 同步与项目保存 | 图纸、加工安排和导出使用同一有效状态 | 阶段 4 的几何与拓扑 |
| 6 | 效率工具、性能与交互收尾 | 常用管材操作顺手，大图有可定位的性能问题 | 前述核心流程稳定 |

每阶段拆成下面的小批次独立交付，不积累到整个阶段结束才构建和交给用户。

## 阶段 1：文档、事务与文件可靠性

目标：已有的移动、删除、颜色和图层编辑先形成完整可靠的操作基础。

- [x] **CAD-01：统一编辑事务与身份。** 沿用 `EditableDrawing` 作为正式修改入口，原生文档为权威数据、领域模型为派生快照；本批删除/恢复及换层保持图元和图层身份。候选副本验证后提交，以事务通知区分颜色、换层、几何变化，失败保持原文档。新建图元、图层管理和夹点已在后续批次接入，其他编辑继续复用。已构建，待用户验收。
- [x] **CAD-02：撤销与重做。** 已补重做及菜单/快捷键状态；有效新编辑清空重做；同步选择、脏标记和受影响的 CAM 状态。历史按次数限制为最近 100 次，复用现有快照机制。已构建，待用户验收。
- [x] **CAD-03：文件生命周期。** 新建、打开、保存、另存为、关闭及退出统一处理未保存修改；DWG 来源进入 DXF 另存为。临时文件替换与 `.bak` 覆盖备份，失败不更新保存版本；独立自动恢复快照和手动恢复入口。已构建，待用户验收。
- [x] **CAD-04：单位与导入报告。** 工作区统一毫米、原生文档保留源单位；未知单位先选择毫米/英寸。报告展示解析/转换数量、跳过样本及警告；已整理[依赖版本与许可证快照](依赖许可证清单.md)。已构建，待用户验收。

主要修改范围：`cad-core/src/edit.rs`、模型及导入转换；`cad-app/src/cad_edit.rs`、`main.rs` 中的文件/历史入口。

用户验收场景：

- 混合图元批量移动、改色、换层、删除，逐次撤销及重做；新编辑后不能重做旧分支。
- 保存后再编辑并撤销回保存位置，脏标记与实际状态一致；保存失败或取消另存为保留未保存状态。
- 保存后重新打开，检查图元数量、颜色、所属图层、坐标、法向及标高。
- 同一尺寸的毫米与英寸图纸进入程序后物理大小一致；未知单位不会被静默当作毫米。

## 阶段 2：精确交互与坐标基础

目标：用户在倾斜视角和不同表面上仍能明确地选择、输入和定位。

- [x] **CAD-05：命令状态与预览。** 移动命令打通“选择 → 基点 → 目标点 → 预览 → 提交/取消”；输入栏显示步骤、参数格式和错误。菜单、Ctrl+M、左侧按钮与命令栏复用路径；文本输入焦点不触发画布快捷键。已构建，待用户验收。
- [x] **CAD-06：坐标与工作平面。** WCS 绝对/相对三维输入、工作平面二维输入、相对距离/角度输入；XY/YZ/ZX 与三点建系，显示原点/轴。鼠标射线与固定工作平面求交，平行/后向/非法结果提示。后续 CAD-08 已加入局部显示原点，局部相机仍有 f32 边界。已构建，待用户验收。
- [x] **CAD-07：几何捕捉与辅助。** 端点、中点、中心、象限点、近点与支持组合的交点/垂足/切点；标记、候选循环、网格、正交和极轴。默认真实 WCS 点，显式投影单独标记；不将屏幕相交当真实交点。完整支持表和数值近点/24 个邻近交点图元的边界见使用指南。已构建，待用户验收。
- [x] **CAD-08：选择与显示精度。** 悬停、重叠循环、选择增删/反选及类型/颜色/图层过滤，蓝/绿框选反馈；保留 Shift 追加。显示、拾取、射线及 CAM 标记统一局部显示原点，先在 f64 减原点再转 f32。选择仍按显示折线命中，未宣称无限精度或全解析曲线选择。已构建，待用户验收。

主要修改范围：应用命令、相机、拾取和交互显示；`cad-core` 中可复用的曲线取点/投影计算。只按实际职责新增模块。

用户验收场景：

- 在 YZ 面和任意倾斜工作平面中，把基点准确移动到另一图元端点；数值输入与鼠标捕捉结果一致。
- 视图缩放、旋转后同一捕捉点坐标不变；空间错开的两条线不能误捕捉为真实交点。
- 重叠图元可逐个选到；在每一步按 `Esc` 均不改动文档；大坐标附近的小圆和短线可准确取点。

## 阶段 3：常用绘图、变换与图层

目标：能在本程序内完成常见补图、孔位调整和批量属性编辑。

- [x] **CAD-09：基础绘图。** 已接入连续直线、平面多段线、矩形、圆、三点圆弧、椭圆及控制点样条新建；复用数值、捕捉、连续绘制/闭合和确认/取消。原生保存法向/标高，直线允许 WCS 三维端点。样条为 1～5 次夹持均匀控制点曲线，闭合非周期；已有对象参数编辑随 CAD-11，不用显示折线代替原始曲线。已构建，待用户验收。
- [x] **CAD-10：批量变换。** 已补基点复制、批量旋转/镜像/正数统一缩放及矩形/环形阵列；旋转可用工作平面法向或三维轴，镜像明确平面内 U 轴、工作平面或自定义法向。保留原生曲线、图层及颜色，预览后整批提交，复制/阵列使用新 ID；不提供非均匀缩放。已构建，具体法向/标高/镜像方向及 DXF 往返待用户验收。
- [x] **CAD-11：属性与夹点。** 共同/混合颜色及图层、圆/圆弧批量半径；六类图元支持范围内的单选端点/圆心/半径/椭圆轴/顶点/控制点夹点，拖动和 WCS 输入均先预览后确认。多段线共用端点联动相邻段，原生几何写回并支持撤销/重做。周期/仅拟合点样条和增删顶点暂不包含。已构建，待用户验收。
- [x] **CAD-12：图层管理。** 新建/改名/删除迁移、当前层、RGB 颜色、显示/锁定及统一事务；图层以原生句柄保持身份，隐藏不参与显示/普通选择/捕捉，核心阻止锁定层编辑和非法目标。非空层删除必须明确迁移，默认层受保护；改名同步内存 G-code 规则，双键冲突整批取消。隐藏/锁定不排除 CAM，图层状态随 DXF 保存。已构建，待用户验收。

主要修改范围：核心图元创建/变换、图层模型、编辑命令和属性面板、原生 DXF 记录映射。

用户验收场景：

- 在四个不同朝向的工作平面绘制孔和轮廓，复制、旋转、镜像后导出 DXF，检查位置、法向及圆弧方向。
- 单选与混合批量选择都能完成适用操作；取消预览不留下图元，阵列一次撤销全部恢复。
- 新图元使用当前图层；隐藏、锁定、改名和删除图层后，选择、属性、DXF 与加工规则一致。

## 阶段 4：曲线整理、拓扑与导入完整性

目标：把工程图整理成可靠轮廓，并解除 CAM 对显示折线精度的依赖。

- [x] **CAD-13：几何计算与公差（基础范围）。** 六类几何求值/反向、数值近点，线/圆弧/多段线求交与裁分；距离/角度/屏幕公差分开。CAM 从领域几何按默认 0.01 mm/3° 独立采样，正权重夹持非周期 NURBS 按控制包络细分；失败阻止整图 NC，不回退控制多边形。椭圆/样条交点及结构裁分仍待扩展。已构建，待用户验收。
- [x] **CAD-14：轮廓编辑工具（基础范围）。** 已接入打断、参数区间修剪、定长延伸、单链连接/闭合、两端点相接直线的倒角/圆角、线/圆弧/平面多段线偏移及反向；整批预览、原生写回和撤销/重做。明确共面/方向/连接容差及元数据限制，退化/自交等错误取消整批。交互式裁剪边界、更多对象组合和复杂偏移拆圈仍待扩展。已构建，待用户验收。
- [ ] **CAD-15：图纸诊断与修复。** 标出重复图元、零长段、端点间隙、开放轮廓和自交；支持定位与选择。修复给出候选和影响范围，由用户确认；超过连接容差的缺口不自动补齐。显示轮廓方向、闭合状态及长度。
- [ ] **CAD-16：块与导入往返。** 先支持常见 BLOCK/INSERT 和嵌套变换，明确实例、展开后对象及源句柄映射；正确处理 OCS/WCS、标高、法向和镜像缩放。文本/标注/填充等按用途逐步支持，尚不支持的对象在报告中可见。影响加工范围的缺失需明确确认，不能静默作为完整图纸导出加工。

主要修改范围：核心几何、转换与导入适配、`display.rs`、CAM 模型构建及诊断界面；新增计算优先服务具体命令，不先开发通用几何内核。

用户验收场景：

- 共面与非共面图元分别修剪、连接、偏移，检查边界和失败提示；圆角连续且可撤销。
- 同一图纸改变显示质量，最终加工采样精度和轮廓覆盖不随之改变。
- 包含重复线、微小缺口、嵌套块和倾斜圆的图纸可定位问题；修复前后及保存重开后的拓扑变化明确。

## 阶段 5：CAD/CAM 同步与项目保存

目标：编辑后的画面、加工安排、轨迹及导出不再各自保留不一致的状态。

- [ ] **CAD-17：变更传播与重算。** 把文档几何/属性版本、加工配置版本关联到派生数据；移动、修剪、改色、换层、撤销/重做分别触发必要的更新。无效或过期轨迹不能直接导出，必须重算；避免每次只改颜色也重做全部几何计算。

5. 一次撤销/重做恢复整个打断、连接、倒角/圆角或批量偏移；核对颜色/图层、保留的主 ID 和新增 ID。DXF 保存重开，检查圆弧/多段线类型、法向、标高和英寸源单位，几何变化后 CAM 重建及撤销分析恢复。
6. 用不同半径圆、椭圆、混合多段线和有效夹持 NURBS 样条，核对加工采样来自原曲线；调整显示离散仅影响画布，不应改变计划、入口和 NC。样条正权重、节点端点、闭合接缝及尖点/退化输入按支持范围检查。
7. 打开包含拟合点/周期/非夹持或无效样条的样本，CAD 可保留图纸，CAM 面板显示采样错误，两个 NC 导出入口都不能输出部分路径。检查单图元/整图/样条工作量预算提示。
8. 对完整方管样本检查自动识别、懒旋转、区位/成品配对、普通及 Ctrl 点击重排、初始位置、X/Z 补偿、过切及最终 NC 均使用同一加工采样；隐藏仍保留加工范围。该验收不以构建通过或仅检查原曲线弦差替代四轴/实机效果判断。

若用户在某批验收中发现坐标、图元遗漏、历史恢复或保存问题，先修复该批问题，再扩展后续工具。每批是否 Git 保存按用户当次要求执行。
