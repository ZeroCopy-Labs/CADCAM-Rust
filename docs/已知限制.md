## 输入与几何

| 当前行为 | 影响与边界 |
|---|---|
| 支持模型空间六类曲线、基础单行 TEXT 及基础几何 INSERT 导入展开，块定义保留 | 展开后为独立实体，不保留块级联动；MTEXT/复杂文字、原生 DIMENSION、属性/外部参照/复杂类型及失败实例仍不进入加工，图纸空间不展开 |
| 导入报告保留打开时的转换、跳过、块映射及解析提示；遗漏/解析恢复触发导出前范围确认 | 确认只允许导出已转换子集，不证明完整；模型空间外对象只列数量。映射/确认不持久化到 DXF，解析期丢失记录无法恢复 |
| 已声明源单位换算到毫米工作区；未知单位须选择毫米/英寸才能打开 | 原生记录及 DXF 保持源单位；自定义 G-code 模态不解析，不能将毫米轨迹配合 G20 使用；极小特征和大坐标仍受既有几何容差/显示精度约束 |
| 显示过滤非有限点，样条数据不足可回退控制多边形 | 可见折线不代表原曲线有效，控制点/节点/权重契约尚未完整校验 |
| 显示离散与 CAM 采样已分开，CAM 默认 0.01 mm 弦差/3° 曲线内角度 | NURBS 加工限有效正权重、最多 16 次、夹持非周期；拟合点/周期/非夹持或采样超预算会阻止整图 G-code 导出；公差不含后续补偿/插补/舍入；`arc_tolerance` 仍只控制输出层语义圆弧展开 |
| 截面由闭合单元整体 YZ 包络和圆角估计，当前至多一个候选 | 自动采用不证明图纸符合方管假设，无任意轴向自动对齐或通用截面内核 |

## 拓扑与加工计划

- 连通组可含分支，节点度判定闭合不等于有效加工遍历。开放样条现通过原始曲线求值取得拓扑端点；求值失败不生成伪端点，加工采样另行报错并阻止输出。
- `ordered_unit_points` 从首条显示路径贪心连接，距离门槛为 `1.0`，不同于拓扑容差 `1e-3`。拼接失败可被轨迹构建直接跳过，尚无完整的计划单元覆盖/重复检查。
- 成品组按独立左右断面配对，普通单元按显示路径采样判断归属；边界检查仍依赖离散路径，未证明采样点之间的完整几何关系。组外单元单列、未配对断面不自动补偿；不支持相邻成品共用断面或自动共切。
- 手动指定断面只要求已有截面、单元闭合且有 X 范围，不执行自动候选同等的绕数/覆盖验证。
- 普通单元起点按局部极点选取，完整重建与手动重排使用同一规则；极点来自显示采样点，受离散精度影响。局部规则保证可解释性，不保证全局最短加工时间；切断断面仍有独立入口策略。
- 跨区位轮廓的首选极点可能不在主区位，懒旋转会尝试南极点，再选主区位内极值。开放路径仅选端点；无端点在主区位时回退到两端极值，不能保证它位于该区位的真实几何极点。
- 几何编辑已保留有效断面/配对/修边及组内相对顺序；区位、单元方向和起点仍为派生策略，没有独立人工编辑/迁移参数。拆分、连接、删除或离开原组会产生待处理项，核对前暂停导出；确认当前安排不恢复旧引用或证明新安排正确。
- 顺序、截面、断面、配对、修边和参考角色可通过 `.cadcam` 项目保存；另开 DXF 会重新生成，不含这些应用设置。无独立 CAM 撤销重做；CAD 的颜色、图层、移动和删除支持整批撤销/重做。

## 图纸诊断与块往返

- 已有重复、零长、间隙、开放/分支及内部交叉诊断、定位和单项修复预览；扫描受图元/段/组合/条目预算限制，超限结果明确不覆盖全图。椭圆/样条交叉是离散候选，不证明全局拓扑正确；不自动解交或批量修复全部问题。
- 块导入采用先在内存中展开、再编辑/保存独立实体。嵌套、镜像、缩放、基点和 OCS 已接入，但未做本轮 GUI/DXF/NC 验收；块内多段线可能拆成多实体，非均匀圆弧可能成为椭圆弧，块级参数/父层锁定联动不保留。原始源映射仅在导入报告，DXF 重开不恢复原块实例关系。
- 含属性、复杂文字/原生标注/填充、外部参照、禁止分解、递归、宽度/挤出厚度/拟合标记、无效变换或超预算的实例保留原生记录并报告未展开。直接导入的拟合多段线/网格也明确不转换，不以控制折线冒充加工几何。
- 原生不可见标记现在参与显示和捕捉过滤，实例隐藏状态可能固化在展开对象上；初版没有单独解除实体不可见的 UI。隐藏仍不自动排除加工。DXF 读写保真继续依赖第三方库，不保证所有版本、附属记录或关联对象无损。

## CAD 编辑与 DXF 导出

- 已提供基础绘图、批量变换、单选夹点、圆/圆弧批量半径及图层管理；已补直线/圆弧/多段线的参数裁分、定长延伸、连接/闭合、倒角/圆角及偏移；尚无通用约束、自由增删顶点、交互式裁剪边界拾取和椭圆/样条结构编辑。夹点按本批支持表工作，不包含周期或仅拟合点样条控制点编辑；样条手动改控制点后旧拟合点数据清除。
- 曲线整理首批限零宽/零厚度、无拟合标记的线框；连接要求单一无分支链，倒角/圆角只接受两条端点相接直线。多段线偏移不处理复杂自交拆圈，失败取消整批；重合区间求交及完整自交/拓扑证明尚未实现。工具参数和具体语义见使用指南。
- 除直线外的新建图元限定在当前工作平面；多段线本批只绘制直线段。新样条为 1～5 次夹持均匀控制点样条，闭合不保证连接处切向连续，未提供周期或拟合点创建。
- 变换只提供刚性变换、镜像和正数统一缩放；阵列数量包含原件，环阵支持整圆或部分总角度且副本一起旋转，单批上限 50000 个图元。原生库对线宽、厚度及关联对象的变换/复制不作完整保证，不属于通用关联图纸的深复制。仅确认完整应用构建，实际法向、标高、镜像圆弧方向及 DXF 往返由用户验收。
- 交点、垂足和切点仅覆盖使用指南列明的直线/圆弧组合；未实现椭圆/样条交点及异面圆—圆交点。交点最多搜索 24 个邻近图元；曲线最近点使用参数采样/细化，不证明复杂样条的全局最优。约 `1e-6 mm` 用于空间交点与候选去重；近共线、相切及退化情况仍需验收。
- 图层隐藏仅作用于显示、普通选择和捕捉，不排除 CAM 加工；项目中的参考对象可明确排除采样和拓扑，仍保留在 CAD/DXF。参考角色不是 CAD 撤销事务，混合角色合并须先统一；锁定由核心拦截整批编辑。图层改名同步内存 G-code 规则，冲突取消，删除层不自动合并规则；DXF 不保存这些工艺配置。隐式导入层缺少原生表记录时，管理操作可能拒绝。适应视图的包围盒仍包含隐藏图元。图层管理不等于完整 DWG 层状态、外部参照和关联对象管理。
- 基点/目标点移动支持数值输入、预览及确认/取消；工作平面、捕捉与辅助不持久化，不参与 CAM 几何。真实空间捕捉默认不投影；显式投影选项有独立标记，没有表观交点功能。
- 图纸与相机目标保持 f64，显示、拾取、射线、CAM 标记共用局部显示原点。局部渲染和相机仍使用 f32，选择命中仍基于显示折线；未验证任意巨大跨度或极微小尺度。命令栏只支持已列明的命令，不是完整 AutoCAD 命令系统。
- DXF 导出使用原生文档和第三方库版本策略，不从显示折线生成；没有 DWG 写出或完整往返保真验证。库未读取或未能正确写出的对象不能保证保留。
- 撤销/重做在内存中共保留最近 100 次批量编辑的原生文档快照及所需界面上下文，按次数限制而非字节数；大图仍可能占用较多内存，没有历史持久化。几何编辑重新计算并按成员身份迁移有效安排，失效项须明确核对后才能导出；CAD 撤销/重做恢复对应分析及待处理项并按当前工艺重算，但没有 CAM 操作的独立撤销事务。
- 新建、打开、关闭图纸及退出会处理未保存 CAD 修改；正常保存及导出采用同目录临时替换和 `.bak` 覆盖备份。异常恢复快照在首次修改后及后续最多每 30 秒更新，不包含历史或 CAM 安排，不能恢复尚未写入的修改；文件 I/O 仍在主线程。仅确认应用构建，文件故障、恢复、单位往返和 GUI 结果待用户验收。

## 运动与输出

- 有截面旋转净空已改用截面/图纸 YZ 包围矩形半对角线，并计入正加工 Z 偏移；它是保守的管材径向上界，不包含夹具、刀头尺寸和切断后材料运动，不能作为完整无干涉证明。
- 同面联动默认启用，以已确认的水平管材平面为前提。圆角、跨面和不确定区域采用净空回退，不做任意障碍避让。关闭联动后旧离面值仍默认为 0，可能表面快速转移。可选的同面/跨区位空移平滑仅构造受保护的参考曲线并输出离散快速线段，空间或离散预算不足时保留原路；未实现控制器专用混合或加加速度规划。
- 非零 Z 的跨区位联动要求可靠的断面方向：圆角/转角拟合残差不超过 0.01 mm，各角方向差不超过 1°；普通跨区位非平面路径不作猜测，会报错阻止导出。未启用壁厚端面补偿时保持的是离散刀头采样点的方向；启用时按含 Z 偏移的激光内壁作用位置统一求单向 X 修正，允许刀头轨迹弯折，不再额外叠加 Z/X 联动。未增加独立加工公差离散，也不保证段间四轴插补及文本舍入后误差为零。
- 壁厚补偿采用局部方向和内壁投影近似，保留壁厚及内轮廓有效性检查，不做严格激光射线穿透判定。不含割缝、热变形、穿透及夹具动力学；补偿后空间检查仍为离散采样检查。本轮仅完成构建，功能与材料效果由用户验收。
- 基础校验包含联动参数、部分数值、空范围、切削段、A 有限性/切削大跳变及跨单元空移 A 变化；不检查机床行程及 A 轴绕线/转角极限、完整几何连续性或夹具/刀具碰撞。
- A 采用连续角度，可超出 ±180°，结束返回只恢复等价朝向，不恢复累计圈数。相邻几何姿态恰差 180° 时，源采样本身无法唯一确定旋转方向。
- 配置的初始及返回位置已纳入统一轨迹与校验；到达首个已知配置位置之前的实际机床姿态仍未知，程序无法验证这一未知进场。
- `arc_cut_info` 按旋转后法向最大分量选择主平面，未严格要求曲线与平面对齐。方向和控制器平面约定需固定样本验证，不能保证任意倾斜圆弧正确输出。
- 无截面回退使用原 XYZ 和固定 A，不应用加工 Z 偏移及过切。不自动输出 F，速度由用户头尾代码控制，未建模机床专用进给模式及完整后处理。
- 自定义头尾可改变模态或运动状态，基础校验不解析这些代码，也不解析最终 NC。
- 快速导出依赖工作目录并覆盖同名文件；两个入口均导出完整计划，无仅导出所选单元功能。

## 测量、表达与几何剪贴板

- 测量沿真实三维取点；椭圆/样条长度为带标识的离散估计，不保证长度误差。坐标/距离/角度结果不随源几何编辑关联更新。
- 基础 TEXT 只支持左/基线、单位宽度、无倾斜/镜像标志/厚度；应用字体、控制码和投影排版可能与源 CAD 字体不同。未支持的文字仍保留原生记录并报告，不能因新建文字功能而声称支持 MTEXT/全部样式。
- 对齐标注是非关联 LINE/TEXT，修改源轮廓或拆开编辑后需手动更新。默认参考角色使用应用 XData；其他软件删除扩展数据后可能无法保留默认角色。文字自身始终不切割，当前参考覆盖仍以项目为准。
- 几何剪贴板只适用于本应用格式，最多 50000 对象/64 MiB，保留解析几何及颜色/图层/角色，不是原生 CAD 剪贴板，不携带原生线型/线宽/字体等全部附属信息。目标同名层不改色，缺失层在同一事务创建；没有剪切命令或完整块关联复制。
- 孔模板首批仅圆孔和工作平面内长圆孔；阵列非关联，副本随环阵旋转。没有自动方管四面映射、完整尺寸约束或动态尺寸输入。绘图和测量功能仅完成构建，实际坐标、字体、DXF/项目往返和 NC 由用户验收。

## 项目文件边界

`.cadcam` 版本 1 内嵌原生 DXF、稳定身份及安排/工艺/参考范围，按来源身份回读检查后保存；支持范围见[项目文件格式](项目文件格式.md)。原生字节往返仍依赖解析库，身份/类型/单位检查不证明所有几何/附属记录无损。没有旧版本迁移、历史/工作平面持久化、压缩或项目自动恢复；现有恢复文件仍只包含 DXF。保存、打开及回读均同步执行，大图可能阻塞界面。

## 性能与验证

属性编辑已复用显示/加工离散和拓扑分析，但仍重建轨迹。几何编辑、读取、离散和 CAM 分析同步执行，绘制逐帧遍历，拾取和标签中心也有重复遍历。尚无经测量的大图性能基线、后台加载、静态 GPU 几何缓冲或专用拾取索引。

现有 3 项测试集中于局部 G-code 行为，不证明导入、拓扑、四轴和最终 NC 正确；严格 Clippy 尚未通过。验证快照和人工验收方法见[开发指南](开发指南.md)。

## 后续完善方向

优先补齐精确交互、输入完整性、加工公差与拓扑覆盖、参数/轨迹/导出一致性、运动安全和输出可检查性；性能优化先测量再选方案。开发需从触发动作验证到最终画布或输出文件，完成后同步移除或改写对应限制。
