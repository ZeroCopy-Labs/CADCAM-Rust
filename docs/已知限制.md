# 已知限制

[返回项目入口](../README.md) · [架构](架构.md) · [使用指南](使用指南.md) · [开发指南](开发指南.md)

按 2026-10-23 当前工作区源码整理。以下属于实现边界；对运行影响尚未做固定样本、GUI 或实机复现的内容，不视为已完成验证。本文不承诺后续实现时间。

## 输入与几何

| 当前行为 | 影响与边界 |
|---|---|
| 仅转换模型空间和六类几何，不展开 INSERT、块定义或图纸空间 | 能打开不代表加工所需几何完整 |
| 导入报告记录转换/跳过及警告，界面主要显示摘要和警告数 | 尚不能完整查看跳过原因，导出也不基于导入损失阻断 |
| 单位来自 INSUNITS，轨迹沿用原坐标，默认头为 G21 | 无统一换算，不自动阻断非毫米/未知单位；只改文件头不能修正所有几何和参数尺度 |
| 显示过滤非有限点，样条数据不足可回退控制多边形 | 可见折线不代表原曲线有效，控制点/节点/权重契约尚未完整校验 |
| 圆、椭圆、样条多用固定 64 段采样，CAM 继续使用显示折线 | 无独立加工公差曲线表示；`arc_tolerance` 只控制输出层语义圆弧展开 |
| 截面由闭合单元整体 YZ 包络和圆角估计，当前至多一个候选 | 自动采用不证明图纸符合方管假设，无任意轴向自动对齐或通用截面内核 |

## 拓扑与加工计划

- 连通组可含分支，节点度判定闭合不等于有效加工遍历。开放样条取控制点或拟合点首尾作为拓扑端点，不一定等于实际曲线端点。
- `ordered_unit_points` 从首条显示路径贪心连接，距离门槛为 `1.0`，不同于拓扑容差 `1e-3`。拼接失败可被轨迹构建直接跳过，尚无完整的计划单元覆盖/重复检查。
- 区间/组按 X 边界和单元 X 中心归属；边界去重、容差重叠和跨区间单元尚无独立验收，不能假定每个单元恰好加工一次。
- 手动指定断面只要求已有截面、单元闭合且有 X 范围，不执行自动候选同等的绕数/覆盖验证。
- 起点取自离散点，受采样影响；启发式顺序和入口评分无全局最优保证。
- 当前工作区整计划重建在非懒旋转模式跨组传递出口；手动重排仍只重算本组并从空前序状态开始，两者尚未统一为完整跨组连续性重算。
- 顺序、手动截面和断面指定只在内存，重开图纸会重新生成；无加工项目保存、撤销重做或几何编辑。

## 界面与状态

| 当前行为 | 使用及开发注意点 |
|---|---|
| 已有截面手动控件每帧从当前截面克隆局部值 | 无持久草稿，跨帧编辑及点击应用存在丢失风险，本轮未做 GUI 复现 |
| “清除/重新识别”执行清除及无截面回退 | 不自动重新拟合，需另行应用候选或手动输入 |
| 配置直接修改内存，运动参数通常保存/重载后重算 | 校验/导出可能组合旧轨迹与新配置，无独立已应用版本 |
| 换图纸及部分 CAM 操作不刷新已有文本预览 | 可能继续显示旧文本；刷新预览也不应用新运动参数 |
| 非法配置启动时保留文件但静默回退默认值，重载失败同样回退 | 提示不完整，主动保存仍可覆盖；有效配置启动时会重新序列化 |
| 只有轨迹统计及文本预览 | 无完整运动路径显示、刀具/夹具/机床仿真或碰撞检测 |

## 运动与输出

- 有截面安全 Z 取 Y/Z 单轴最大偏移加间隙，未计算完整绕 X 径向包络，也未完整考虑加工 Z 偏移等因素，不能作为无干涉证明。
- 同区且同 A 角离面距离默认为 0，会在表面快速转移；正离面的局部抬刀也无全程碰撞校验。
- 基础校验只检查部分数值、空范围、切削段及单元内相邻快速段的 A 变化，不检查完整连续性、跨单元边界、行程、A 极限、夹具或刀具包络。
- 初始及返回位置在文本层追加，不在统一轨迹校验内；程序实际启动姿态也不是已知输入。
- `arc_cut_info` 按旋转后法向最大分量选择主平面，未严格要求曲线与平面对齐。方向和控制器平面约定需固定样本验证，不能保证任意倾斜圆弧正确输出。
- 无截面回退使用原 XYZ 和固定 A，不应用加工 Z 偏移及过切。进给为统一 F 值，未建模机床专用进给模式及完整后处理。
- 自定义头尾可改变模态或运动状态，基础校验不解析这些代码，也不解析最终 NC。
- 快速导出依赖工作目录并覆盖同名文件；两个入口均导出完整计划，无仅导出所选单元功能。

## 性能与验证

读取、离散和 CAM 分析同步执行，绘制逐帧遍历，拾取和标签中心也有重复遍历。尚无经测量的大图性能基线、后台加载、静态 GPU 几何缓冲或专用拾取索引。

现有 3 项测试集中于局部 G-code 行为，不证明导入、拓扑、四轴和最终 NC 正确；严格 Clippy 尚未通过。验证快照和人工验收方法见[开发指南](开发指南.md)。

## 后续完善方向

优先补齐输入完整性与单位、加工公差与拓扑覆盖、参数/轨迹/预览一致性、运动安全和输出可检查性；性能优化先测量再选方案。开发需从触发动作验证到最终画布或输出文件，完成后同步移除或改写对应限制。
