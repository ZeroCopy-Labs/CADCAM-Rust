## 第一批：点击式夹点编辑

操作顺序：选择图元 → 点击夹点 → 松开鼠标 → 移动鼠标或输入 → 再次点击或 Enter 提交。

- 第一次点击只激活夹点，释放鼠标不提交；鼠标移动只更新临时预览。
- 输入完整坐标后，可点击或 Enter 确认，不增加额外确认步骤。
- Esc 取消当前未提交修改并保留对象选择，再次 Esc 清除选择。
- 侧栏、底部控件和画布外的点击不作为目标点，不意外提交；焦点切换保留输入。
- 直线端点、圆和圆弧、椭圆、多段线顶点、已有样条控制点和文字插入点共用同一流程。
- 保留属性面板输入固定目标后预览、确认的入口。
- 移除夹点的按住拖动及释放提交分支，同步界面提示与使用说明。

本批不新增夹点类型，也不修改夹点的几何含义。直线中点在第二批实现；夹点模式切换在第三批实现，第一批 Enter/Space 沿用确认语义。

2026-10-26 实施记录：移除 Step::Grip 的 dragging 字段与画布释放事件提交分支，首次拾取后返回，后续按下才确认目标；属性入口可保留固定预览或通过画布点击替换目标后提交。两入口统一清除旧字段锁定并请求输入焦点。完成源码流与文档静态核对及 `cargo build --workspace --offline`；未运行 GUI、功能测试或文件/加工验收。上一轮第十三批改动仍保留在工作区，本次未执行 Git 提交。

输入与输出路径：画布夹点拾取/属性入口 → CommandState 夹点步骤 → 共用坐标、捕捉与约束 → 临时解析几何预览 → 最终确认 → 原生文档事务 → 显示与 CAM 更新。每次提交可整次撤销，取消不改变图纸。

第一批人工验收清单（待用户执行）：

1. 选择直线，点击端点并松开；移动鼠标时只有预览变化，第二次点击才写入。即使按住移动后释放，也不因释放而提交。
2. 点击夹点后分别在光标和底部输入 `#10,20,30`、`@0,20,0`，使用 Enter 或画布点击确认；显式坐标不被点击位置覆盖，非法坐标不提交。
3. 输入或预览期间点击侧栏、底部开关或移出窗口后释放，不能写入；回画布后仍可继续指定目标或取消。
4. Esc 取消当前预览，原图元与选择保持；再次 Esc 清除选择。一次成功修改只生成一次历史，撤销/重做恢复对应几何。
5. 圆心/半径、圆弧端点、椭圆轴、多段线顶点、可编辑样条控制点及文字插入点重复上述流程；保留原有共面性、半径等几何检查。
6. 属性面板选择夹点并指定目标后，仍可预览、改输入或重新点击目标后一次提交；锁定层失败不产生部分修改。图纸保存、DXF、CAM 结果由用户验收。

## 第二批：夹点覆盖与明确语义

- 直线增加中点夹点：中点平移整条直线，保持长度和方向；端点只修改对应端点。
- 圆心平移圆，四个象限夹点调整半径且保持圆心。
- 圆弧圆心、端点、弧中点分别明确整体移动、端点调整和形状调整；弧中点不能仅用半径修改冒充形状调整。
- 多段线顶点调整相邻段；椭圆轴端点与样条控制点沿用已有原生几何能力。
- 区分普通、悬停和激活夹点；增加操作提示，按 DPI 校准显示和拾取尺寸。

## 第三批：精确输入与夹点模式

- 移动显示位移/方向，半径显示实际半径，端点编辑区分位移和最终长度。
- 光标、底部命令行和预览使用相同参数与坐标含义，配合捕捉、正交、极轴和工作平面。
- 夹点快捷菜单首先提供拉伸、移动、复制和重新指定基点。
- 单独处理夹点状态的快捷键：有输入时提交参数，无输入时按支持的夹点模式切换；不复用普通命令的空确认规则。
- 示例：直线 `(0,0,0)` 至 `(100,0,0)`，中点夹点输入 `@0,20,0` 时整体上移 20；端点夹点输入相同位移只移动该端点。

## 第四批：底部状态与设置

- 顶部启动常用命令；侧栏保留特性、图层及复杂参数；底部命令行显示步骤、选项和错误。
- 最底部状态栏集中坐标、工作平面、对象捕捉、栅格、正交、极轴和动态输入。
- 捕捉类型、栅格间距和极轴角度从对应状态按钮的菜单设置。
- 窄窗口采用溢出菜单，尽量保持状态栏单行，避免自动换行挤占画布。

## 第五批：实时鼠标坐标

- 默认在底部状态栏左侧显示 X/Y/Z，使用等宽数字和固定空间。
- 空闲显示鼠标射线与当前工作平面的交点；取点时显示经过捕捉和约束的实际候选点。
- 标注 WCS 或工作平面坐标，支持切换查看；数值与实际取点共用坐标转换。
- 鼠标离开画布或射线无法求交时显示 `—`，不沿用失效坐标。
- 小框只读、不抢焦点；鼠标旁的动态输入继续承担命令输入。

## 第六批：整体交互收尾

- 统一十字光标、拾取框、选择高亮、夹点和预览样式。
- 夹点操作出现在对应快捷菜单，底部提示统一使用选择对象、指定基点、指定目标点等明确措辞。
- 核对多选时夹点的显示、拾取和重叠处理；批量移动保持共同位移。
- 核对面板收起、窄窗口、高 DPI、CAD/CAM 切换后的画布范围、输入焦点及控件穿透。
- 同步文档和整轮人工验收清单，完成完整构建。
