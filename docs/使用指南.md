# 使用指南

## 打开图纸

通过“文件 → 打开图纸或项目”、最近打开列表或启动参数打开 DXF/DWG/`.cadcam` 项目。对话框优先使用最近文件所在目录，无可用目录时尝试用户桌面，再回退到进程工作目录。最近文件保留最多 10 项。

支持模型空间中的 LINE、可转换的 POLYLINE/LWPOLYLINE、CIRCLE、ARC、ELLIPSE、SPLINE 及基础单行 TEXT。基础几何 INSERT 在导入阶段按下述规则展开；块定义不直接参与加工，图纸空间、MTEXT/复杂文字、原生 DIMENSION、填充和实体建模对象等暂不转换；支持的 TEXT 用于显示/编辑，始终不生成切割轮廓。拟合多段线和网格也会列入未转换报告。窗口上方显示文件名，底部消息显示实体/图层/单元数、格式、版本及单位。“文件 → 导入报告”显示打开时的解析后图元总数、模型空间数量、转换类型/数量、跳过样本的类型/图层/句柄/原因和警告；跳过样本最多 256 个，另列省略数量。存在警告或跳过对象时自动打开报告，后续编辑不改写打开时的报告。读取和加工计算在后台进行，底部提供阶段与取消；当前图纸保留到候选成功并通过未保存确认后才替换。

### 块导入、展开与 DXF 保存

首批以独立图元实现块支持：打开时递归展开模型空间中可处理的 INSERT，覆盖块基点、插入点、OCS 法向、旋转、正/负缩放、非均匀缩放及 MINSERT 行列阵列。嵌套块先在自己的坐标内求出叶图元，再应用各级变换，避免把带非均匀缩放的嵌套关系压成一个失真的 INSERT。

块内支持已有六类线框几何和本节支持范围内的基础 TEXT。多段线展开为独立直线/圆弧段；圆及圆弧经非均匀变换可能成为椭圆/椭圆弧，仍保存解析曲线。数值上仍为圆的结果恢复为圆/圆弧。源单位在展开完成后统一换算为工作区毫米，DXF 原生记录仍使用源单位。

图层 `0` 继承实例有效图层，ByBlock 颜色继承实例有效颜色；实例的 ByLayer 颜色按其有效层解析，避免子对象自有图层改变继承颜色。展开后的 G-code 规则按实际图元类型、图层和颜色匹配，因此原 ByBlock 颜色可能变为具体 ACI/RGB。实体不可见标记和实例隐藏状态会保留到展开对象；隐藏仍不作为 CAM 排除条件。

成功展开后，仅移除该模型空间源 INSERT，保留原块定义，输出的独立实体获得新原生句柄。导入报告列出原始 INSERT 路径、阵列行列（从 0 开始）、源叶实体句柄/段号与新句柄的映射；图元信息显示当前原生句柄，便于对照。映射最多列 2048 条，另计省略数。映射是本次导入的追溯信息，不代表持久块实例关系，也不写入 DXF 作为永久关联。

展开在内存中完成，不直接覆盖原文件；图纸会标记为未保存，保存/另存为后写出展开的实体。块级参数编辑、属性、约束、阵列联动和父块锁定关系不再保留，编辑权限按独立对象所属层判断；不可见标记暂没有单独解除控件。重新打开已展开的 DXF 时，它们就是普通图元。

以下实例保留原生 INSERT、不部分展开：引用缺失/循环、超过 24 层、外部参照或禁止分解、带实例属性、含暂不支持的复杂文字/原生标注/填充等类型、带宽度/挤出厚度/拟合标记的块内几何，以及变换后无法转换的对象。遍历/展开有 100000 工作量及实体预算；失败样本最多列 256 个，另计省略数。报告说明完整实例未进入当前加工模型；DXF 仍保留它及原定义，显示及加工不会假装含有这些对象。

### 导出前确认加工范围

导入报告有未转换对象、块展开失败，或解析器跳过记录/发生恢复/未完整读流时，两个 G-code 导出入口均先暂停并打开报告。检查提示后勾选“我已核对遗漏，允许仅导出当前已转换图元的加工代码”，再重新导出。仅关闭报告不确认范围。解析跳过记录可能涉及非切割数据，程序不代替用户判断用途。

确认只允许输出当前已转换子集，不会补回缺失几何；采样和轨迹错误仍会阻止输出。确认绑定当前会话图纸，打开/替换图纸及几何编辑、撤销/重做后需重新核对，不随 DXF 或恢复快照保存。只有未使用块定义或图纸空间计数时不因此要求该确认。DXF 保存仍受解析库往返范围限制，解析期已丢失的记录不能靠保存补回。

### 单位

工作区的坐标、移动量、截面尺寸、长度容差和 G-code 长度参数统一使用毫米。源 DXF/DWG 单位来自 INSUNITS；例如源图纸中 `1 in` 的长度在工作区显示为 `25.4 mm`。曲线的坐标、半径和椭圆轴长换算，角度、法向、节点参数和权重不乘长度比例。

原生文档保留源坐标和源单位，三维平移从毫米换回源单位再写入；保存/导出 DXF 仍使用源单位，避免重复换算或改动尚未显示的源记录。源单位和工作单位同时显示。无单位或未知单位图纸在打开时询问：是＝毫米，否＝英寸，取消＝停止打开并保留当前图纸；用户指定的单位在保存 DXF 时写入 INSUNITS，并计入未保存状态。新建图纸使用毫米。

G-code 轨迹使用毫米，默认文件头为 `G21`；自定义头尾原样输出，使用者应保持与毫米轨迹一致，程序尚不解析自定义模态指令。旧配置参数不根据图纸源单位再次缩放。

### 新建、保存与关闭

| 操作 | 入口与行为 |
|---|---|
| 新建图纸 | 文件菜单或 Ctrl+N，创建空白毫米文档；使用顶部“默认 → 绘图”或绘图菜单添加图元 |
| 打开图纸 | 文件菜单或 Ctrl+O；也可选择 `.bak` 备份恢复 |
| 保存当前文件 | Ctrl+S：已进入项目时保存 `.cadcam`，普通图纸会话保存 DXF；未命名、DWG 来源或恢复图纸选择路径 |
| 保存项目 / 项目另存为 | 文件菜单，保存图纸、加工安排及配置快照；不覆盖源 DXF 或全局配置 |
| 保存 DXF 图纸 | 文件菜单“保存 DXF 图纸（不含加工安排）”，项目会话也可单独保存源图纸 |
| 另存为 | Ctrl+Shift+S 跟随当前文件类型：项目会话为项目另存，普通图纸为 DXF 另存；菜单可明确选择项目或 DXF |
| 关闭图纸 / 退出 | 文件菜单或窗口关闭按钮；有未保存图纸或项目修改时提供保存、放弃、取消 |

快捷键在没有文本输入焦点、G-code 配置或导入报告弹窗时生效。保存对话框取消、写入失败或打开失败均保留当前图纸；只有成功写入才更新保存版本。DXF 只保存图纸；需要保留加工安排时使用下述项目保存。

保存和导出先完成序列化，再写同目录临时文件、同步并替换目标。覆盖已有文件时，将覆盖前内容保存在 `<文件名>.bak`；备份或目标替换失败会报告错误。可通过“打开文件”选择 `.bak`，作为待另存的恢复图纸打开，不直接写回该备份。图纸输出要求 `.dxf` 扩展名；项目输出要求 `.cadcam` 扩展名，项目备份为 `.cadcam.bak`。

### CAD/CAM 项目保存

使用“文件 → 保存 CAD/CAM 项目…”生成 `.cadcam` 文件。它内嵌当前原生图纸及单位、稳定图元/图层身份、断面指定/取消、显式端面配对、修边、手动顺序、截面与懒旋转策略、待处理安排、工艺配置及参考对象范围。文件自带格式版本，打开后重新生成显示、采样、分组、起点和轨迹，不依赖源 DXF 仍在原位置。

打开项目会采用内嵌工艺，与打开前会话配置不同会提示；不覆盖全局 `gcode.toml`。来源文件不存在会提示，继续使用内嵌图纸。格式/版本、解析或身份不匹配会停止打开并保留当前工作。打开项目及备份后，导入遗漏仍需重新核对；范围确认不写入项目。

项目名后的 `*` 表示图纸、来源路径、加工安排、范围或工艺相对项目保存点有变更。没有项目时，已修改的加工安排/工艺另有黄色提示。新建、打开、关闭或退出会处理未保存项目；保存失败或取消不丢弃当前工作。DXF 保存点与项目保存点独立，保存 DXF 不能清除项目中的安排/工艺修改，项目保存也不证明外部 DXF 已更新。

项目不保存撤销历史、当前选择、工作平面/捕捉草稿、相机或未确认几何预览；重开从新的编辑历史开始。现有自动恢复仍是 DXF 图纸快照，不包含未保存的 CAM 修改；干净项目不重复生成恢复快照。存储采用内嵌 DXF 字节的 Base64 和 JSON，实际边界见[项目文件格式](项目文件格式.md)。

### 自动恢复快照

未保存图纸在首次修改后的更新周期写入一次快照，之后存在版本变化时最多每 30 秒更新一次，位置为 `%LOCALAPPDATA%\CADCAM-Rust\Recovery`，不可用时按 APPDATA/当前目录回退。每个会话使用独立文件名；快照不改变保存标记或源路径。正常保存、放弃当前图纸或正常退出时清理本会话快照；异常退出后的文件通过“文件 → 恢复图纸快照…”打开，启动发现现存快照时会提示入口。

恢复后必须另存为 DXF。快照只包含原生图纸及单位，不包含撤销/重做历史和 CAM 人工安排；最近尚未写入快照的修改无法恢复。恢复写入仍在主线程，大图可能短暂停顿。旧的恢复来源文件不会因打开而自动删除。

## 后台计算与性能记录

底部任务栏显示读取、显示离散、加工采样、拓扑、分析和轨迹阶段，提供取消、重算当前加工及性能记录入口。取消撤销结果应用资格，当前第三方解析/计算阶段结束后才释放资源；不会强行终止线程。后台使用独立候选或不可变快照，只有对应当前会话与输入版本的结果才能生效。

几何编辑后 CAD 显示先更新，CAM 分析在后台跟进；待计算时 CAM 操作和旧编号暂停，CAD 仍可编辑。连续修改只保留最新等待请求，旧结果丢弃。配置输入变化会使旧轨迹失效，关闭/保存/校验配置时触发重算。

导出、快速导出、校验和轨迹查看在需要时等待计算后自动继续；项目保存需要当前分析时也会等待，保存成功后才继续此前的新建、关闭、退出或文件切换。取消、失败和期间修改输入会取消对应后续动作。加载完成时若有未确认 CAD 命令则等待命令结束，提交新输入会丢弃原候选，避免覆盖新编辑。

“视图 → 性能记录…”列出最近实际操作的 CPU 毫秒耗时、拾取候选/总段数、过期丢弃数及路径点数组容量，可复制记录。不是自动基准：点容量不含原生文档/历史/临时快照/索引/GPU，不是进程内存；绘制是 CPU 提交，不是 GPU 时间或 FPS。记录与验收方法见[性能与后台任务](性能与后台任务.md)。

画布使用面板之外的实际区域，适应视图、投影拾取和浮动原点沿用同一视口；系统缩放系数用于物理视口换算。侧栏和底栏尺寸变化会使投影缓存更新。读取/加工计算已后台化，核心编辑、编辑显示离散、文件写出及恢复仍有同步工作，大图不保证完全无停顿。

## CAD 默认功能区与面板

CAD 模式顶部增加“默认”功能区：绘图、修改、图层、特性、实用工具。按钮使用线条图标加中文文字，悬停显示命令名；窗口可用逻辑宽度小于 1020 时改为紧凑下拉菜单，不挤压成横向滚动条。原有文件、绘图、编辑、视图和 G 代码入口保留。

- 绘图提供直线、多段线、圆、圆弧、矩形、椭圆；下拉还有样条与孔模板。
- 修改提供常用变换、删除和曲线工具；常用曲线工具和删除均可先启动。修剪/延伸先选择边界，偏移/圆角/倒角先输入尺寸；悬停预览，最终点击或输入确认直接提交。右侧保留批量参数方式。
- 图层下拉显示颜色块、隐藏/锁定状态；无选择时设置当前图层，有选择时修改整批对象的所属图层。显示与锁定按钮作用于当前展示的那个图层，混合层时不提供这两个快捷修改；通过“图层管理”统一管理。
- 特性快捷颜色支持随层、随块与常用 RGB；无选择时修改新图元颜色，有选择时修改整批对象颜色。任意 RGB 与 ACI 在详细特性中设置。不同颜色/图层的多选显示“多个值”，锁定层限制和撤销沿用原事务。
- 实用工具提供距离、角度、坐标测量，及“所选曲线长度 / 半径”。文字与标注保留在下拉菜单，尚无专用注释/块面板。

右侧面板分为“特性 / 图层 / 工具”。“特性”显示选择属性与长度；“工具”包含当前命令参数、绘图辅助、曲线整理、选择过滤及图纸检查。点击“特性面板”或“收起 ×”可收起，通过顶部按钮重新打开。加工定位和参考对象设置位于“加工关联与范围”折叠项。CAM 保留左侧布局。

底部状态栏集中提供对象捕捉 F3、栅格 F7、栅格捕捉 F9、正交 F8、极轴 F10 与工作平面入口。鼠标旁动态输入已加入，可用 F12 或状态栏开关切换；常用命令的确认次数和选择习惯已按下文统一。进度见 [CAD 交互改造计划](CAD交互改造计划.md)。

| 操作 | 行为 |
|---|---|

| Shift + 中键拖动 | 旋转视角 |
| 滚轮 | 以鼠标位置为中心正交缩放 |
| “视图”菜单 | 适应视图、等轴测、俯视图、前视图 |
| 右上角视角魔方 | 点击可见面切换预设方向 |
| 左键点选 | CAD 默认追加当前橙色预选对象；重叠候选按屏幕距离、深度排序 |
| Shift + 左键/框选 | CAD 从选择集中移除；CAM 追加选择 |
| Alt + 左键/框选 | 从当前选择移除 |
| Ctrl + 左键/框选（CAD） | 切换命中对象的选中状态 |

| 从右向左框选 | 绿色“交叉”，选择与框相交的对象 |
| CAD/CAM 开关 | 在图元和加工单元选择语义间映射 |

CAD 模式按图元选择，CAM 模式按整个加工单元选择。CAM 保留图元原色，选中单元黄色高亮。CAD 右侧“特性”面板显示对象属性与几何信息；CAM 左侧“特征”面板显示成员、区位及加工断面信息，多选以折叠项展示。

CAD 悬停对象为橙色，已选对象为黄色；光标旁显示图元类型、图层及候选序号。光标动态字段获得焦点时，Tab/Shift+Tab 切换字段；空闲命令输入中 Tab 补全命令。其他情况下，Tab 在存在捕捉/预选候选时循环，没有候选时保留界面焦点导航。右侧“特性面板 → 工具 → 选择方式与过滤”提供替换、追加、移除、切换四种方式，修饰键优先级为 Ctrl、Alt、Shift，再使用面板方式。CAD 默认追加、Shift/Alt 移除、Ctrl 切换；CAM 的 Shift 追加和 Ctrl 点击重排保持原行为。

类型、图层和颜色属性过滤应用到后续点选、框选和 Ctrl+A；颜色按图元的随层/ACI/RGB 等属性匹配。改变过滤不自动移除已选对象，“反选过滤范围”只翻转符合当前过滤的对象，“清除过滤”恢复全部。成功换图后重置过滤。过滤不改变几何捕捉范围，画面中可见的其他对象仍可作为取点参考。

世界坐标轴固定在 CAD 原点，正半轴实线、负半轴虚线；CAD 工作区另有工作平面边框和 U/V/N 轴。底部命令栏固定显示操作提示和输入框；“展开历史”可查看最近最多 4 行消息，“收起历史”恢复紧凑布局。点击画布不再收起命令栏；可用鼠标取点或在底部输入坐标。

## 精确移动与工作平面

### 基点与目标点移动

入口为“编辑 → 基点 → 目标点移动”、Ctrl+M、顶部“默认 → 修改 → 移动”，或在命令栏输入 `MOVE`、`M`、`移动`。

1. 已有选择时直接指定基点；未选择时先点选/框选，默认追加，Shift 移除或 Ctrl+A 全选，再按 Enter 或“确认选择”。
2. 在画布点选基点，或在命令栏输入坐标后按 Enter。基点确定后冻结本批选择。
3. 移动鼠标显示青色平移预览，橙色线表示基点到目标点；点击目标点或输入目标坐标并确认后直接完成批量平移，不再多按一次 Enter。成功后可一次撤销/重做；零位移不增加历史。

Esc 或“取消”结束命令，不修改图纸和历史。非法坐标保留在输入框供修改；提交失败保留预览。命令进行中暂时禁用其他 CAD 编辑、直接保存和 DXF/G-code 导出；可以先完成或取消。切换 CAD/CAM 工作区取消未确认命令；成功新建、打开或关闭图纸时重置命令和工作平面。

鼠标优先取启用的几何捕捉点，没有候选时取当前工作平面上的交点，再按辅助开关处理。数值输入按下面的坐标约定处理，可离开工作平面且不受捕捉/方向辅助约束。原有“三维偏移”按钮仍按输入的毫米偏移直接提交，不经过交互取点步骤。

### 确认、取消与右键菜单

CAD 命令输入框中 Enter/Space 确认当前输入，连续修改等待目标时结束命令，空闲时重复上一命令；其他文字编辑框中的空格与编辑快捷键保持文字行为。完整空格分隔坐标仍可粘贴后 Enter。Esc 先取消当前输入/操作，连续绘图保存有效已取点部分，连续修改保留已经提交的结果；空闲且没有输入时再按 Esc 清除选择。

画布右键打开当前命令选项：确认/结束、连续绘图 U/C、取消或放弃整次未提交绘图；空闲时提供重复、撤销、重做及移动/复制/删除。菜单外点击只关闭菜单。删除可 E/ERASE 后选对象并确认，也可先选对象再 E；UCS 可 UCS+Space 后输入 XY/YZ/ZX/3P。

### 坐标输入

以下表格以底部命令行为准；光标输入的后续点默认相对，见下一节。

所有长度为毫米，角度为度，数值允许小数、负数和科学计数法。键入 Space 用于确认，坐标建议用逗号分隔；空格分隔的完整表达式可整体粘贴后 Enter。不能输入 NaN/Infinity。指定方向后的单个距离值沿当前基点到鼠标预览方向取点。

| 输入 | 含义 |
|---|---|
| `20,0,5` 或 `W:20,0,5` | WCS 绝对三维坐标，不受工作平面方向影响 |
| `20,5` | 工作平面内绝对 U/V 坐标，法向坐标 N＝0 |
| `@10,0,5` | 从参考点沿 WCS 增加 ΔX/ΔY/ΔZ |
| `@10,5` | 从参考点沿当前工作平面 U/V 增加位移，保留参考点的法向位置 |
| `@10<45` | 从参考点沿工作平面移动 10 mm，方向为从 +U 朝 +V 的 45° |

移动目标点的参考点为基点；指定第一个基点时参考点为当前工作平面原点。三点定义中，第一点相对当前平面原点，第二、第三点相对新平面的第一点。相对输入不累积到上一次预览目标。

例如在 XY 工作平面输入基点 `0,0,0`、目标 `@10,0,0`，再 Enter 确认，即沿世界 +X 移动 10 mm；在 YZ 平面输入目标 `@10,0` 则沿世界 +Y 移动 10 mm。

### 鼠标旁动态输入

在 CAD 画布上直接键入 `L`、`C`、`M`、`CO`、`RO`、`SC`、`MI`、`DI`、`TR`、`EX` 等常用别名，光标附近显示命令输入和最多五个候选；方向键选择、Tab 补全、Enter 执行。完整命令名和别名也可在底部输入。删除和常用图形化曲线工具均支持先启动再选择。

命令取点时显示 X/Y/Z，后续点默认显示工作平面内的长度与角度，可切换为三维坐标位移；画圆和半径夹点显示半径，旋转/缩放取基点后显示角度/比例，R 参照流程显示原角度/长度及新方向/长度；矩形阵列显示列/行数，环形阵列显示数量。空字段用提示值显示鼠标与捕捉点的位置，输入数值后标为“锁”；Tab/Shift+Tab 切换字段，坐标字段也可用逗号切换。未锁字段继续跟随鼠标，锁定值约束青色预览及最终取点；悬停输入框和修改数字期间保留最后有效几何点。删除字段内容可解除该字段锁定，“清除尺寸锁定”清除全部锁定。切换坐标/长度角度表示方式会清除锁定。

- 光标坐标字段的首点是 WCS 绝对 X/Y/Z；后续三维坐标字段是相对基点的 WCS 位移。长度/角度沿当前工作平面 U/V 计算，半径和长度单位为 mm，角度单位为度。
- 在光标旁输入 `#10,20,30` 明确指定 WCS 绝对点，`@10,20,30` 为 WCS 位移；二维 `#10,20` 为工作平面绝对 U/V，`@10,20` 为平面位移。直接键入 `@` 或 `#` 会进入完整表达式输入。
- 光标完整表达式中的后续点默认相对基点，如 `10,20` 与 `10<30`；首点默认绝对。底部命令行不带前缀仍默认绝对；`@10<30` 明确为相对极坐标，不带 @ 的极坐标以工作平面原点为基准。
- 两处共享同一输入草稿。点击底部即可继续编辑；光标提示中的“切换到光标输入”可切回。切换时会补上必要的 #/@，避免改变坐标含义。底部始终显示完整操作提示和错误；文字控件中的复制粘贴保留文本行为。
- F12/状态栏开关可关闭或启用动态输入，关闭后仍可使用底部命令行。浮层靠近画布边缘换侧；画布不足 340×260 逻辑像素或无法避让光标时转到底部输入。

圆半径及其他定点图元最后一个必要输入确认后直接提交。命令输入框中 Space 与 Enter 同样确认；连续绘图的 Esc 保留有效已取点部分，空闲 Enter/Space 重复上一命令。详见 [交互改造计划](CAD交互改造计划.md)。

### 工作平面

底部工作平面菜单、右侧工具页或命令 `UCS XY`、`UCS YZ`、`UCS ZX` 切换方向并保留原点。三种平面的 U/V 分别对应世界 X/Y、Y/Z、Z/X。可在右侧工具页输入有限的 WCS 原点并点击设置。平面边框只表示取点方向和位置，不是新增 CAD 图元，也不限制可输入坐标的范围。

`UCS 3P` 或“三点平面”按原点、+U 方向点、+V 一侧点依次取点；第三点不要求与 +U 垂直，程序建立正交坐标系。三点共线、重合或数值无效时保留原平面并提示；完成第三点后应用，Esc 在完成前取消。可输入三个 WCS 点，或捕捉三个空间几何特征来建立倾斜平面；没有几何候选时鼠标点仍位于原工作平面。

平面原点、方向及当前取点坐标显示在右侧工具页；U 红、V 蓝、N 绿。平面固定在图纸坐标中，旋转相机不改变它。视线近乎平行、平面在视线后方或交点无效时暂停鼠标取点，可以调整视角或输入坐标。工作平面只保留在当前会话，不随 DXF 或恢复快照保存。

命令栏另外支持 `UNDO` / `U` / `撤销` 和 `REDO` / `重做`，与现有历史入口相同。输入框拥有焦点时，Ctrl+Z/Ctrl+Y 仍编辑文本；Esc 可取消活动命令。图纸、捕捉、平面及相机目标坐标使用 f64；渲染前先减去视图原点再转成 f32，鼠标射线反向转换回 WCS。此变换只影响显示，不平移原图或 CAM；仍受 f64 本身、相机及显示离散的精度范围限制。

### 几何捕捉与绘图辅助

右侧“工具 → 捕捉与绘图辅助”设置捕捉类型和方向辅助；状态行显示当前开关。默认开启端点、中点、中心、象限点和真实交点；最近点、垂足、切点、投影及方向/网格辅助默认关闭。

| 功能 | 当前支持 |
|---|---|
| 端点/中点 | 直线、圆弧及多段线各段；部分椭圆的端点/参数中点；有效开放样条的求值端点。完整圆/椭圆没有独立端点，样条不提供伪装为弧长中点的参数中点 |
| 中心/象限点 | 圆、圆弧、椭圆；多段线内圆弧也可提供圆心和范围内象限点 |
| 最近点 | 直线解析求解；圆弧、椭圆及有效 NURBS 样条采用参数搜索与局部细化，复杂样条不保证全局最近点 |
| 真实交点 | 直线—直线、直线—圆/圆弧及共面圆/圆弧组合，含多段线段与自交；按约 `1e-6 mm` 空间容差判断，不将异面投影相交当作交点 |
| 垂足/切点 | 有已确定的基点、绘图前一点或平面定义参考点时，支持直线垂足、圆/圆弧垂足及共面外部参考点的圆/圆弧切点；只提供源段范围内的点 |

捕捉在光标附近 12 像素内寻找候选，绿色方框显示种类及候选序号。取点时 Tab/Shift+Tab 循环候选，确认坐标仍来自原几何。交点最多处理当前 24 个邻近图元，超出时在工具页提示；椭圆/样条交点、异面圆—圆交点尚未实现。捕捉点在约 `1e-6 mm` 内去重。

默认使用捕捉点的真实 WCS 坐标，允许其不在当前工作平面；勾选“将捕捉点投影到工作平面”后才沿平面法向投影，标记增加“投影”前缀。投影捕捉与真实空间交点分开处理，未实现单独的“屏幕表观交点”功能。

| 快捷键 | 行为 |
|---|---|
| F3 | 几何捕捉开关 |
| F7 | 显示当前工作平面的网格 |
| F8 | 正交方向约束，启用时关闭极轴 |
| F9 | 网格捕捉，默认间距 10 mm，可修改 |
| F10 | 极轴方向约束，默认角度增量 15°，启用时关闭正交 |

优先级为几何捕捉、正交/极轴、网格、自由取点。方向约束以已确定的参考点为基准，沿平面 U/V 方向保持参考点的法向位置；命中几何捕捉时不再移动该精确点。方向约束生效时不强行同时满足网格。缩小时网格可能以间距的整数倍稀疏显示，实际网格捕捉仍使用所设间距。

快捷键不抢占其他文本控件。命令坐标框为空时也可切换辅助、循环候选；有文字时保留文本导航。辅助和过滤只保留在当前会话，不写入 DXF 或 CAM。

## 基础绘图与批量变换

在 CAD 工作区打开或新建图纸，从顶部默认功能区、“绘图”“编辑”菜单或命令栏启动。右侧“特性/工具”页的“新图元属性”显示当前图层，可预选随层/随块/ACI/RGB 颜色及样条次数；命令开始后冻结这些设置。新图元使用原生文档当前层，可在“图层管理”切换；新图纸默认当前层为 `0`，打开图纸沿用源文件当前层。当前层隐藏或锁定时须先切换、显示或解锁。

### 绘图命令

| 命令 | 取点及结果 |
|---|---|
| `LINE` / `L` | 连续取点，每相邻两点生成独立直线；可输入任意 WCS 三维点 |
| `PLINE` / `PL` | 连续取点生成一个平面多段线，本批只新增直线段 |
| `RECTANGLE` / `RECT` | 两个对角点，边沿当前平面 U/V，生成闭合多段线 |
| `CIRCLE` | 圆心、半径点；取圆心后也可直接输入正半径，如 `5` |
| `ARC` | 起点、经过点、终点；三点不能共线，方向经过中间点 |
| `ELLIPSE` | 中心、长半轴端点、短半轴参考点；第三点取垂直长轴的距离，也可直接输入正短半轴长度，不能超过长半轴 |
| `SPLINE` | 控制点样条，开始前选择 1～5 次，至少次数加一的控制点；不将取点解释为拟合点 |

所有工具复用坐标输入、捕捉及方向辅助。除 LINE 外在当前工作平面内绘制，空间捕捉点不共面时提示错误，可先建三点平面或显式开启投影捕捉。绘图相对坐标的参考点是前一个已取点，首点相对工作平面原点。

圆、矩形、三点圆弧和椭圆取齐必要点或数值后直接写入。连续直线、多段线和样条用 Enter/Space/“结束取点”结束并提交；`C` / `CLOSE` /“闭合”闭合并提交。`U` / `UNDO` /“撤回一点”只撤回本次草稿中的一个点，不撤销正式文档。

闭合直线/多段线至少需要三个点。样条采用夹持均匀节点；闭合仅让首尾控制点重合，非周期样条，不保证连接处切向平滑。圆弧、椭圆和样条保存原生曲线，不用青色显示折线代替 DXF 几何。Esc 保留已经取点且能成形的部分，未确认的鼠标预览不写入；点数不足则取消。右键“放弃整次未提交绘图”可明确丢弃全部草稿。结束后自动选中新对象，一次撤销整个命令；尚未结束的草稿不写入自动恢复快照。

### 变换命令

混合批量选择后启动；没有选择时先选择并按 Enter。COPY 固定“源选择 → 基点”，每个目标点直接提交一批副本并继续取下一目标；M 多次（默认）、S 单次后结束；旋转取基点后可移动鼠标取角度或输入数值，缩放可直接输入比例或用 R 定义参照长度；镜像依次点选轴线两点并回答是否替换源对象。阵列在右侧工具页设置参数后 Enter/Space 提交。每次提交前的预览不修改原图；Esc 丢弃当前预览，连续复制中已完成副本保留；每次提交只占一条历史。创建副本时选中新结果；替换源对象时保留原对象身份、图层和颜色。

| 命令 | 参数与方向 |
|---|---|
| `COPY` / `CO` / `复制` | 依固定原基点/每次目标点的 WCS 差值连续生成副本，原件保留；M/S 切换多次/单次 |
| `ROTATE` | 绕经过基点的轴旋转，默认轴为当前工作平面法向，正角遵循右手方向；固定基点后鼠标方向或输入值为旋转增量，R 可改为参照旋转 |
| `SCALE` | 围绕基点正数统一缩放；固定基点后输入比例，或 R 用原长度与新长度求比例，不提供非均匀或负比例缩放 |
| `MIRROR` | 默认点选镜像轴两点，镜像平面由轴线的工作平面内方向与 N 张成；高级设置可改用工作平面或自定义法向 |
| `ARRAYRECT` | U 方向为列、V 方向为行；设置行列数及毫米间距，基点用于完成取点确认，阵列方向固定为当前平面 |
| `ARRAYPOLAR` | 绕经过基点的轴按总角度分布，默认 360° 整圆和当前工作平面法向，副本自身也随阵列旋转 |

旋转和环阵可设置三维轴向量；镜像可设置三维镜像平面法向，均由基点确定位置。旋转/缩放可勾选“保留原件并创建副本”或输入 C 切换；镜像在末步输入 N/Enter 保留源对象，Y 将源对象替换为镜像结果；阵列固定保留原件，行列数或环阵数量均包含原件。单次最多新增或变换 50000 个图元，超限整批拒绝，不做部分提交。

COPY 的每次目标都相对于同一个原基点，源选择不会变为刚生成的副本。例如以 (10,0,0) 为基点，依次输入 `@20,0,0`、`@50,0,0`，两批副本相对原对象的位移为 +20、+50，而非 +20、+70。动态尺寸锁定、极坐标、#/@ 三维坐标与捕捉沿用原取点流程；在光标字段已有尺寸锁时键入 M/S 仍按选项处理。

等待目标时，空输入 Enter/Space 结束且不额外复制悬停位置；输入了坐标或锁定尺寸时确认会提交该目标。右键可选择模式、U 或结束。U、空输入 Ctrl+Z 仅撤回本 COPY 最近一次成功放置，核对原生栈顶事务 ID，不能撤销进入 COPY 前的操作。每次放置一条整批历史；无效目标或锁定层失败不产生副本或历史，单次或多次模式下失败均可重新点选目标或取消。命令内不提供重做，结束后可用全局重做；超过现有 100 条历史预算时停止命令内撤回并提示。

M/S 只影响当前 COPY，重新启动仍默认多次；不修改剪贴板复制、阵列和 MOVE。尚无 COPYMODE 保存、COPY 内部阵列或 D 位移子命令。

R 参照有两种原尺寸输入：直接输入原角度/长度，或点选参照第一点、第二点（输入 `@` 可使用当前基点作第一点）。之后输入新方向角/长度，也可在画布点选相对基点的新方向/距离。旋转角度是工作平面 U/V 方向的绝对角度，实际增量为“新方向 − 原方向”；例如原方向 30°、新方向 90°，旋转 60°。缩放比例为“新长度 ÷ 原长度”，例如 20 改为 50，比例为 2.5，基点不动。自定义旋转轴启用后，方向角基准使用工作平面 U 在轴法平面上的投影，退化时使用 V。

参照步骤、两点轴线与新方向复用捕捉及三维坐标输入；原长度不能为零，新长度/比例须为正。光标旁字段显示原角度/原长度与新方向/新长度，数值变化更新预览；输入 R/C 或使用右键同名项切换流程，Esc 丢弃整次未提交变换。镜像末步 N 为默认保留，Y 为替换；替换仍保留稳定 ID，一次撤销恢复整批原几何。

新增与变换仍经原生文档更新；工作区毫米坐标先反换算为源单位，再写入原生记录。几何改变后更新 CAM 并保留有效加工安排；失效项在 CAM 面板提示，撤销/重做恢复对应上下文。已补属性/夹点、图层管理及下述曲线整理基础工具；扩展边界见[开发计划](CAD开发计划.md)。

## 属性与夹点编辑

右侧特性页批量属性中的颜色和所属图层显示共同值；不一致时显示“多个值”，须显式选择目标后才能应用。圆与圆弧混合选择可输入统一目标半径，一次修改、一条撤销；包含其他类型时不显示批量半径入口。三维偏移仍可批量调整位置。选择中含锁定层时编辑控件只读，菜单或命令提交也会由核心拒绝，整批不发生部分修改。

单选可编辑对象时，画布显示绿色方形夹点。按住夹点拖动，青色预览使用解析几何生成；在画布内松开即写回，拖动中 Esc 取消。也可在属性中选择夹点、输入 WCS X/Y/Z，点击“预览夹点坐标修改”后确认；此时可在光标旁继续输入位移或坐标，圆/圆弧半径夹点可直接输入实际半径。预览期间不改变图纸、保存标记或 CAM；提交后更新几何、显示和 CAM，支持整次撤销/重做。松开在界面或画布外时不提交，仍可输入目标或取消。

| 图元 | 本批可编辑夹点及约定 |
|---|---|
| 直线 | 起点、终点，允许 WCS 三维坐标，不能形成零长线 |
| 圆 | 圆心、半径；移动圆心保留法向，半径点必须共面 |
| 圆弧 | 圆心、半径、起点、终点；拖端点时保留另一端及原弧中点，用三点重建，半径和圆心可随之改变 |
| 椭圆 | 中心、长/短半轴端点；长轴可在原平面内转向，短轴保持正交，长度满足长半轴不小于短半轴 |
| 多段线 | 各顶点；共用顶点同步更新前后段，闭合首尾联动；圆弧段保持原扫角/凸度，由新弦重算圆心和半径 |
| 样条 | 非周期、具有控制点的样条控制点，节点/权重/次数保留；重合的闭合首尾控制点联动，编辑后清除旧拟合点数据；离开原平面时可变为空间样条 |

夹点取点使用临时平面：原点为所选夹点，平面图元使用自身平面方向，直线/样条等使用当前工作平面方向；不覆盖会话中设置的工作平面。此时二维绝对 `u,v` 以该临时原点计，`@du,dv` 以原夹点计；三维绝对与相对输入仍按 WCS。数值输入框同时显示临时平面原点。圆弧端点、多段线平面顶点和椭圆轴不能离开图元自身平面。

本批不增删顶点、不改变样条次数/节点/权重，不提供周期样条或只有拟合点样条的控制点编辑；还不是通用参数约束求解器。下节曲线整理已提供直线、圆/圆弧和多段线的相应基础操作。

## 图纸诊断与修复

CAD 右侧“工具 → 图纸诊断与修复”设置间隙候选上限（默认 `0.01 mm`，范围 `1e-6～1 mm`），点击“扫描当前图纸”。扫描原始领域几何，包含隐藏图层；只生成诊断快照，不修改图纸。图纸版本或参数改变后显示过期，必须重扫才能使用候选。

问题列表提供“选择并定位”，将相机中心移到问题点并选择相关图元；不改变图元坐标。隐藏对象仍受显示限制，锁定对象可查看但不能修复。重复项核对几何并考虑反向，多段线对比限 1024 段，闭合时尝试循环起点；样条以控制点/节点/权重等数据判断，不声明检测所有等价表示。内部交叉对直线/圆弧使用解析求交，对椭圆/样条使用离散候选，后者须放大核对；重合区间不作为完整求交结果处理。

| 单项修复 | 预览行为 |
|---|---|
| 重复 | 同图层、颜色和可见状态且几何一致时保留最小 ID，预览删除其余项；属性不同请人工核对 |
| 零长 | 删除不超过 `1e-6 mm` 的独立直线，或移除多段线的零长段；剩余结构仍须通过原生提交检查 |
| 间隙 | 只处理当前所选端点对，且距离不能超过当前候选上限；把后一个可编辑端点移到前一个端点，同一开放轮廓可提议闭合 |

点击“预览当前项修复”后，新增/修改结果为青色，待删除对象为红色，命令栏显示输出及删除数量。Enter 确认才提交，Esc 取消；沿用整批事务、撤销/重做及 CAM 刷新。其他问题提供定位，由曲线整理工具人工处理，不自动解交，也不自动修复全部候选；超限间隙不补齐。

“轮廓闭合、长度与方向”列出按 `1e-6 mm` 端点关系组成的轮廓，判断唯一闭合、开放或分支，显示长度。线/圆弧长度按解析参数求和，椭圆/样条长度显示“约”，按独立离散估计。可判断的平面闭合轮廓显示顺/逆时针及参考法向；法向最大分量取正，空间、退化或无法排成单链的轮廓方向未定。此处是 CAD 几何方向，不直接决定 CAM 加工方向。

诊断为同步、受预算限制的扫描：最多 50000 图元、20000 基本段，每类组合检查最多 200000 对，问题最多列 512 项、轮廓界面最多列 256 项。达到预算会明确提示结果不覆盖全图；未列问题不代表几何已完整验证。诊断容差与 CAM 的 `0.001 mm` 连通门槛分开，前者可以发现 CAM 已按近邻连接、但原图尚有实际间隙的情况。

## 曲线整理

### 图形化修改

顶部“默认 → 修改”、编辑菜单或命令行的以下五个命令使用画布点选流程，无需先选目标。修剪/延伸/偏移可在同一命令内连续处理目标，圆角/倒角仍为单次一对直线。青色为预览，待替换/删除的原对象为红色，偏移原件保留；未选中的保留边界以蓝色标记，实际图元颜色不变。最终点击直接写入，不再多按一次回车；每次点击一条撤销记录。

| 命令 | 操作流程 |
|---|---|
| TRIM / TR | 选择一个或多个边界（可 Ctrl+A），确认后悬停要去除的区间预览，点击提交并继续选目标。可去除端部或交点之间的中段；闭合圆/多段线至少需要两个不同交点。不要直接点交点。 |
| EXTEND / EX | 选择边界并确认，悬停目标靠近待延伸端的一侧预览，点击提交并继续选目标。只延伸到边界自身的有效范围；开放多段线仅修改首/末段，圆弧不能达到整圆。 |
| OFFSET / O | 输入距离并确认（空输入沿用会话上次值），点选对象，悬停偏移侧预览，点击提交后继续选源对象，距离保留。总是保留原件。侧点也可输入坐标，显式 @ 位移以源对象的点选位置为参考。 |
| FILLET / F | 输入半径并确认，点击第一条直线的保留侧，悬停第二条保留侧预览，点击提交。支持两条有唯一共面交点的直线，不要求原先端点相接；尺寸不能越过保留端。 |
| CHAMFER / CHA | 与圆角相同，尺寸为两边各自距交点的退让距离，连接为直线。 |

连续修剪/延伸/偏移等待目标时，Enter/Space 结束命令，不处理当前悬停目标；Esc 或右键“结束连续修改”放弃未提交预览并保留已经完成的修改。偏移侧点阶段 Enter 仍确认该侧点；N 重新选择源对象，D 重新输入距离，已确认尺寸在当前会话沿用。D/N 可通过键盘或右键使用，即使当前动态字段已有锁定值。

U（或命令输入为空时的 Ctrl+Z）只撤回本命令最近一次修改，并清除当前预览；撤销前核对原生事务 ID，不越过本命令之前的操作。边界拆分/删除后跟随真实结果更新，撤回时恢复；每次成功点击是一条原生历史，最多保留原有 100 条，超出预算时明确停止。U 不回退偏移距离等工具设置，退出命令后可使用全局重做。失败目标不产生历史，原有成功修改保留；侧点预览无效时可 N 重选或 D 改距。

目标与边界限直线、圆/圆弧及多段线，椭圆/样条结构操作暂不支持；圆角/倒角限两条共面非平行直线。使用已有真实几何求交，不按显示折线猜测；非共面圆相关求交、重合区间和复杂自交结果仍不支持。边界可来自锁定层，待修改目标必须可见且未锁定。圆角/倒角分别保留两条原线图层、颜色和方向，连接边继承第一条线属性；不强制把不同属性合并为一个多段线。

直线偏移使用当前工作平面，须与该直线平行；圆/圆弧、多段线按自身平面选侧。多段线偏移仍会检查塌缩、连接和自交，失败不保留部分结果。遇到不支持的形状或没有有效交点时保持原图，按提示重新选点或 Esc 取消。

矩形阵列在基点后支持光标输入“列数,行数”，Tab 切换字段；环阵输入数量。数量必须为 1～1000 的整数，总结果仍受 50000 图元预算限制；右侧可设置间距、总角度，并拾取工作平面 U/V 间距。光标参数修改更新预览，确认后一次提交。

### 参数方式与批量整理

先选择源对象，打开右侧“特性面板 → 工具 → 曲线整理（参数方式）”，设置参数后点“预览曲线整理结果”。此处保留旧的参数裁分、固定长度及批量操作；BREAK、JOIN、CLOSE、REVERSE 的菜单/命令行仍使用相应参数配方。预览后 Enter/Space 提交，Esc 取消；参数表如下。

| 命令 | 本批操作及范围 |
|---|---|
| `BREAK` 打断 | 直线、非整圆圆弧、圆和多段线，在参数 t 分成 `[0,t]`、`[t,1]` 两部分；圆拆成两条圆弧 |
| `TRIM` 参数修剪 | 同上，明确保留 `[from,to]`，丢弃其他部分；须满足 `0 ≤ from < to ≤ 1` |
| `EXTEND` 定长延伸 | 直线、非整圆圆弧及开放多段线，选起点/终点，输入正长度；多段线只延伸首/末段，弧长延伸不能达到整圆 |
| `JOIN` 连接 | 多个开放直线/圆弧/多段线组成单一链，自动检查端点的唯一邻接；分支、不连通或闭合输入拒绝 |
| `CLOSE` 闭合 | 开放圆弧/多段线明确添加直线闭合边；单条直线不能构成有效闭合轮廓，已闭合对象不修改 |
| `CHAMFER` 倒角 | 两条端点相接直线，两边各退让所给长度，生成含倒角边的多段线 |
| `FILLET` 圆角 | 同样选择两条端点相接直线，输入圆角半径，保留远端并以相切圆弧连接；半径过大则拒绝 |
| `OFFSET` 偏移 | 直线、圆/圆弧及平面多段线，按带符号距离偏移；默认保留原件并创建副本，可取消该选项 |
| `REVERSE` 反向 | 反转原始曲线的遍历方向；圆反转法向、椭圆反转参数方向、样条反转控制点/权重/节点；不直接指定 CAM 的最终切割方向 |

参数 t 归一化为 0～1：直线/圆弧按其参数比例，圆从自身平面参考轴开始，**多段线按段数等分，并非弧长比例**。该表只描述参数方式；顶部/命令行的常用五种工具改用上面的图形化流程。椭圆/样条的打断、修剪或偏移仍未实现。

连接容差默认 `0.001 mm`，只用于连接、倒角和圆角的端点判断，与几何距离容差 `1e-6 mm`、角度容差 `1e-8 rad` 及屏幕拾取像素分开。近邻端点在用户给定连接容差内合并到前段终点；圆弧段保留扫角/凸度重算，预览中可见变化。带圆弧结果必须共面；纯直线链若不位于选定平面，保存为空间多段线。仅共面线段/圆弧求交，本批不处理椭圆/样条交点或重合区间求交。

直线偏移使用当前工作平面法向，正值沿行进左侧，要求该平面与线平行。多段线使用自身平面，正值同样向行进左侧；圆/独立圆弧正值增加半径。多段线相邻偏移段按其支撑直线/圆求交连接，圆角仍保留圆弧；局部坍缩、边反向、连接失败或检测到自交时取消整批。首批不对复杂偏移结果自动拆圈、裁除自交或保留部分轮廓。

参数方式中的连接、倒角和圆角要求所选图元图层/颜色一致；结果继承最小 ID 源对象的公共属性（包括线型等），其他源对象在同一事务删除。普通替换保留主对象 ID，打断的附加片段和偏移副本获得新 ID；提交后选择结果。所有入口都受隐藏/锁定层约束，带宽度、厚度或拟合标记的源图元暂不参加结构整理，避免丢失附加属性。椭圆/样条反向也需满足本批有效加工采样条件。

结果写回解析几何及原生记录，DXF 保持曲线类型；多段线增减段数时可能重建原生多段线类型，公共属性保留，不承诺所有顶点附加记录和关联对象无损。几何确认后更新 CAM，按原始成员身份保留有效安排；拆分/连接等造成的失效项需在 CAM 面板处理，撤销/重做恢复对应上下文。

## 独立加工采样与公差

CAD 画布继续使用显示离散，CAM 分析、手动重排和四轴轨迹使用从原始领域几何生成的另一份采样数据，单位为毫米。默认加工弦差为 `0.01 mm`、单条光滑曲线内方向转角约束为 `3°`，当前是核心默认值，未新增配置输入框。原图显式折角和样条的 C0 接点保留，不会自动磨平。

- 直线保留端点，圆/圆弧按弦差及角度细分；椭圆以长短轴和参数导数上界限制细分步长。
- 样条先检查控制点、节点和正权重，支持最多 16 次的夹持非周期 NURBS。通过节点插入分成有理 Bézier 段，再按控制包络到弦段距离和控制边方向细分。节点/权重无效、周期或非夹持、只有拟合点、分段不连续或无法稳定细分时明确失败，不用控制多边形作为加工刀路。
- 单图元最多 100000 点、整图最多 2000000 点；样条另有分解工作量及 24 层细分预算。超限不输出部分几何，CAM 面板显示原因，两个 G-code 导出入口均停止。

这些约束控制原始 CAD 曲线的空间近似，不包含壁厚/Z 修正、四轴插补、后续圆弧输出及文本舍入的总误差，也不是 NC/实机验证结论。隐藏图层仍进入加工采样；暂不支持的样条仍可在 CAD 显示、编辑或保存 DXF，但存在此类对象时本批 G-code 导出被阻止。已有拓扑连通容差及路径覆盖限制仍见[已知限制](已知限制.md)。

## 图层管理

CAD 右侧“特性面板 → 图层 → 图层管理”列出所有领域图层，显示实际颜色和当前/隐藏/锁定状态；选择图层后可：

- 输入新名称并新建；选中已有层后重命名。名称按原生表规则忽略大小写判重，不能使用首尾空格及非法符号。
- 设置当前图层，所有后续新建图元使用它；只允许将可见、未锁定层设为当前层。
- 修改 RGB 颜色、显示或锁定状态。图层原有 ACI 颜色在未改色时保留，应用颜色后写入所选 RGB。
- 删除空层，或明确选择迁移目标后删除非空层。目标必须可见且未锁定，锁定源层需先解锁；`0`、`Defpoints` 和外部参照层不能删除，原生库同时限制这些层的改名。删除当前层时切换到迁移目标；无目标的空当前层删除后切到 `0`。

上述修改以原生文档事务提交，记录撤销/重做和未保存标记，并随 DXF 及恢复快照保存。改名保留图层身份及图元归属；迁移不删除图元。缺少原生层表记录的隐式导入层可查看，管理操作会提示缺少记录，不凭空覆盖原始图纸结构。

隐藏/冻结层不绘制、不参与普通点选/框选/全选或几何捕捉，已有 CAD 选择会清理隐藏对象；领域几何及 CAM 数据仍保留，加工计划与 NC 不因隐藏或锁定自动排除这些对象。锁定层仍可选择查看和作为捕捉参考，禁止颜色/换层/移动/删除/变换/几何修改；新建、换层和迁移目标同样不能使用隐藏/锁定层。

图层改名同时迁移内存中的同名 G-code 规则。新旧名称都已有规则时，提示冲突并取消整次改名；只有目标规则时保留它。撤销/重做只交换改名涉及名称的规则，其他规则及工艺参数保持当前值；期间对这两条规则的编辑也随该事务回退。规则仍需在 G-code 配置中保存才持久化，DXF 不含工艺规则。删除层不自动合并 G-code 规则，源名称规则保留为未使用配置，迁移后的图元使用目标层规则。

## CAD 批量编辑与 DXF 导出

在 CAD 工作区点选/框选追加图元，Shift 从选择集中移除，也可用“编辑 → 全选”或 Ctrl+A。右侧特性页的批量编辑操作应用于所有选中图元；即使多种几何混合选择，也只生成一次撤销记录。

| 操作 | 入口与行为 |
|---|---|
| 修改颜色 | 选择随层、随块、ACI 1–255 或自定义 RGB，点击“应用颜色到所选图元” |
| 修改所属图层 | 选择当前图纸已有图层并应用；随层颜色同时按新图层刷新 |
| 三维平移 | 输入 WCS 中的 ΔX、ΔY、ΔZ（mm），点击移动；各选中图元使用相同的毫米偏移，写回时转换为源单位 |
| 删除 | 右侧“特性 → 删除所选图元”、编辑菜单或 Delete，删除全部选中图元 |
| 撤销 | “编辑 → 撤销”或 Ctrl+Z，一次恢复上一批修改及原选择；可以连续撤销 |
| 重做 | “编辑 → 重做”、Ctrl+Y 或 Ctrl+Shift+Z，恢复刚撤销的批量修改及相应选择；可以连续重做 |
| DXF 导出 | “文件 → 导出 DXF…”，导出整张当前图纸，默认文件名为 `<原名>-edited.dxf`，不按选择过滤 |

Ctrl+A、Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z、Delete 仅在 CAD 工作区、没有文本输入控件占用键盘时作用于图元。输入框内继续使用文本自身的快捷键。颜色使用完整 ACI 色表；随层、随块与 RGB 语义写回 CAD 数据，并传递到 G-code 规则匹配。

当前会话最多保留最近 100 次批量编辑，撤销和重做共用这批历史；更早的修改仍保留在图纸中，但不能继续撤销。撤销后提交新的有效编辑，会清除旧的重做分支；空选择、零位移、属性未变化或编辑失败不增加历史，也不清空重做。没有可用历史时，对应菜单项禁用。

颜色和换层编辑保留现有加工安排；平移和删除会根据当前几何重建 CAM。撤销/重做几何编辑时同步恢复对应的加工分析、手动截面/配对和选择，并按当前 G-code 配置重建轨迹。CAM 面板中的独立操作不属于 CAD 撤销历史，G-code 配置也不会随 CAD 撤销回退。

文件名后的 `*` 表示有未保存的 CAD 修改，成功保存或导出 DXF 后清除；撤销或重做回到已保存版本也会清除。保存/导出不会清空撤销或重做历史。导出 DXF 保留当前文档路径；另存为会切换当前路径。未保存确认针对 CAD 图纸，不包含尚未持久化的 CAM 人工安排。

颜色和图层修改直接刷新属性及 G-code 规则元数据，保留已有显示/加工采样、拓扑及分析。移动、删除、半径及夹点修改会重新计算几何及分组，保留有效的人工断面指定/取消、显式端面配对、修边、手动截面和组内相对顺序。自动截面重新识别；显式清除的截面保持清除。区位、正反向及起点仍按现有策略和当前几何计算；没有新增独立人工起点或单元方向编辑。

安排绑定精确的图元成员集合及闭合状态，排序绑定左右端面的身份。新建单元使用生成位置；旧单元仍在原组时保留相对顺序。拆分、连接、删除或离开原组使安排失效时，CAM 面板显示待处理项，两个 G-code 导出入口暂停。核对并补好断面/配对/排序后，点击“已核对并处理失效安排，使用当前安排”，再按当前安排重算；确认不会消除采样、分组或轨迹错误。丢失的引用不会自动重新绑定到替代图元。

CAM 面板显示图纸、几何、属性、配置及安排版本和轨迹计算状态。配置输入变化时旧轨迹标为待重算；关闭、保存、校验配置及导出时按当前值计算。撤销/重做恢复对应的安排及待处理项；图纸 revision 可能回退，派生数据的会话版本继续递增，工艺配置不随 CAD 历史回退。DXF 及恢复文件只保存 CAD 图纸，不保存加工安排；使用 `.cadcam` 项目才能保留这些正式设置。

DXF 导出基于保留的原生文档记录，由 acadrust 写出 ASCII DXF，遵循库的版本处理策略；不从显示折线重新构造图纸。编辑范围为可见且已转换的六类曲线和基础 TEXT 模型空间图元；其他成功解析的源记录保留在原生文档中，但读写完整性受第三方库支持范围限制，不承诺对所有 DXF/DWG 记录无损往返。当前不提供 DWG 写出或完整关联图纸的无损往返。

## 测量、文字与标注

在顶部“默认 → 实用工具”或“绘图”下拉菜单选工具，或使用命令栏：

| 命令 | 取点及结果 |
|---|---|
| `ID` | 一点，显示 WCS 坐标及当前平面 U/V/N |
| `DIST` | 两点，显示三维距离和 ΔX/ΔY/ΔZ，不把离面距离投影成平面距离 |
| `ANGLE` | 三点，第二点为顶点，显示 0–180° 空间夹角；零长边拒绝 |
| 所选图元测量 | 特征面板中展开，显示圆/弧半径和直径、所选曲线总长；支持批量 |
| `TEXT` | 在工具中输入单行内容、字高和相对工作平面 U 轴的角度，再取插入点 |
| `DIMALIGNED` | 两端点和标注线位置；三点须在当前工作平面中，用字高控制文字及箭头大小 |

取点沿用捕捉、WCS/局部/相对数值输入，取齐后 Enter 完成，Esc 取消。测量仅输出结果和临时预览，不修改图纸、保存标记或历史。文字和标注先预览，Enter 才提交，一次撤销/重做整批恢复。

直线、圆、圆弧及线/弧多段线长度按解析公式计算。椭圆/样条是弦差 0.05 mm、转角 5° 的离散估长并标“约”，不是长度误差保证；无效对象明确未计入。长度结果按文档 revision/选择缓存，不在每帧重复采样。测量数值是当前取点结果，不与后续几何变更关联。

文字首版只支持左对齐/基线、宽度系数 1、无倾斜/镜像标志和厚度的 TEXT；插入点和方向保留真实三维平面。可单选改内容/字高，使用插入点夹点及已有批量平移、旋转、缩放、改色、换层、删除和历史。文字镜像及高级文字属性可能因超出支持范围取消整批。屏幕使用应用字体近似显示，不保证 SHX/原字体、宽度、控制码或倾斜投影排版一致；DXF 仍写原生 TEXT，不把字形轮廓加工化。

对齐标注为专用 `_CADCAM_ANNOTATION` 层中的独立线段、箭头和 TEXT，保存为这些原生实体，不生成关联 DIMENSION。它们带默认参考 XData，重开 DXF 仍默认排除加工。修改被标轮廓不会自动更新标注；修改标注线或文字也不联动其他组成对象，需要时删掉旧标注重新生成。专用层已有时沿用其颜色，锁定/隐藏时整批拒绝，不自动解锁。原生 DIMENSION/MTEXT 等仍保留原生记录并在导入报告说明未转换。

## 几何剪贴板与常用模板

在 CAD 画布且没有文本输入焦点时，Ctrl+C 复制当前选择，以所选显示包围盒的最小角为默认 WCS 基点；“编辑 → 指定复制基点”或 Ctrl+Shift+C / `COPYBASE` 先选对象、精确取基点、Enter 复制。Ctrl+V、“编辑 → 粘贴”或 `PASTE` 读取当前系统剪贴板，指定目标点后预览，再 Enter 新建对象；`@dx,dy,dz` 表示相对原基点的偏移。取消不创建对象，粘贴不依赖源图纸继续打开，支持本应用不同窗口/实例间使用。

剪贴板使用 `CADCAM-RUST-GEOMETRY/1` 文字数据，保留世界毫米解析几何、颜色、源图层名/颜色及当前参考角色。它不是 AutoCAD 原生剪贴板，也不复制原生线型、线宽、附属记录、块关系或完整文字样式；需要原生保真时用 DXF/项目保存。目标有同名层时沿用目标层属性，缺层时在同一次粘贴事务创建；锁定/隐藏目标层整批拒绝。单次最多 50000 个对象、64 MiB 剪贴板内容，坐标按目标源单位写回，跨毫米/英寸图纸不再次缩放世界几何。

空闲时 Enter 或“编辑 → 重复上一命令”重新启动上一个绘图/测量/复制/变换等工具，使用当前选择与工具参数；UNDO/REDO 不覆盖重复项。活动命令中 Enter 继续原有确认逻辑，文本框仍保留自己的快捷键。

矩形阵列取基点后，可在右侧工具页点击“拾取列/行间距”，以第二点相对基点的工作平面 U/V 差定义间距，预览后确认；多行/列的对应间距不能为零。环形阵列可设 −360°～360° 非零总角度：整圆不重复末项，部分角度包含首末项，数量仍包含原件，副本随轴旋转。阵列仍在一次事务提交及撤销，不生成关联阵列。

`HOLE` 圆孔：设孔径，取圆心，生成以当前工作平面为方向的真实三维圆。`SLOT` 长圆孔：设孔宽，依次取两端圆心；两点须在当前工作平面，不能重合。生成封闭的两条直线及两段半圆多段线，总长为圆心距加孔宽。两者都先预览再 Enter，后续可用矩形/环形阵列布孔；工作平面 XY/YZ/ZX/三点切换沿用现有入口，没有完整尺寸约束或方管自动四面模板。

## CAD/CAM 定位与参考对象

特征面板中，“定位对应加工单元 → CAM”将 CAD 选择转换为连续加工单元并定位相机；“定位源图元 → CAD”选择对应的全部源图元并定位。加工顺序每行的“定位”按当前加工编号定位该单元，并同步已打开的轨迹查看索引。隐藏图层不会被自动打开；隐藏源对象仍可从 CAM 信息和图层管理核对。未提交命令期间禁用这些选择/范围修改，青色预览与正式图纸明确区分。

“排除所选参考对象”按图元 ID 排除 CAM 采样和拓扑，普通 CAD 画面中灰色显示，仍参与 CAD 选择、捕捉、编辑和 DXF 保存。回 CAD 选择这些对象，用“将所选纳入加工”恢复。隐藏和锁定不改变加工范围；本项才明确排除加工。范围更改触发重算，失效安排继续要求核对，并有独立范围版本。

普通新建曲线默认纳入加工；文字始终不参与加工，标注及带本应用参考标记的对象默认排除。参考对象的复制/阵列、打断附加片段及偏移副本继承源角色。需要把加工与参考对象合并为一个结果时，先统一角色；不靠主对象 ID 猜测合并后的用途。范围是项目设置，不是 CAD 几何撤销事务；几何撤销会按当前范围恢复安排，避免重新带入已排除对象。已有对象通过范围按钮排除的当前角色仍由项目保存；新建标注、在专用标注层新建的对象和几何剪贴板创建的参考对象带 `CADCAM_RUST / REFERENCE_V1` DXF XData 默认参考标记，改名/换层仍保留。项目可保存对默认角色的显式覆盖，单独重开 DXF 则采用该默认标记；普通未标记曲线默认纳入，文字始终不切割。其他 CAD 若移除扩展数据则不能保证参考角色保留。

## 机床轨迹查看

从“视图 → 机床轨迹查看…”或 CAM 的“查看切削与空移轨迹”打开窗口；先选择加工单元时索引跳到该单元进场。支持 XY、XZ、YZ 和等轴测投影、滚轮缩放、拖动平移及适应轨迹。橙色切削、蓝色空移、黄色当前运动段、红色当前终点，可分别开关切削/空移或仅查看当前单元（含进场）。

通过上一段/下一段或运动点索引查看 XYZ/A 数值、加工编号和区位；“定位对应 CAD 图元”返回工件工作区选择并定位源对象。索引从 0 开始，首点是首个已知机床姿态，首点前的未知移动不绘制；末端退出段可能不属于某个加工单元。

窗口使用当前版本的语义机床轨迹，不把机床 XYZ 叠到工件 CAD 坐标。圆弧仅为显示按约 2° 离散，独立于 CAM 公差及 NC 输出圆弧开关；A 值独立显示，不模拟管材旋转、刀头/夹具、材料及自定义头尾代码。配置过期、采样失败或安排待处理时不显示旧轨迹；这不是最终 NC 解释器或碰撞仿真。

## 加工规划

1. 切换到 CAM，查看“方管截面”。程序从闭合单元的 YZ 包络估计中心、尺寸和圆角，当前单一候选自动采用。
2. 手动截面参数跨帧保留，点击“应用手动参数/截面”才生效，可用“还原当前截面参数”恢复当前正式截面；非法数值不可应用。清除截面按钮明确进入普通路径回退，重新采用截面需应用候选或手动参数。
3. 查看“加工断面与区间”。高置信断面自动应用，其他候选可手动应用。选择闭合单元可“设为加工断面”，已设定的可“取消加工断面”；手动设定要求已有管材截面。
4. 加工断面默认按轴向中心位置两两配对，两个断面之间为一节成品段。用“手动成品段配对”选择左右断面并应用；“恢复自动配对”清除手工配对，保留修边标记。左右角色由成品归属确定，不随切削顺序改变。
5. 组外/修边组先执行；每个成品组固定按“左端面 → 各区位普通单元 → 右端面”加工。懒旋转按区位集中加工，关闭后按最小 X 排序。普通单元可用上下按钮或 Ctrl 点击组内连续编号重排，只能在两端之间移动。
6. 画布显示加工编号、断面编号和橙色起点箭头；四轴轨迹面板显示单元数、运动段数、切削段数、安全 Z、A 范围和末姿态。画布目前显示原图线框和规划标记，没有完整机床运动仿真。

未配对断面、修边和组外加工单元单独列出；可勾选“仅作修边”将断面排除配对和壁厚补偿。普通单元依据路径采样与两侧断面的局部 X 边界归属，跨边界、归属不唯一、成品段重叠或边界交叉会报错并阻止导出。相邻成品不自动共用同一断面。配对、修边和手动排序仅保存在本次图纸的内存中。

关闭壁厚端面补偿时，没有截面也能导出：按 X 排序，以原 XYZ 和固定 A 偏移生成轨迹。该回退路径不执行完整方管区位策略，也不应用过切和加工面 Z 修正。

有截面时，普通加工单元的落刀点只由自身几何决定：非懒旋转取 X 最大点，懒旋转优先取所在区位的局部北极点。这里的“北”是区位转到朝上加工姿态后横向 +Y 的方向，不是统一的世界 +Z。北极点不在主区位时尝试南极点；两种模式的首选极点均不可用时，按各自规则回退到主区位内的极值点。无端点在主区位的开放路径仍按两端极值回退，不从中间拆分开切。

懒旋转优先从极点沿 +X 开始切削；非懒旋转在 +X 极点按顺逆时针选择局部周向切向。闭合轮廓无过切时回到起点结束，过切时后续转移从实际过切终点开始。切断断面和无截面回退路径仍有独立规则。

## G-code 配置

顶部“G代码配置”和“导出 G 代码”与“文件”“视图”同级，点击即可进入。配置以覆盖应用客户区的模态弹窗显示：顶部右侧说明规则代码顺序，保存与校验操作栏贴底，中间区占满剩余空间；左侧六个分类等高排列。文件与规则页左侧设置选项或选择规则，右侧上下两个大输入框编辑头尾代码，底部横排一行编辑说明；加工安全页左侧为参数、右侧为剖面示意，加工规划按选项与输入两栏排列。选项说明在悬停时显示，不重复展示分类标题。中间区不设整体横纵滚动，仅代码、规则列表或选项实际溢出时局部滚动。关闭按钮或 Esc 返回画布，弹窗阻止底层画布操作；不再提供 G 代码文本预览。

### 配置位置与加载

- 配置：`%APPDATA%\CADCAM-Rust\gcode.toml`。
- 最近打开：`%APPDATA%\CADCAM-Rust\recent.txt`。
- 无 `APPDATA` 时回退到 `<进程工作目录>/CADCAM-Rust/`。

启动时不存在配置会尝试创建默认文件，有效配置会重新序列化以补入新增字段。非法或不可读的配置在启动加载时保留原文件，内存回退默认值，当前不明确提示启动加载失败。配置导入和重新加载先检查 TOML、数值及联动参数，失败保留当前内存配置并在窗口底部显示原因。

| 操作 | 行为 |
|---|---|
| 导入配置 | 选择 TOML 文件，成功后替换当前内存配置并重算，不自动覆盖默认配置文件 |
| 导出配置 | 将当前配置保存为选定的 TOML 文件，取消对话框不产生写入 |
| 保存配置并重算 | 校验配置后写入上述默认位置，并重建轨迹，供下次启动使用 |
| 重新加载 | 读取默认位置已保存的配置，成功后替换当前配置并重算 |
| 恢复默认 | 将全部字段及类型/颜色/图层规则恢复为内置默认值并重算，点击保存后才持久化 |

操作结果显示在配置窗口底部，并同步写入命令栏。配置读写校验不要求当前已有图纸；轨迹校验另行执行。

### 速度与默认文件头尾

程序不再为直线、圆弧或圆弧展开的折线自动添加 F，也不再提供统一“进给速度”输入框。需要的 F 值由用户直接写入文件、图元类型、所属图层、图元颜色等层级的头尾代码，按顶栏说明的顺序原样输出。旧 TOML 中的 `feed` 字段不再参与生成或校验，再次保存配置时移除。

新建配置或恢复默认时，文件头为：

```gcode
%
G90
G21
G17
M8
M7
G00 Z50
G80 G40 G49 G17 G90
M05
```

默认文件尾为：

```gcode
G00 Z50
M05
M30
%
```

### 加工面 Z 联动修正

在“加工规划”页设置“加工面 Z 修正”。未启用壁厚端面补偿的单元，Z 为 0 时保持原轨迹，A 恒定时统一偏移机床 Z；跨区位、A 变化时，按原始方向联动补偿 X。启用壁厚端面补偿的左右端面则按下节方式，将 Z 偏移纳入内壁投影统一求 X，不再额外叠加 Z/X 联动。两种加工模式使用同一处理。

设局部断面方向为 `x = a*y + b*z + c`，机床 Z 偏移为 `h`、当前角度为 `A`，对应工件坐标位移为 `ΔY = h*sin(A)`、`ΔZ = h*cos(A)`，补偿量为 `ΔX = a*ΔY + b*ΔZ`。计算使用弧度。它使倾斜平面的刀头采样点仍保持原方向，避免仅偏移 Z 后两侧弯曲。

加工断面从四个圆角各自的采样求方向，方向一致后等权合并，并以每个源点为锚修正，保留断面边上的曲线；直角断面使用转角及相邻边采样。其他 A 变化的加工单元要求采样能确定可靠的平面方向。方向退化、局部不共面或各转角方向不一致时显示具体单元及原因，并阻止轨迹生成和导出。原始 CAD 图元及计划选点不变，进场、切削、过切和后续空移使用修正后的实际姿态。

壁厚端面补偿沿用旧项目对激光内壁作用位置的处理；Z/X 联动只用于未启用该补偿的单元。启用壁厚补偿后，刀头轨迹允许弯折或不共面，不以刀头轨迹共面作为成品端面的判断依据。采样和输出精度仍影响 NC 中的几何误差。

### 壁厚端面补偿

在“加工规划”页输入“方管壁厚”，勾选“启用成品端面壁厚补偿（左 +X / 右 −X）”，再保存重算、校验或导出。旧配置缺少两个字段时默认关闭。普通单元及显式修边断面不执行壁厚补偿；开启时，未配对且未标记为修边的断面会阻止导出。

先生成已含机床 Z 偏移、X 仍为源点 X 的刀头姿态，反变换到工件坐标，沿激光方向取一个壁厚的候选点，再投影到内轮廓；不要求射线严格穿过内腔。内轮廓尺寸为外尺寸减两倍壁厚，内圆角为 `max(外圆角 − 壁厚, 0)`。以源点为锚，按原始局部斜率求一次修正量 `ΔX = a·(内壁Y − 源点Y) + b·(内壁Z − 源点Z)`：左端取非负值，右端取非正值。最终 `X = 原始 X + ΔX`，不再追加另一份 Z/X 联动，机床 Z 偏移也只施加一次。原始断面保留为定位和方向基准，不要求补偿后各折线的延长线都经过原轴线交点。

保留壁厚数值、内轮廓尺寸、断面方向和补偿后两端空间的必要检查；不再因射线相切、未穿过内腔或刀头与内壁的严格位置关系阻止补偿。修正后的入口、切削和过切参与后续空移；过切承接闭合后的连续 A 角，不回到首圈角度。

本功能使用局部方向及内壁投影近似，不含割缝、热变形、真实夹具及共切求解。验收应查看整层管壁的成品端面，不再只要求刀头轨迹共面。

### A 轴连续角度与 ±180° 交界

A 是按实际运动连续展开的旋转角，不强制限制在 ±180°。`-180°` 与 `+180°`、`0°` 与 `360°` 分别代表相同姿态，等价姿态衔接不执行整圈转动。单元内部始终连续展开，例如 `179° → -179°` 的几何方向输出为 `179° → 181°`；反向经过边界则可输出 `-179° → -181°`。经过交界不插入关光、抬刀或回转。

文件级的“A 轴保持连续角度（跨单元最短转位）”默认开启，单元入口选择靠近上一末姿态的等价 A 角。关闭时，非等价的单元入口以归一化角度重新定位，可能产生较长转位；精确等价的姿态仍不额外转圈，单元内部切削仍连续。两种加工模式共用这套处理。A 偏移按周期归一化，例如 `720°` 等效于 `0°`；初始 A 保留配置的有限数值，不按 ±180° 截断。

结束返回初始位置时，XYZ 返回配置值，A 取靠近末姿态的等价角度，不为恢复数值而多绕整圈。例如从 `A540°` 返回配置的 `A-180°`，保持 `A540°` 即已回到相同朝向。非等价姿态的空移旋转继续遵循旋转净空策略。

### 同面联动转移

在“加工安全”页配置，懒旋转和非懒旋转共用同一算法。只有前后单元均确认处于同一水平管材平面、主区位相同、实际 A 角不变且未跨过切断边界时，使用局部联动；圆角、过渡、跨面、需旋转或无法确认平面的情况经保守净空转移。

| `[transfer]` 字段 | 默认值 | 含义 |
|---|---|---|
| `enabled` | `true` | 启用局部联动；关闭时使用 `same_zone_clearance` |
| `retract_height` | `2.0` | 横向移动前的垂直抬刀高度 |
| `approach_height` | `2.0` | 横向移动结束后的垂直落刀高度 |
| `height` | `4.0` | 相对两端较高 Z 的联动峰高 |
| `auto_height` | `false` | 总高度自动取两个最小高度的较大值 |
| `rise_ratio` | `0.5` | 同面 XY 行程中用于联动抬升的比例，UI 按百分比输入 |
| `fall_ratio` | `0.5` | 同面 XY 行程中用于联动下降的比例，UI 按百分比输入 |
| `smooth_enabled` | `false` | 同面及跨区位空移几何平滑，默认关闭 |
| `smooth_tolerance` | `0.05` | 光顺参考曲线离散及 XYZ 输出舍入的总允许偏差，单位 mm |

高度必须有限且非负，总高度不能小于最小抬/落高度；两项水平占比均在 0–1，合计不超过 1。非法联动参数会在界面提示并阻止保存、校验及导出。原 TOML 缺少 `[transfer]` 时加载默认值，原同区离面值保留。

转移剖面依次为：垂直抬刀、XY/Z 联动抬升、可选平台、XY/Z 联动下降、垂直落刀。50%＋50% 时平台消失；零长度段合并，零 XY 距离退化为垂直抬落。关闭联动时，等高转移高度取两端较高 Z 加旧离面距离，不再只从上一终点计算，也不会被旋转安全 Z 向下截断。

右侧示例 XY 距离、终点 Z 差、跨区位模式及 A 转角只影响示意、不保存到工艺；示意图与实际轨迹调用同一转移函数。异高示意仅展示几何，实际局部联动仍要求已确认的共同平面。实际起点使用过切后的末姿态。整个单元间空移位于单元结束代码与下一个单元开始代码之间。

旋转净空按截面及图纸 YZ 包围矩形半对角线、正向加工 Z 偏移和旋转间隙计算；不是完整机床/夹具碰撞模型。首尾进退采用该净空策略，已有高于净空的位置不会先降低再旋转。未启用初始位置时，实际程序启动姿态仍未知。

### 空移路径平滑（同面及跨区位）

在“加工安全”页勾选“启用空移路径平滑（同区位 / 跨区位）”，设置允许偏差，再保存重算或校验。两种加工模式、普通/快速导出共用轨迹层结果；平滑输出为离散快速移动线段，不新增圆弧、样条或 F。切削轮廓、进出刀点和激光启停边界保持原有语义。

- **同面**：需启用同面联动，保留起点上方最小抬刀高度内及终点上方最小落刀高度内的竖直段，仅对上方联动部分构造五次 Bézier 参考曲线，再自适应离散。同面沿用原有联动总高度与水平占比。
- **跨区位**：先保持 XY/A 不变，竖直抬到不低于旋转净空、起点最小抬刀高度及终点最小落刀高度的共同安全平面。只在此平面以上平滑联动 XY/Z/A，A 使用五次渐变；转位完成后保持末端 XY/A 竖直落刀。联动总高度在此作为共同安全平面上方的额外过渡高度，不能为压低折角而侵入旋转净空。
- **离散及精度**：利用 Bézier 控制点界约束整段曲线与线段的 XYZ 偏差，并为输出舍入扣除误差预算；允许偏差必须大于 `sqrt(3)/2 × 10^(-小数位数)`。保护段增加向上量化余量，以免舍入提前横移或转位。A 另按角度误差及相邻步长细分，不与长度单位混算。
- **回退**：纯竖直移动、没有已知起点、同面联动关闭、过渡高度/水平区间不足，或达到离散资源上限仍无法满足偏差时，保留原路径。零 XY 距离但需要 A 转位的跨区位路径仍可在净空上方平滑旋转。

参考曲线在过渡处保持切向及曲率连续，输出仍为有限直线段；不等于已完成机床速度、加速度或加加速度规划。实际运动还受控制器对快速指令的解释、前瞻和混合模式影响，本轮仅确认应用构建，未做 NC/实机验收。

### 类型、图层和颜色规则

文件级及每条规则均含 `header`、`footer`、`comment`；`comment` 只作配置说明，不输出到 NC。文件级、图元类型、图元颜色及所属图层页的说明统一位于右侧底部横排输入框，随配置导入、导出及保存。旧配置未含文件级 `comment` 时默认为空。所属图层与图元颜色列表在选项左侧显示实际色块；图层色取自当前图纸的图层颜色，悬停色块可查看 RGB 值。仅存在于配置而未出现在图纸中的图层无实际颜色可显示。

- 类型键为内部六类几何名：`LINE`、`POLYLINE`、`CIRCLE`、`ARC`、`ELLIPSE`、`SPLINE`。LWPOLYLINE 转换后归入 `POLYLINE`。
- 图层键为源图层名；图层页列出当前显示数据图层并补入 `0`。
- 颜色键为图元颜色语义：`BYLAYER`、`BYBLOCK`、`ACI:n`、`#RRGGBB`。随层图元匹配 `BYLAYER`，不按解析后的图层 RGB 匹配。UI 默认提供随层、随块和 ACI 1–9，其他键可编辑 TOML。
- 每单元收集不重复的“类型、图层、颜色”组合。每段连续切削的头部按每个组合依次插入类型、图层、颜色规则，再插入 `unit_start`；切削后先插入 `unit_end`，再按相反组合顺序及颜色、图层、类型顺序插入尾部。同一规则可能因不同组合重复输出。

### 重算与校验

配置直接编辑当前内存值；保存成功、导入成功、重新加载成功、恢复默认及关闭配置窗口时重算轨迹。校验及两个导出入口使用当前内存参数；需要时等待后台重算并自动继续，不要求先保存。等待期间改动输入或取消会取消原后续动作。示意图随参数编辑即时更新，G 代码文本仅在导出时生成。

“校验 G 代码”实际检查语义轨迹及部分配置，不解析最终 NC。检查包括 Z 联动修正的构建错误、空轨迹、部分数值合法性、每单元是否有切削段、A 是否有限、切削是否存在超过 180° 的跳变，以及跨单元在内的空移 A 变化是否在安全高度。配置窗口底部显示校验结果，悬停可查看完整信息；导出失败时命令栏最多显示前 5 项问题，范围见[已知限制](已知限制.md#运动与输出)。
