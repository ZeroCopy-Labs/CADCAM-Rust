# 使用指南

[返回项目入口](../README.md) · [开发指南](开发指南.md) · [已知限制](已知限制.md)

## 打开图纸

通过“文件 → 打开文件”、最近打开列表或启动参数打开 DXF/DWG。对话框优先使用最近文件所在目录，无可用目录时尝试用户桌面，再回退到进程工作目录。最近文件保留最多 10 项。

支持模型空间中的 LINE、可转换的 POLYLINE/LWPOLYLINE、CIRCLE、ARC、ELLIPSE、SPLINE。INSERT、块定义、图纸空间、标注和三维实体等不在当前转换范围内。窗口上方显示文件名，底部消息显示实体/图层/单元数、格式、版本及单位。“文件 → 导入报告”显示打开时的解析后图元总数、模型空间数量、转换类型/数量、跳过样本的类型/图层/句柄/原因和警告；跳过样本最多 256 个，另列省略数量。存在警告或跳过对象时自动打开报告，后续编辑不改写打开时的报告。

### 单位

工作区的坐标、移动量、截面尺寸、长度容差和 G-code 长度参数统一使用毫米。源 DXF/DWG 单位来自 INSUNITS；例如源图纸中 `1 in` 的长度在工作区显示为 `25.4 mm`。曲线的坐标、半径和椭圆轴长换算，角度、法向、节点参数和权重不乘长度比例。

原生文档保留源坐标和源单位，三维平移从毫米换回源单位再写入；保存/导出 DXF 仍使用源单位，避免重复换算或改动尚未显示的源记录。源单位和工作单位同时显示。无单位或未知单位图纸在打开时询问：是＝毫米，否＝英寸，取消＝停止打开并保留当前图纸；用户指定的单位在保存 DXF 时写入 INSUNITS，并计入未保存状态。新建图纸使用毫米。

G-code 轨迹使用毫米，默认文件头为 `G21`；自定义头尾原样输出，使用者应保持与毫米轨迹一致，程序尚不解析自定义模态指令。旧配置参数不根据图纸源单位再次缩放。

### 新建、保存与关闭

| 操作 | 入口与行为 |
|---|---|
| 新建图纸 | 文件菜单或 Ctrl+N，创建空白毫米文档；绘图工具在后续阶段增加 |
| 打开图纸 | 文件菜单或 Ctrl+O；也可选择 `.bak` 备份恢复 |
| 保存 | 文件菜单或 Ctrl+S，已有 DXF 写回当前路径；未命名、DWG 来源或恢复图纸进入另存为 |
| 另存为 | 文件菜单或 Ctrl+Shift+S，成功后将所选 DXF 作为当前保存路径 |
| 关闭图纸 / 退出 | 文件菜单或窗口关闭按钮；有未保存 CAD 修改时提供保存、放弃、取消 |

快捷键在没有文本输入焦点、G-code 配置或导入报告弹窗时生效。保存对话框取消、写入失败或打开失败均保留当前图纸；只有成功写入才更新保存版本。文件操作不保存 CAM 手动安排，完整项目保存属于后续阶段。

保存和导出先完成序列化，再写同目录临时文件、同步并替换目标。覆盖已有文件时，将覆盖前内容保存在 `<文件名>.bak`；备份或目标替换失败会报告错误。可通过“打开文件”选择 `.bak`，作为待另存的恢复图纸打开，不直接写回该备份。所有图纸输出要求 `.dxf` 扩展名。

### 自动恢复快照

未保存图纸在首次修改后的更新周期写入一次快照，之后存在版本变化时最多每 30 秒更新一次，位置为 `%LOCALAPPDATA%\CADCAM-Rust\Recovery`，不可用时按 APPDATA/当前目录回退。每个会话使用独立文件名；快照不改变保存标记或源路径。正常保存、放弃当前图纸或正常退出时清理本会话快照；异常退出后的文件通过“文件 → 恢复图纸快照…”打开，启动发现现存快照时会提示入口。

恢复后必须另存为 DXF。快照只包含原生图纸及单位，不包含撤销/重做历史和 CAM 人工安排；最近尚未写入快照的修改无法恢复。恢复写入仍在主线程，大图可能短暂停顿。旧的恢复来源文件不会因打开而自动删除。

## 视图与选择

| 操作 | 行为 |
|---|---|
| 中键拖动 | 平移 |
| Shift + 中键拖动 | 旋转视角 |
| 滚轮 | 正交缩放 |
| “视图”菜单 | 适应视图、等轴测、俯视图、前视图 |
| 右上角视角魔方 | 点击可见面切换预设方向 |
| 左键点选 | 选择当前橙色预选对象；重叠候选按屏幕距离、深度排序 |
| Shift + 左键/框选 | 追加选择 |
| Alt + 左键/框选 | 从当前选择移除 |
| Ctrl + 左键/框选（CAD） | 切换命中对象的选中状态 |
| Tab / Shift+Tab | CAD 选择时正向/反向循环附近候选；命令取点时循环捕捉候选 |
| 从左向右框选 | 蓝色“窗口”，选择完整包含的对象 |
| 从右向左框选 | 绿色“交叉”，选择与框相交的对象 |
| CAD/CAM 开关 | 在图元和加工单元选择语义间映射 |

CAD 模式按图元选择，CAM 模式按整个加工单元选择。CAM 保留图元原色，选中单元黄色高亮。左侧“特征”面板显示几何、成员、区位及加工断面信息，多选以折叠项展示。

CAD 悬停对象为橙色，已选对象为黄色；光标旁显示图元类型、图层及候选序号。Tab 只在存在候选时用于循环，没有候选时保留界面焦点导航。左侧“选择方式与过滤”提供替换、追加、移除、切换四种方式，修饰键优先级为 Ctrl、Alt、Shift，再使用面板方式。原有 Shift 追加行为不变，CAM 的 Ctrl 点击重排保持原行为。

类型、图层和颜色属性过滤应用到后续点选、框选和 Ctrl+A；颜色按图元的随层/ACI/RGB 等属性匹配。改变过滤不自动移除已选对象，“反选过滤范围”只翻转符合当前过滤的对象，“清除过滤”恢复全部。成功换图后重置过滤。过滤不改变几何捕捉范围，画面中可见的其他对象仍可作为取点参考。

世界坐标轴固定在 CAD 原点，正半轴实线、负半轴虚线；CAD 工作区另有工作平面边框和 U/V/N 轴。底部命令栏默认显示最新消息；点击展开最多 4 行历史和 1 行输入，活动命令额外显示当前步骤。命令进行中保持展开，可用鼠标取点或输入坐标；空闲时点击其他区域收起。

## 精确移动与工作平面

### 基点与目标点移动

入口为“编辑 → 基点 → 目标点移动”、Ctrl+M、左侧“绘图、变换与工作平面”，或在命令栏输入 `MOVE`、`M`、`移动`。

1. 已有选择时直接指定基点；未选择时先点选/框选，可 Shift 追加或 Ctrl+A 全选，再按 Enter 或“确认选择”。
2. 在画布点选基点，或在命令栏输入坐标后按 Enter。基点确定后冻结本批选择。
3. 移动鼠标显示青色平移预览，橙色线表示基点到目标点；点击目标点或输入目标坐标后，预览固定。原图、CAM 和保存标记在此期间不改变。
4. 再按 Enter 或“确认 / 提交”提交一次批量平移；也可重新输入目标坐标修改固定预览。成功后可一次撤销/重做；零位移不增加历史。

Esc 或“取消”结束命令，不修改图纸和历史。非法坐标保留在输入框供修改；提交失败保留预览。命令进行中暂时禁用其他 CAD 编辑、直接保存和 DXF/G-code 导出；可以先完成或取消。切换 CAD/CAM 工作区取消未确认命令；成功新建、打开或关闭图纸时重置命令和工作平面。

鼠标优先取启用的几何捕捉点，没有候选时取当前工作平面上的交点，再按辅助开关处理。数值输入按下面的坐标约定处理，可离开工作平面且不受捕捉/方向辅助约束。原有“三维偏移”按钮仍按输入的毫米偏移直接提交，不经过交互取点步骤。

### 坐标输入

所有长度为毫米，角度为度，数值允许小数、负数和科学计数法。逗号分隔或空格分隔均可；不能输入 NaN/Infinity。

| 输入 | 含义 |
|---|---|
| `20,0,5` 或 `W:20,0,5` | WCS 绝对三维坐标，不受工作平面方向影响 |
| `20,5` | 工作平面内绝对 U/V 坐标，法向坐标 N＝0 |
| `@10,0,5` | 从参考点沿 WCS 增加 ΔX/ΔY/ΔZ |
| `@10,5` | 从参考点沿当前工作平面 U/V 增加位移，保留参考点的法向位置 |
| `@10<45` | 从参考点沿工作平面移动 10 mm，方向为从 +U 朝 +V 的 45° |

移动目标点的参考点为基点；指定第一个基点时参考点为当前工作平面原点。三点定义中，第一点相对当前平面原点，第二、第三点相对新平面的第一点。相对输入不累积到上一次预览目标。

例如在 XY 工作平面输入基点 `0,0,0`、目标 `@10,0,0`，再 Enter 确认，即沿世界 +X 移动 10 mm；在 YZ 平面输入目标 `@10,0` 则沿世界 +Y 移动 10 mm。

### 工作平面

左侧按钮或命令 `UCS XY`、`UCS YZ`、`UCS ZX` 切换方向并保留原点。三种平面的 U/V 分别对应世界 X/Y、Y/Z、Z/X。可在左侧输入有限的 WCS 原点并点击设置。平面边框只表示取点方向和位置，不是新增 CAD 图元，也不限制可输入坐标的范围。

`UCS 3P` 或“三点平面”按原点、+U 方向点、+V 一侧点依次取点；第三点不要求与 +U 垂直，程序建立正交坐标系。三点共线、重合或数值无效时保留原平面并提示；完成第三点后应用，Esc 在完成前取消。可输入三个 WCS 点，或捕捉三个空间几何特征来建立倾斜平面；没有几何候选时鼠标点仍位于原工作平面。

平面原点、方向及当前取点坐标显示在左侧；U 红、V 蓝、N 绿。平面固定在图纸坐标中，旋转相机不改变它。视线近乎平行、平面在视线后方或交点无效时暂停鼠标取点，可以调整视角或输入坐标。工作平面只保留在当前会话，不随 DXF 或恢复快照保存。

命令栏另外支持 `UNDO` / `U` / `撤销` 和 `REDO` / `重做`，与现有历史入口相同。输入框拥有焦点时，Ctrl+Z/Ctrl+Y 仍编辑文本；Esc 可取消活动命令。图纸、捕捉、平面及相机目标坐标使用 f64；渲染前先减去视图原点再转成 f32，鼠标射线反向转换回 WCS。此变换只影响显示，不平移原图或 CAM；仍受 f64 本身、相机及显示离散的精度范围限制。

### 几何捕捉与绘图辅助

左侧“捕捉与绘图辅助”设置捕捉类型和方向辅助；状态行显示当前开关。默认开启端点、中点、中心、象限点和真实交点；最近点、垂足、切点、投影及方向/网格辅助默认关闭。

| 功能 | 当前支持 |
|---|---|
| 端点/中点 | 直线、圆弧及多段线各段；部分椭圆的端点/参数中点；有效开放样条的求值端点。完整圆/椭圆没有独立端点，样条不提供伪装为弧长中点的参数中点 |
| 中心/象限点 | 圆、圆弧、椭圆；多段线内圆弧也可提供圆心和范围内象限点 |
| 最近点 | 直线解析求解；圆弧、椭圆及有效 NURBS 样条采用参数搜索与局部细化，复杂样条不保证全局最近点 |
| 真实交点 | 直线—直线、直线—圆/圆弧及共面圆/圆弧组合，含多段线段与自交；按约 `1e-6 mm` 空间容差判断，不将异面投影相交当作交点 |
| 垂足/切点 | 有已确定的基点、绘图前一点或平面定义参考点时，支持直线垂足、圆/圆弧垂足及共面外部参考点的圆/圆弧切点；只提供源段范围内的点 |

捕捉在光标附近 12 像素内寻找候选，绿色方框显示种类及候选序号。取点时 Tab/Shift+Tab 循环候选，确认坐标仍来自原几何。交点最多处理当前 24 个邻近图元，超出时左侧提示；椭圆/样条交点、异面圆—圆交点尚未实现。捕捉点在约 `1e-6 mm` 内去重。

默认使用捕捉点的真实 WCS 坐标，允许其不在当前工作平面；勾选“将捕捉点投影到工作平面”后才沿平面法向投影，标记增加“投影”前缀。投影捕捉与真实空间交点分开处理，未实现单独的“屏幕表观交点”功能。

| 快捷键 | 行为 |
|---|---|
| F3 | 几何捕捉开关 |
| F7 | 显示当前工作平面的网格 |
| F8 | 正交方向约束，启用时关闭极轴 |
| F9 | 网格捕捉，默认间距 10 mm，可修改 |
| F10 | 极轴方向约束，默认角度增量 15°，启用时关闭正交 |

优先级为几何捕捉、正交/极轴、网格、自由取点。方向约束以已确定的参考点为基准，沿平面 U/V 方向保持参考点的法向位置；命中几何捕捉时不再移动该精确点。方向约束生效时不强行同时满足网格。缩小时网格可能以间距的整数倍稀疏显示，实际网格捕捉仍使用所设间距。

快捷键不抢占其他文本控件。命令坐标框为空时也可切换辅助、循环候选；有文字时保留文本导航。辅助和过滤只保留在当前会话，不写入 DXF 或 CAM。

## 基础绘图与批量变换

在 CAD 工作区打开或新建图纸，从顶部“绘图”“编辑”菜单、左侧工具按钮或命令栏启动。左侧“新图元属性”显示当前图层，可预选随层/随块/ACI/RGB 颜色及样条次数；命令开始后冻结这些设置。新图元使用原生文档当前层，可在“图层管理”切换；新图纸默认当前层为 `0`，打开图纸沿用源文件当前层。当前层隐藏或锁定时须先切换、显示或解锁。

### 绘图命令

| 命令 | 取点及结果 |
|---|---|
| `LINE` / `L` | 连续取点，每相邻两点生成独立直线；可输入任意 WCS 三维点 |
| `PLINE` / `PL` | 连续取点生成一个平面多段线，本批只新增直线段 |
| `RECTANGLE` / `RECT` | 两个对角点，边沿当前平面 U/V，生成闭合多段线 |
| `CIRCLE` | 圆心、半径点；取圆心后也可直接输入正半径，如 `5` |
| `ARC` | 起点、经过点、终点；三点不能共线，方向经过中间点 |
| `ELLIPSE` | 中心、长半轴端点、短半轴参考点；第三点取垂直长轴的距离，也可直接输入正短半轴长度，不能超过长半轴 |
| `SPLINE` | 控制点样条，开始前选择 1～5 次，至少次数加一的控制点；不将取点解释为拟合点 |

所有工具复用坐标输入、捕捉及方向辅助。除 LINE 外在当前工作平面内绘制，空间捕捉点不共面时提示错误，可先建三点平面或显式开启投影捕捉。绘图相对坐标的参考点是前一个已取点，首点相对工作平面原点。

圆、矩形、三点圆弧和椭圆在取齐点后固定预览，再按 Enter 或“确认 / 提交”写入。连续直线、多段线和样条先用 Enter /“结束取点”结束，再次 Enter 提交；也可用 `C` / `CLOSE` /“闭合”固定闭合预览，再 Enter 提交。`U` / `UNDO` /“撤回一点”只撤回本命令中的一个点并解除闭合，不撤销正式文档。固定预览时重新输入坐标替换最后一点。

闭合直线/多段线至少需要三个点。样条采用夹持均匀节点；闭合仅让首尾控制点重合，非周期样条，不保证连接处切向平滑。圆弧、椭圆和样条保存原生曲线，不用青色显示折线代替 DXF 几何。Esc 丢弃整次绘制；确认创建后自动选中新对象，一次撤销整个命令。

### 变换命令

混合批量选择后启动；没有选择时先选择并按 Enter。复制按“基点 → 目标点 → 确认”操作，其余取一个基点后固定预览，在左侧调整参数，再 Enter 提交。预览期间原图保持不变，Esc 取消；一次确认只占一条历史。复制/阵列结果自动选中；其他变换保留原对象身份、图层和颜色。

| 命令 | 参数与方向 |
|---|---|
| `COPY` / `CO` / `复制` | 依基点/目标点的 WCS 差值生成一批副本，原件保留 |
| `ROTATE` | 绕经过基点的轴旋转，默认轴为当前工作平面法向，正角遵循右手方向；固定基点后也可直接输入角度 |
| `SCALE` | 围绕基点正数统一缩放；固定基点后可直接输入比例，不提供非均匀或负比例缩放 |
| `MIRROR` | 默认关于经过基点、沿 U 方向的平面内轴线镜像；在三维中对应由 U 和 N 张成的镜像平面。勾选后可改为关于经过基点的工作平面镜像 |
| `ARRAYRECT` | U 方向为列、V 方向为行；设置行列数及毫米间距，基点用于完成取点确认，阵列方向固定为当前平面 |
| `ARRAYPOLAR` | 绕经过基点的轴等分整圆，默认轴为当前工作平面法向，副本自身也随阵列旋转 |

旋转和环阵可设置三维轴向量；镜像可设置三维镜像平面法向，均由基点确定位置。旋转/缩放/镜像可勾选“保留原件并创建副本”；阵列固定保留原件，行列数或环阵数量均包含原件。单次最多新增或变换 50000 个图元，超限整批拒绝，不做部分提交。

新增与变换仍经原生文档更新；工作区毫米坐标先反换算为源单位，再写入原生记录。几何改变后重建 CAM，手动断面、配对和排序需重新确认；撤销/重做沿用现有 CAM 上下文恢复。已补属性/夹点及图层管理；曲线修剪、连接等见[后续计划](CAD开发计划.md)。

## 属性与夹点编辑

左侧批量属性中的颜色和所属图层显示共同值；不一致时显示“多个值”，须显式选择目标后才能应用。圆与圆弧混合选择可输入统一目标半径，一次修改、一条撤销；包含其他类型时不显示批量半径入口。三维偏移仍可批量调整位置。选择中含锁定层时编辑控件只读，菜单或命令提交也会由核心拒绝，整批不发生部分修改。

单选可编辑对象时，画布显示绿色方形夹点。按住夹点拖动，青色预览使用解析几何生成；松开固定预览，再 Enter /“确认 / 提交”写回，Esc 取消。也可在属性中选择夹点、输入 WCS X/Y/Z，点击“预览夹点坐标修改”后确认。预览期间不改变图纸、保存标记或 CAM；提交后更新几何、显示和 CAM，支持整次撤销/重做。松开在界面或画布外时不提交，仍可输入目标或取消。

| 图元 | 本批可编辑夹点及约定 |
|---|---|
| 直线 | 起点、终点，允许 WCS 三维坐标，不能形成零长线 |
| 圆 | 圆心、半径；移动圆心保留法向，半径点必须共面 |
| 圆弧 | 圆心、半径、起点、终点；拖端点时保留另一端及原弧中点，用三点重建，半径和圆心可随之改变 |
| 椭圆 | 中心、长/短半轴端点；长轴可在原平面内转向，短轴保持正交，长度满足长半轴不小于短半轴 |
| 多段线 | 各顶点；共用顶点同步更新前后段，闭合首尾联动；圆弧段保持原扫角/凸度，由新弦重算圆心和半径 |
| 样条 | 非周期、具有控制点的样条控制点，节点/权重/次数保留；重合的闭合首尾控制点联动，编辑后清除旧拟合点数据；离开原平面时可变为空间样条 |

夹点取点使用临时平面：原点为所选夹点，平面图元使用自身平面方向，直线/样条等使用当前工作平面方向；不覆盖会话中设置的工作平面。此时二维绝对 `u,v` 以该临时原点计，`@du,dv` 以原夹点计；三维绝对与相对输入仍按 WCS。数值输入框同时显示临时平面原点。圆弧端点、多段线平面顶点和椭圆轴不能离开图元自身平面。

本批不增删顶点、不改变样条次数/节点/权重，不提供周期样条或只有拟合点样条的控制点编辑；还不是通用参数约束求解器。圆角、修剪、偏移等后续接入。

## 图层管理

CAD 左侧“图层管理”列出所有领域图层，显示实际颜色和当前/隐藏/锁定状态；选择图层后可：

- 输入新名称并新建；选中已有层后重命名。名称按原生表规则忽略大小写判重，不能使用首尾空格及非法符号。
- 设置当前图层，所有后续新建图元使用它；只允许将可见、未锁定层设为当前层。
- 修改 RGB 颜色、显示或锁定状态。图层原有 ACI 颜色在未改色时保留，应用颜色后写入所选 RGB。
- 删除空层，或明确选择迁移目标后删除非空层。目标必须可见且未锁定，锁定源层需先解锁；`0`、`Defpoints` 和外部参照层不能删除，原生库同时限制这些层的改名。删除当前层时切换到迁移目标；无目标的空当前层删除后切到 `0`。

上述修改以原生文档事务提交，记录撤销/重做和未保存标记，并随 DXF 及恢复快照保存。改名保留图层身份及图元归属；迁移不删除图元。缺少原生层表记录的隐式导入层可查看，管理操作会提示缺少记录，不凭空覆盖原始图纸结构。

隐藏/冻结层不绘制、不参与普通点选/框选/全选或几何捕捉，已有 CAD 选择会清理隐藏对象；领域几何及 CAM 数据仍保留，加工计划与 NC 不因隐藏或锁定自动排除这些对象。锁定层仍可选择查看和作为捕捉参考，禁止颜色/换层/移动/删除/变换/几何修改；新建、换层和迁移目标同样不能使用隐藏/锁定层。

图层改名同时迁移内存中的同名 G-code 规则。新旧名称都已有规则时，提示冲突并取消整次改名；只有目标规则时保留它。撤销/重做只交换改名涉及名称的规则，其他规则及工艺参数保持当前值；期间对这两条规则的编辑也随该事务回退。规则仍需在 G-code 配置中保存才持久化，DXF 不含工艺规则。删除层不自动合并 G-code 规则，源名称规则保留为未使用配置，迁移后的图元使用目标层规则。

## CAD 批量编辑与 DXF 导出

在 CAD 工作区点选、框选或 Shift 追加选择图元，也可用“编辑 → 全选”或 Ctrl+A。左侧特征面板的批量编辑操作应用于所有选中图元；即使多种几何混合选择，也只生成一次撤销记录。

| 操作 | 入口与行为 |
|---|---|
| 修改颜色 | 选择随层、随块、ACI 1–255 或自定义 RGB，点击“应用颜色到所选图元” |
| 修改所属图层 | 选择当前图纸已有图层并应用；随层颜色同时按新图层刷新 |
| 三维平移 | 输入 WCS 中的 ΔX、ΔY、ΔZ（mm），点击移动；各选中图元使用相同的毫米偏移，写回时转换为源单位 |
| 删除 | 左侧“删除所选图元”、编辑菜单或 Delete，删除全部选中图元 |
| 撤销 | “编辑 → 撤销”或 Ctrl+Z，一次恢复上一批修改及原选择；可以连续撤销 |
| 重做 | “编辑 → 重做”、Ctrl+Y 或 Ctrl+Shift+Z，恢复刚撤销的批量修改及相应选择；可以连续重做 |
| DXF 导出 | “文件 → 导出 DXF…”，导出整张当前图纸，默认文件名为 `<原名>-edited.dxf`，不按选择过滤 |

Ctrl+A、Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z、Delete 仅在 CAD 工作区、没有文本输入控件占用键盘时作用于图元。输入框内继续使用文本自身的快捷键。颜色使用完整 ACI 色表；随层、随块与 RGB 语义写回 CAD 数据，并传递到 G-code 规则匹配。

当前会话最多保留最近 100 次批量编辑，撤销和重做共用这批历史；更早的修改仍保留在图纸中，但不能继续撤销。撤销后提交新的有效编辑，会清除旧的重做分支；空选择、零位移、属性未变化或编辑失败不增加历史，也不清空重做。没有可用历史时，对应菜单项禁用。

颜色和换层编辑保留现有加工安排；平移和删除会根据当前几何重建 CAM。撤销/重做几何编辑时同步恢复对应的加工分析、手动截面/配对和选择，并按当前 G-code 配置重建轨迹。CAM 面板中的独立操作不属于 CAD 撤销历史，G-code 配置也不会随 CAD 撤销回退。

文件名后的 `*` 表示有未保存的 CAD 修改，成功保存或导出 DXF 后清除；撤销或重做回到已保存版本也会清除。保存/导出不会清空撤销或重做历史。导出 DXF 保留当前文档路径；另存为会切换当前路径。未保存确认针对 CAD 图纸，不包含尚未持久化的 CAM 人工安排。

颜色和图层修改保留现有 CAM 规划。移动、删除、半径及夹点修改会根据新几何重新识别截面、断面和分组，保留懒旋转/旋转方向选项，但手动指定、配对和排序需重新确认；撤销这些 CAD 几何编辑时恢复编辑前的加工分析状态。DXF 只保存 CAD 图纸，不保存加工计划或工艺配置。

DXF 导出基于保留的原生文档记录，由 acadrust 写出 ASCII DXF，遵循库的版本处理策略；不从显示折线重新构造图纸。编辑范围仍限于可见且已转换的六类模型空间图元；其他成功解析的源记录保留在原生文档中，但读写完整性受第三方库支持范围限制，不承诺对所有 DXF/DWG 记录无损往返。当前不提供 DWG 写出或完整关联图纸的无损往返。

## 加工规划

1. 切换到 CAM，查看“方管截面”。程序从闭合单元的 YZ 包络估计中心、尺寸和圆角，当前单一候选自动采用。
2. 无截面时可输入手动参数并应用；已有截面时也提供手动参数控件，但草稿保留存在限制，见[状态限制](已知限制.md#界面与状态)。清除截面会进入无截面回退规划，按钮名称中的“重新识别”不会自动再次拟合。
3. 查看“加工断面与区间”。高置信断面自动应用，其他候选可手动应用。选择闭合单元可“设为加工断面”，已设定的可“取消加工断面”；手动设定要求已有管材截面。
4. 加工断面默认按轴向中心位置两两配对，两个断面之间为一节成品段。用“手动成品段配对”选择左右断面并应用；“恢复自动配对”清除手工配对，保留修边标记。左右角色由成品归属确定，不随切削顺序改变。
5. 组外/修边组先执行；每个成品组固定按“左端面 → 各区位普通单元 → 右端面”加工。懒旋转按区位集中加工，关闭后按最小 X 排序。普通单元可用上下按钮或 Ctrl 点击组内连续编号重排，只能在两端之间移动。
6. 画布显示加工编号、断面编号和橙色起点箭头；四轴轨迹面板显示单元数、运动段数、切削段数、安全 Z、A 范围和末姿态。画布目前显示原图线框和规划标记，没有完整机床运动仿真。

未配对断面、修边和组外加工单元单独列出；可勾选“仅作修边”将断面排除配对和壁厚补偿。普通单元依据路径采样与两侧断面的局部 X 边界归属，跨边界、归属不唯一、成品段重叠或边界交叉会报错并阻止导出。相邻成品不自动共用同一断面。配对、修边和手动排序仅保存在本次图纸的内存中。

关闭壁厚端面补偿时，没有截面也能导出：按 X 排序，以原 XYZ 和固定 A 偏移生成轨迹。该回退路径不执行完整方管区位策略，也不应用过切和加工面 Z 修正。

有截面时，普通加工单元的落刀点只由自身几何决定：非懒旋转取 X 最大点，懒旋转优先取所在区位的局部北极点。这里的“北”是区位转到朝上加工姿态后横向 +Y 的方向，不是统一的世界 +Z。北极点不在主区位时尝试南极点；两种模式的首选极点均不可用时，按各自规则回退到主区位内的极值点。无端点在主区位的开放路径仍按两端极值回退，不从中间拆分开切。

懒旋转优先从极点沿 +X 开始切削；非懒旋转在 +X 极点按顺逆时针选择局部周向切向。闭合轮廓无过切时回到起点结束，过切时后续转移从实际过切终点开始。切断断面和无截面回退路径仍有独立规则。

## G-code 配置

顶部“G代码配置”和“导出 G 代码”与“文件”“视图”同级，点击即可进入。配置以覆盖应用客户区的模态弹窗显示：顶部右侧说明规则代码顺序，保存与校验操作栏贴底，中间区占满剩余空间；左侧六个分类等高排列。文件与规则页左侧设置选项或选择规则，右侧上下两个大输入框编辑头尾代码，底部横排一行编辑说明；加工安全页左侧为参数、右侧为剖面示意，加工规划按选项与输入两栏排列。选项说明在悬停时显示，不重复展示分类标题。中间区不设整体横纵滚动，仅代码、规则列表或选项实际溢出时局部滚动。关闭按钮或 Esc 返回画布，弹窗阻止底层画布操作；不再提供 G 代码文本预览。

### 配置位置与加载

- 配置：`%APPDATA%\CADCAM-Rust\gcode.toml`。
- 最近打开：`%APPDATA%\CADCAM-Rust\recent.txt`。
- 无 `APPDATA` 时回退到 `<进程工作目录>/CADCAM-Rust/`。

启动时不存在配置会尝试创建默认文件，有效配置会重新序列化以补入新增字段。非法或不可读的配置在启动加载时保留原文件，内存回退默认值，当前不明确提示启动加载失败。配置导入和重新加载先检查 TOML、数值及联动参数，失败保留当前内存配置并在窗口底部显示原因。

| 操作 | 行为 |
|---|---|
| 导入配置 | 选择 TOML 文件，成功后替换当前内存配置并重算，不自动覆盖默认配置文件 |
| 导出配置 | 将当前配置保存为选定的 TOML 文件，取消对话框不产生写入 |
| 保存配置并重算 | 校验配置后写入上述默认位置，并重建轨迹，供下次启动使用 |
| 重新加载 | 读取默认位置已保存的配置，成功后替换当前配置并重算 |
| 恢复默认 | 将全部字段及类型/颜色/图层规则恢复为内置默认值并重算，点击保存后才持久化 |

操作结果显示在配置窗口底部，并同步写入命令栏。配置读写校验不要求当前已有图纸；轨迹校验另行执行。

### 速度与默认文件头尾

程序不再为直线、圆弧或圆弧展开的折线自动添加 F，也不再提供统一“进给速度”输入框。需要的 F 值由用户直接写入文件、图元类型、所属图层、图元颜色等层级的头尾代码，按顶栏说明的顺序原样输出。旧 TOML 中的 `feed` 字段不再参与生成或校验，再次保存配置时移除。

新建配置或恢复默认时，文件头为：

```gcode
%
G90
G21
G17
M8
M7
G00 Z50
G80 G40 G49 G17 G90
M05
```

默认文件尾为：

```gcode
G00 Z50
M05
M30
%
```

已经保存的自定义文件头尾不自动替换，可在文件级右侧输入框修改。文件头尾中的 `G00 Z50` 为原样输出的模板指令，不是轨迹层根据管材生成的动态安全高度。

初始 XYZ 在加载图纸、保存或重载配置时同步到规划参考，即使未勾选“启用初始机床位置”也参与该参考。返回初始位置的开关独立于初始移动开关。

### 加工面 Z 联动修正

在“加工规划”页设置“加工面 Z 修正”。未启用壁厚端面补偿的单元，Z 为 0 时保持原轨迹，A 恒定时统一偏移机床 Z；跨区位、A 变化时，按原始方向联动补偿 X。启用壁厚端面补偿的左右端面则按下节方式，将 Z 偏移纳入内壁投影统一求 X，不再额外叠加 Z/X 联动。两种加工模式使用同一处理。

设局部断面方向为 `x = a*y + b*z + c`，机床 Z 偏移为 `h`、当前角度为 `A`，对应工件坐标位移为 `ΔY = h*sin(A)`、`ΔZ = h*cos(A)`，补偿量为 `ΔX = a*ΔY + b*ΔZ`。计算使用弧度。它使倾斜平面的刀头采样点仍保持原方向，避免仅偏移 Z 后两侧弯曲。

加工断面从四个圆角各自的采样求方向，方向一致后等权合并，并以每个源点为锚修正，保留断面边上的曲线；直角断面使用转角及相邻边采样。其他 A 变化的加工单元要求采样能确定可靠的平面方向。方向退化、局部不共面或各转角方向不一致时显示具体单元及原因，并阻止轨迹生成和导出。原始 CAD 图元及计划选点不变，进场、切削、过切和后续空移使用修正后的实际姿态。

壁厚端面补偿沿用旧项目对激光内壁作用位置的处理；Z/X 联动只用于未启用该补偿的单元。启用壁厚补偿后，刀头轨迹允许弯折或不共面，不以刀头轨迹共面作为成品端面的判断依据。采样和输出精度仍影响 NC 中的几何误差。

### 壁厚端面补偿

在“加工规划”页输入“方管壁厚”，勾选“启用成品端面壁厚补偿（左 +X / 右 −X）”，再保存重算、校验或导出。旧配置缺少两个字段时默认关闭。普通单元及显式修边断面不执行壁厚补偿；开启时，未配对且未标记为修边的断面会阻止导出。

先生成已含机床 Z 偏移、X 仍为源点 X 的刀头姿态，反变换到工件坐标，沿激光方向取一个壁厚的候选点，再投影到内轮廓；不要求射线严格穿过内腔。内轮廓尺寸为外尺寸减两倍壁厚，内圆角为 `max(外圆角 − 壁厚, 0)`。以源点为锚，按原始局部斜率求一次修正量 `ΔX = a·(内壁Y − 源点Y) + b·(内壁Z − 源点Z)`：左端取非负值，右端取非正值。最终 `X = 原始 X + ΔX`，不再追加另一份 Z/X 联动，机床 Z 偏移也只施加一次。原始断面保留为定位和方向基准，不要求补偿后各折线的延长线都经过原轴线交点。

保留壁厚数值、内轮廓尺寸、断面方向和补偿后两端空间的必要检查；不再因射线相切、未穿过内腔或刀头与内壁的严格位置关系阻止补偿。修正后的入口、切削和过切参与后续空移；过切承接闭合后的连续 A 角，不回到首圈角度。

本功能使用局部方向及内壁投影近似，不含割缝、热变形、真实夹具及共切求解。验收应查看整层管壁的成品端面，不再只要求刀头轨迹共面。

### A 轴连续角度与 ±180° 交界

A 是按实际运动连续展开的旋转角，不强制限制在 ±180°。`-180°` 与 `+180°`、`0°` 与 `360°` 分别代表相同姿态，等价姿态衔接不执行整圈转动。单元内部始终连续展开，例如 `179° → -179°` 的几何方向输出为 `179° → 181°`；反向经过边界则可输出 `-179° → -181°`。经过交界不插入关光、抬刀或回转。

文件级的“A 轴保持连续角度（跨单元最短转位）”默认开启，单元入口选择靠近上一末姿态的等价 A 角。关闭时，非等价的单元入口以归一化角度重新定位，可能产生较长转位；精确等价的姿态仍不额外转圈，单元内部切削仍连续。两种加工模式共用这套处理。A 偏移按周期归一化，例如 `720°` 等效于 `0°`；初始 A 保留配置的有限数值，不按 ±180° 截断。

结束返回初始位置时，XYZ 返回配置值，A 取靠近末姿态的等价角度，不为恢复数值而多绕整圈。例如从 `A540°` 返回配置的 `A-180°`，保持 `A540°` 即已回到相同朝向。非等价姿态的空移旋转继续遵循旋转净空策略。

### 同面联动转移

在“加工安全”页配置，懒旋转和非懒旋转共用同一算法。只有前后单元均确认处于同一水平管材平面、主区位相同、实际 A 角不变且未跨过切断边界时，使用局部联动；圆角、过渡、跨面、需旋转或无法确认平面的情况经保守净空转移。

| `[transfer]` 字段 | 默认值 | 含义 |
|---|---|---|
| `enabled` | `true` | 启用局部联动；关闭时使用 `same_zone_clearance` |
| `retract_height` | `2.0` | 横向移动前的垂直抬刀高度 |
| `approach_height` | `2.0` | 横向移动结束后的垂直落刀高度 |
| `height` | `4.0` | 相对两端较高 Z 的联动峰高 |
| `auto_height` | `false` | 总高度自动取两个最小高度的较大值 |
| `rise_ratio` | `0.5` | 同面 XY 行程中用于联动抬升的比例，UI 按百分比输入 |
| `fall_ratio` | `0.5` | 同面 XY 行程中用于联动下降的比例，UI 按百分比输入 |
| `smooth_enabled` | `false` | 同面及跨区位空移几何平滑，默认关闭 |
| `smooth_tolerance` | `0.05` | 光顺参考曲线离散及 XYZ 输出舍入的总允许偏差，单位 mm |

高度必须有限且非负，总高度不能小于最小抬/落高度；两项水平占比均在 0–1，合计不超过 1。非法联动参数会在界面提示并阻止保存、校验及导出。原 TOML 缺少 `[transfer]` 时加载默认值，原同区离面值保留。

转移剖面依次为：垂直抬刀、XY/Z 联动抬升、可选平台、XY/Z 联动下降、垂直落刀。50%＋50% 时平台消失；零长度段合并，零 XY 距离退化为垂直抬落。关闭联动时，等高转移高度取两端较高 Z 加旧离面距离，不再只从上一终点计算，也不会被旋转安全 Z 向下截断。

右侧示例 XY 距离、终点 Z 差、跨区位模式及 A 转角只影响示意、不保存到工艺；示意图与实际轨迹调用同一转移函数。异高示意仅展示几何，实际局部联动仍要求已确认的共同平面。实际起点使用过切后的末姿态。整个单元间空移位于单元结束代码与下一个单元开始代码之间。

旋转净空按截面及图纸 YZ 包围矩形半对角线、正向加工 Z 偏移和旋转间隙计算；不是完整机床/夹具碰撞模型。首尾进退采用该净空策略，已有高于净空的位置不会先降低再旋转。未启用初始位置时，实际程序启动姿态仍未知。

### 空移路径平滑（同面及跨区位）

在“加工安全”页勾选“启用空移路径平滑（同区位 / 跨区位）”，设置允许偏差，再保存重算或校验。两种加工模式、普通/快速导出共用轨迹层结果；平滑输出为离散快速移动线段，不新增圆弧、样条或 F。切削轮廓、进出刀点和激光启停边界保持原有语义。

- **同面**：需启用同面联动，保留起点上方最小抬刀高度内及终点上方最小落刀高度内的竖直段，仅对上方联动部分构造五次 Bézier 参考曲线，再自适应离散。同面沿用原有联动总高度与水平占比。
- **跨区位**：先保持 XY/A 不变，竖直抬到不低于旋转净空、起点最小抬刀高度及终点最小落刀高度的共同安全平面。只在此平面以上平滑联动 XY/Z/A，A 使用五次渐变；转位完成后保持末端 XY/A 竖直落刀。联动总高度在此作为共同安全平面上方的额外过渡高度，不能为压低折角而侵入旋转净空。
- **离散及精度**：利用 Bézier 控制点界约束整段曲线与线段的 XYZ 偏差，并为输出舍入扣除误差预算；允许偏差必须大于 `sqrt(3)/2 × 10^(-小数位数)`。保护段增加向上量化余量，以免舍入提前横移或转位。A 另按角度误差及相邻步长细分，不与长度单位混算。
- **回退**：纯竖直移动、没有已知起点、同面联动关闭、过渡高度/水平区间不足，或达到离散资源上限仍无法满足偏差时，保留原路径。零 XY 距离但需要 A 转位的跨区位路径仍可在净空上方平滑旋转。

参考曲线在过渡处保持切向及曲率连续，输出仍为有限直线段；不等于已完成机床速度、加速度或加加速度规划。实际运动还受控制器对快速指令的解释、前瞻和混合模式影响，本轮仅确认应用构建，未做 NC/实机验收。

### 类型、图层和颜色规则

文件级及每条规则均含 `header`、`footer`、`comment`；`comment` 只作配置说明，不输出到 NC。文件级、图元类型、图元颜色及所属图层页的说明统一位于右侧底部横排输入框，随配置导入、导出及保存。旧配置未含文件级 `comment` 时默认为空。所属图层与图元颜色列表在选项左侧显示实际色块；图层色取自当前图纸的图层颜色，悬停色块可查看 RGB 值。仅存在于配置而未出现在图纸中的图层无实际颜色可显示。

- 类型键为内部六类几何名：`LINE`、`POLYLINE`、`CIRCLE`、`ARC`、`ELLIPSE`、`SPLINE`。LWPOLYLINE 转换后归入 `POLYLINE`。
- 图层键为源图层名；图层页列出当前显示数据图层并补入 `0`。
- 颜色键为图元颜色语义：`BYLAYER`、`BYBLOCK`、`ACI:n`、`#RRGGBB`。随层图元匹配 `BYLAYER`，不按解析后的图层 RGB 匹配。UI 默认提供随层、随块和 ACI 1–9，其他键可编辑 TOML。
- 每单元收集不重复的“类型、图层、颜色”组合。每段连续切削的头部按每个组合依次插入类型、图层、颜色规则，再插入 `unit_start`；切削后先插入 `unit_end`，再按相反组合顺序及颜色、图层、类型顺序插入尾部。同一规则可能因不同组合重复输出。

### 重算与校验

配置直接编辑当前内存值；保存成功、导入成功、重新加载成功、恢复默认及关闭配置窗口时重算轨迹。校验及两个导出入口也会同步当前内存参数并重建轨迹，不要求先保存。示意图随参数编辑即时更新，G 代码文本仅在导出时生成。

“校验 G 代码”实际检查语义轨迹及部分配置，不解析最终 NC。检查包括 Z 联动修正的构建错误、空轨迹、部分数值合法性、每单元是否有切削段、A 是否有限、切削是否存在超过 180° 的跳变，以及跨单元在内的空移 A 变化是否在安全高度。配置窗口底部显示校验结果，悬停可查看完整信息；导出失败时命令栏最多显示前 5 项问题，范围见[已知限制](已知限制.md#运动与输出)。

## 导出

| 菜单 | 输出位置与行为 |
|---|---|
| 顶部“导出 G 代码” | 保存对话框指定路径，默认 `<图纸名>.nc` |
| “文件 → 快速导出到 build” | `<进程工作目录>/build/<图纸名>-quick.nc`，覆盖同名文件 |

两个入口均从当前内存配置重建轨迹，再校验和生成导出文本，有问题则停止；范围是完整计划，不按当前选择过滤。导出不会自动保存配置。

核对最终文件的单位、单元数量、顺序、首尾移动和曲线运动。当前基础校验不能证明无碰撞或控制器适配完成。
