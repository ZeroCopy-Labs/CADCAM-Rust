## 块导入与诊断

`read_editable_document` 在原生坐标中先调用 `blocks::materialize`，再执行 OCS/WCS 转换和源单位缩放。每个模型空间 INSERT 以候选原生文档单独原子展开：递归解析叶图元、按各块基点和各层 INSERT 矩阵由内向外变换，支持行列阵列。圆弧先作为圆锥曲线处理以覆盖倾斜及非均匀变换，仍为圆时恢复圆类型；块内多段线拆段，避免非均匀缩放后仍保留错误凸度。ByBlock/层 0 等从有效实例上下文解析，隐藏写入实体标记。

仅完整成功的实例从模型空间移除；失败原实例和块定义保留，不输出局部成功叶。展开后的原生文档为编辑权威数据，初始版本标未保存；首次打开前的块级关系不在 CAD 历史中。`Entity.native_handle` 对应当前原生实体，`ImportReport.blocks` 记录原 INSERT 路径/阵列单元/叶句柄/段号到新句柄的映射；报告在编辑转换中保留，并由文件 UI 保存打开时快照。映射不作为 DXF 持久关系。

`diagnostics::analyze` 对领域几何生成问题、端点连通组和长度/方向，不修改正式文档。基本段求交保留解析线/圆弧，其他曲线用明确标注的离散候选；预算耗尽会标截断。修复只为当前问题构造 `CurveEdit`；应用先预览，删除项另以红色显示，再经已有核心锁定检查和统一事务提交。UI 按文档 revision 和参数判断诊断是否过期。

`ImportReport::has_omissions` 覆盖未转换对象、块展开失败及解析跳过/恢复/未完成读流。两个 G-code 导出入口在轨迹导出前要求 `FileState.coverage_acknowledged`，未确认时打开报告并停止；确认只针对已转换范围，采样/轨迹错误仍阻断输出。新图纸或几何事务使确认失效，配置及 DXF 不持久化该确认。

## 加工采样

`curves::Sampling` 默认弦差 0.01 mm、光滑曲线内转角 3°，独立于显示用固定采样。圆弧/椭圆按参数导数界计算步数；正权重夹持非周期 NURBS 以齐次节点插入分段，再以有理 Bézier 控制包络和方向锥判定细分。保持源折角，不为满足光滑曲线角度而磨平 C0 接点。开放样条拓扑端点也改为求值。

`display::build_machining` 从领域几何建立全量加工路径及元数据，与 `build_display` 的画布路径分开缓存。打开、几何编辑、属性/图层刷新、撤销/重做会同步数据；分析、初始点、普通重排/Ctrl 重排与轨迹均使用加工实例。采样错误清空加工实例并生成带 error 的空轨迹，基础校验在两个导出入口阻止输出；不影响 CAD 保存。单图元 100000 点、整图 2000000 点，样条有工作量/深度预算。该预算和近似控制不替代完整路径覆盖、机床插补或 NC 误差验证。

## 主数据流

```mermaid
flowchart TD
    A[文件对话框 / 最近打开 / 启动参数] --> B[open_drawing]
    B --> R[read_editable_document → EditableDrawing]
    R --> C[DrawingDocument]
    Q[批量 CAD 编辑 / 撤销 / 重做] --> R
    R --> X[原生文档 → DxfWriter → DXF 文件]
    C --> D[build_display → DisplayData]
    C --> E[build_cam_model → CamModel]
    C --> S[build_machining → 独立加工采样]
    S --> F[CamAnalysis → CamPlan]
    E --> F
    F --> G[build_trajectory → MachineTrajectory]
    S --> G
    E --> G
    P[GCodeProfile] --> G
    G --> H[validate_trajectory]
    G --> I[render_gcode]
    P --> H
    P --> I
    H --> K[两个导出入口：校验有问题则停止]
    I --> K
    K --> L[NC / G-code 文件]
    D --> M[相机适配 / Gizmos / 拾取]
    F --> N[加工编号 / 起点箭头 / 特征面板]
```

`cad_file::open_drawing` 向 `cad_jobs` 提交读取候选，后台完成读取和派生计算；单位选择、未保存确认及候选安装在主线程执行，`install_prepared` 不重复离散；成功后更新 `ViewerState`、增加 `load_version` 并标记相机适配。取消或失败保留原图纸。新建/关闭也通过同一安装入口清理旧选择版本、编辑历史及 CAM 手动输入。`ViewerState` 通过 `EditableDrawing` 同时持有当前领域文档及封装的原生记录；来源摘要和显示/CAM 均从该当前文档派生。

## 领域模型与导入

- `DrawingDocument` 包含单位、图层、实体、来源和导入报告。`EntityId`/`LayerId` 是内部 ID，不是文件句柄或数组下标；实体及原生图层按句柄映射，缺少原生句柄/表记录的图层以忽略大小写的名称回退。映射跨编辑及撤销/重做保留，删除不重排其他 ID；图层改名保留 ID，新层即使复用撤销后的句柄仍获新 ID。查找使用稳定 ID，不能把 ID 当数组下标。
- `Geometry` 包含 Line、Polyline、Circle、Arc、Ellipse、Spline，WCS 坐标为 `f64`；平面曲线保留平面或轴向基。
- `DrawingDocument::source_units` 表示原生记录使用的单位；单位已确认时，`units` 为毫米。转换在 OCS/WCS 几何生成后，统一缩放位置、半径及椭圆轴长，保留角度、法向、节点和权重。原生文档不整体缩放，毫米编辑位移按源单位比例反向换算；保存 DXF 保留源单位。未知单位必须由打开流程指定毫米或英寸，指定后标为未保存。
- 多段线保存直线和圆弧段，闭合段已包含在列表内；样条保存控制点、节点、权重、拟合点及源标记。
- 格式识别优先使用内容签名和特征，扩展名作回退及诊断。acadrust 使用 failsafe 解析，并拒绝没有可用绘图记录的结果。
- 转换仅处理模型空间，未支持或失败实体写入报告；最多保留 256 个跳过样本，另计省略数。解析诊断合并到警告列表。

## CAD 编辑事务、撤销/重做与 DXF 写出

`EditableDrawing` 是正式修改入口，原生 `CadDocument` 为权威数据，`DrawingDocument` 为派生快照。它封装稳定实体/图层 ID 映射和编辑历史。`DrawingEdit` 提供批量颜色、所属图层、WCS 三维平移及删除；先验证整批选择、目标图层和偏移，再修改候选原生副本并转换。若非删除对象在转换中丢失则整批取消；成功后才替换正式文档。空操作、失败和未产生模型变化的操作不增加历史或清除重做。移动使用原生 WCS/OCS 变换，重型二维多段线单独更新标高，防止仅移动顶点而遗漏导出头部的标高。ACI 显示颜色与原生完整色表一致。

`create` 将 `NewEntity` 中的解析几何适配为原生实体，保留平面法向和 OCS 标高；圆弧按扫角符号选择法向，椭圆和样条保留其原生类型。`transform` 克隆选中源实体，以“移到基点原点 → 线性变换 → 移回”的源单位变换保留原生属性；重型二维多段线同步归一化顶点及头部标高。复制重置父对象句柄/所有者，为三维多段线顶点分配新句柄；新实体始终分配新的内部 ID，即使撤销后的原生句柄被再次使用也不复用旧 ID。创建/变换和原有编辑共用候选转换及提交；新增对象无法转换时同样整批取消。

`properties::grips/move_grip` 在解析几何上修改端点、圆心/半径、椭圆轴、多段线顶点和样条控制点；多段线共用顶点联动相邻段，圆弧段保留凸度。`set_geometry` 批量更新原生字段，保留实体身份、公共属性及多段线顶点附属字段，更新的原始 DXF 缓存失效；失败不提交。周期/只有拟合点的样条不提供控制点夹点。

`LayerEdit` 操作原生层表/当前层头部和引用，层状态加入领域模型。锁定/隐藏检查集中于核心编辑入口及新建/换层目标，不能绕过控件修改。图层事务对比实体、图层和当前层，空层新增或仅改变显示/锁定也能记录历史。改名沿用原生引用更新；删除明确迁移目标，保留目标层记录。图层状态不用于构建 CAM 的排除条件。

`cad_curve_command::Session` 在 `CommandState::CurvePick` 中保存边界、点选源、阶段、尺寸和待提交 `CurveEdit`。边界阶段复用选择集；目标阶段用现有拾取缓存及射线最近点定位原几何，Tab 可循环候选。侧点阶段复用工作平面/动态取点。`curve_pick` 在领域几何中决定裁分区间、有限边界交点、延伸端与偏移侧；圆角/倒角构造连接边但保留两个原对象各自属性和方向。悬停仅重建预览，最终点击或键盘确认交给原生事务；参数面板的旧批量配方保留。

TRIM/EXTEND/OFFSET/FILLET/CHAMFER 成功提交后保留 `CurvePick` 会话，前三者回到目标选择，圆角/倒角回到 FirstLine 并清空旧边对快照；失败只清除本次预览；等待目标时 Enter 结束而不提交悬停预览。`Session` 用原生 `DrawingChange.transaction_id` 记录本命令操作，利用 `created_sources` 跟踪边界新片段，并保存成员增删差量供 U 恢复。U 在调用既有 `apply_cad_action(Undo)` 前比较 `EditableDrawing::undo_transaction_id()`，完成后恢复差量并清空悬停/侧点快照，不跨越本命令记录或原生历史预算。原有选择、参考角色和 CAM 上下文仍由应用历史对称恢复。参数选项由 parameter_option 提供：偏移/倒角用 D、圆角用 R；N 只在侧点或第二条边阶段清空未提交源并恢复初选。参数与重选只修改会话草稿，不创建文档历史；角点工具的 waiting_target 包含 FirstLine/SecondLine，空确认在查看第二边预览时也只结束，最终点击转 Confirm 后才提交。CurvePick 参数阶段的右键/工具页确认使用同一 command_input 草稿。

`CurveEdit` 保存主对象到结果列表的替换及合并后删除集合；`apply_curves` 同时校验源层、元数据和全部结果，替换首片段保留 ID，附加片段/副本分配新 ID。原生类型或顶点数变化时重建几何并复制公共属性；带宽/厚度/拟合标记图元明确拒绝。正式提交一次记录全部替换/新增/删除；失败不修改文档。曲线预览是 `CommandState::Curves`，只接受提交或取消，控件和命令栏共用配方。

每次有效提交分配递增事务 ID，返回包含事务 ID、影响数量、操作类型、新建 ID 及新结果源 ID 映射的 `DrawingChange`；提交、撤销、重做共用这一通知。历史共保留最多 100 条批量操作，快照使用库的共享/COW 存储；撤销/重做交换对应原生文档及版本，再生成领域模型，已删除的实体仍使用原 ID。新编辑清除重做分支。保存版本独立记录，不随历史切换而改写，因此撤销或重做回到保存版本时清除未保存标记。`DxfWriter` 先在内存完成序列化，`file_io` 写同目录临时文件、`sync_all` 后重命名替换；覆盖目标前先以同样方式写入 `.bak` 备份。失败不更新保存版本或当前路径。源块、表和其他已解析记录保留在原生文档中，读写完整性仍取决于库支持范围。

`main.rs::apply_cad_action` 将批量 UI 和菜单/快捷键汇入同一入口，以 `DrawingChange` 决定刷新。界面上下文按核心事务 ID 保存，不另外维护一套撤销/重做顺序；随核心历史淘汰及分支清除同步释放。属性修改由 `display::refresh_properties` 刷新已有路径的颜色、可见性及实体/图层规则元数据，保留离散坐标、包围盒、拓扑和分析；创建/移动/删除/几何变换在后台重新采样并重建 CAM，再由 `CamAnalysis::reconcile` 迁移有效安排。几何事务撤销/重做时交换加工分析、手动截面/配对及 CAD/CAM 选择上下文，再用当前 G-code 配置同步初始位置及重算。CAD 历史不单独记录 CAM 面板操作或恢复整份 G-code 配置；图层改名事务单独保存涉及名称的规则条目，撤销/重做交换这部分条目，不影响其他规则及参数。改名前若新旧键均有规则则拒绝，删除层不合并工艺规则。编辑后清理失效选择、拖框及点击重排状态。`export_dxf_file` 导出整张图纸，与两个 G-code 导出入口独立。

`cad_file::save_drawing` 为已有 DXF 写回当前路径，DWG、未命名及恢复图纸进入另存为；成功后切换文件元信息。导出副本沿用既有清除保存标记的行为，但不切换当前路径。新建、替换、关闭及退出共用保存/放弃/取消确认；禁用 Bevy 默认自动关闭，由 `WindowCloseRequested` 处理确认后发送 `AppExit`。

`FileState` 保留打开时的导入报告和本会话恢复信息。`maintain_recovery` 在首次未保存变更后、后续有版本变化且经过 30 秒时，通过 `write_recovery` 写独立 DXF；不更新正式保存版本。正常保存、放弃/替换及退出清理本会话快照，异常遗留文件可手动恢复；恢复文档清除源路径并标为未保存。恢复不包含 CAM 人工安排和历史。文件写入仍同步执行。

### 派生数据版本及人工安排迁移

`cam_sync.rs::DerivedState` 维护会话内文档 revision、几何/属性/配置/安排版本。显示和加工快照绑定几何/属性版本，拓扑/分析绑定几何版本，轨迹绑定全部输入版本。新建/打开/关闭重置会话；几何事务同时递增几何、属性及安排版本，属性事务不递增几何版本。配置按完整 `GCodeProfile` 值比较，识别输入、导入、恢复默认及图层规则迁移；配置窗口未重算时清除旧轨迹。CAM 修改和点击重排递增安排版本。加工计算通过单工作线程返回，只有会话及全部输入版本匹配才投递到正式状态。

两个导出入口及配置校验通过后台版本续接，缺少当前轨迹时排队计算，匹配后再执行原有校验/输出；工作线程同步初始位置、检查待处理安排/采样/配置并生成轨迹。来源失配不允许使用旧结果；构建错误仍由已有 G-code 校验拒绝写出。版本表示来源一致性，不证明轨迹或 NC 几何正确。

`CamAnalysis` 将 `section_overrides`、`section_pairs`、`trim_sections`、`manual_orders` 与自动识别结果分开。显式配对/修边也保留其端面指定。几何更新时同时比较旧/新加工单元的排序成员 ID 和闭合状态，不单凭哈希 ID 猜测；组内排序以 `(left_section, right_section)` 为键，组外采用 `(None, None)`。有效旧单元保留相对顺序，新单元保留生成位置。失效端面/排序引用移除并加入 `pending_arrangements`，需用户在 CAM 面板核对当前安排后明确清除提示；正常几何校验继续有效。

自动截面重拟合，手动截面保持；全局懒旋转/旋转方向保持。区位、单元方向、入口和出口从当前几何重算，没有独立人工起点/单元方向数据。CAD 几何事务的分析快照包含人工覆盖、顺序及待处理项，因此撤销/重做可恢复；它们写入 `.cadcam` 项目，不写入 DXF。

## 显示、坐标与选择

### 命令及工作平面

`cad_input::DynamicInput` 管理光标输入焦点、显示模式与字段锁定，底部和光标输入共用 `ViewerState::command_input`。命令别名在分派前统一规范化。`CommandState::input_spec` 按当前步骤提供输入字段；`viewport_point` 先执行原有几何捕捉，再施加字段约束。保留原始指针点与约束后预览点，数字编辑在指针不移动时也可重算预览；进入面板时暂停指针，不把未锁数值重置为零。两处输入切换时显式保留 #/@ 坐标含义，所有提交仍走 `submit_command` 与原生编辑事务。浮层使用实际画布边界，首次焦点转移先保存文本事件以免 sizing pass 丢失首字符；Tab 在字段/命令候选处理后才可能用于捕捉或选择候选。

`CommandState` 持有当前 `WorkPlane`、活动步骤、临时取点及错误；不改写 `DrawingDocument` 或 `DisplayData`。顶部 `cad_workspace` 功能区、菜单、Ctrl+M、右侧工具参数及命令栏复用现有编辑分派。几何命令由 `submit_command` 处理，颜色/图层快捷操作经 `EditAction` 交给 `apply_cad_action`，删除经统一命令分派并支持先选/后选。`Workspace` 保存特性面板页签、展开、历史显示及右键菜单位置；CAD 右侧面板和 CAM 左侧面板处理后，从根 UI 剩余区域取得实际画布矩形，供视口、文字裁剪和视图立方体定位使用。移动依次经过选择、基点、目标点；基点阶段固定图元 ID，预览从显示路径临时加偏移，目标点确认后立即将 `DrawingEdit::Translate` 交给原批量事务。提交失败保留确认步骤，成功或取消清除临时状态。原数值偏移按钮保留直接提交行为。

夹点命令冻结源几何和句柄，鼠标命中由屏幕距离选取真实几何夹点。按住拖动预览，画布内松开后提交几何更新；属性面板数值入口保留显式预览与确认。夹点临时平面通过原夹点，方向取图元平面或当前工作平面，存储的工作平面不改。

矩形继续使用原有 `SketchKind::Rectangle` 与两角点构造。`CommandState::rectangle_dimensions` 仅保存 Length/Width/Place 临时阶段及正长宽，不写文档或项目；首角点后 D 收集两个标量，期间不接收鼠标取点。放置阶段 `rectangle_target` 在当前工作平面内按光标相对首角点的 U/V 符号构造固定尺寸的对角点，鼠标、输入预览与 `accept_point` 共用该计算，并保留异面拒绝。输入两项尺寸不直接提交，最终点击或有效预览确认后沿用 `ready → Create`；U 逐步回退参数/角点，取消清空尺寸状态。固定尺寸放置没有可改尺寸的动态字段，提示显示尺寸、文本接受点坐标/选项，光标相对输入仍由同一 submission 规则编码。

`rectangle_angle` / `rectangle_rotating` 保存当前矩形数值角度和临时输入标志；R 输入期间保留 `rectangle_dimensions` 的原阶段。确认后从会话 `CommandState::plane` 的原基向量计算旋转后的 Sketch 平面，不以已旋转向量叠乘；原点和法向所在平面保持，`point_plane` 仍返回原会话工作平面，防止 #/@ 坐标跟随矩形角度改义。D 的目标计算及最终多段线构造直接使用同一 Sketch 轴，U 取消当前角度输入，撤回首点或 cancel 时清零。

`SketchKind` 的 Circle、CircleDiameter、Circle2P、Circle3P 只区分绘制方法，输出均为 `Geometry::Circle`。圆心直径方式的第二点/数值表示完整直径长度，核心 `Sketch::geometry` 统一取半，动态字段不另做第二次缩放；两点方式取端点中点和半距；三点方式与现有圆弧共用平面内圆心计算，再输出完整圆。`circle_options` 按当前点数提供模式切换；R/D 可保留圆心，两点/三点只能在首点前切换。光标尺寸约束、底部标量预览和最终点击使用同一长度含义，最后必要输入仍经原有 `ready → CommandCommit::Create → apply_cad_action → EditableDrawing::create`，不新增独立历史或 CAM 几何来源。

`SketchKind::ArcCenterEnd/ArcCenterAngle` 通过圆心/起点构造解析圆弧。前者从第三点得到终点射线，固定半径并计算正向扫角；后者用 `Sketch::sweep_degrees` 保存独立的有符号扫角。ArcCenterAngle 的两个位置输入取齐后不置 confirmed，`arc_sweep_input` 停止取点并提供标量字段，只有数值确认、核心 geometry 验证成功才返回 Create。预览克隆草稿，未输入扫角时显示默认 90°；字段改变只改草稿，失败不写原生文档。端点方向阶段的 reference/snap_reference 改为圆心，避免把射线坐标误用为起点偏移；三点圆弧和其属性编辑仍使用原有构造。

绘图命令保存 `Sketch` 点列及确认状态，调用解析几何构造生成临时显示；变换命令冻结选择 ID，按基点及工具参数对显示路径生成矩阵预览。连续绘图用 Enter/Space、C 或 Esc 结束时一次提交，Esc 不包含未确认的鼠标预览；点数不足时取消。固定点数工具取齐后直接提交；本命令的 U 只撤回未提交取点。`CommandState::ready` 在鼠标最终取点后复用命令提交入口；键入最终点直接返回 `CommandCommit`，创建/变换/移动/删除统一交给 `apply_cad_action`。旋转和缩放确认最终标量或方向点后返回变换意图，镜像在两点定轴后等待保留/替换确认。新图元使用文档当前图层及所选颜色，副本继承源属性；提交后选择新 ID。几何变更重建 CAM，撤销/重做复用事务上下文。

COPY 沿用 `Select → Base → Target → Confirm`，`copy_single` 区分单次与默认多次，源 ID 和原基点在成功放置后保持，`resume_edit` 将 Confirm 恢复为 Target 并清除临时取点。每个目标继续输出 `CommandCommit::Transform`，原生事务成功后才记录 `copy_operations` 中的事务 ID。连续曲线与 COPY 共用 `command_undo_id` / `undo_command_change` 及根入口的栈顶核对；复制不另建文档历史。目标阶段空输入仅结束，最终取点进入 Confirm 后的内部提交不受该结束判断影响。单次成功结束；单次和多次失败均不追加事务，并回到目标阶段。几何变换、撤回与 CAM 上下文恢复继续走原有原生路径。

`cad_transform_command::Session` 在 `TransformPick` 步骤中冻结源 ID，保存基点、参照与待提交矩阵。ROTATE 默认取方向角作为增量，R 用新旧方向之差；SCALE 默认接受比例，R 用新旧长度之比。自定义旋转轴先建立投影后的角度基准，动态字段约束与矩阵计算共用该基准。MIRROR 由两点轴线和工作平面法向确定镜像平面，末步 N 复制、Y 原位反射；高级设置仍支持工作平面及显式镜像法向。鼠标、坐标、标量、右键和侧栏均汇入相同状态与 `CommandCommit::Transform`，正式修改继续复用 `EditableDrawing::transform`，预览不产生历史。

三点平面在第三点有效时建系；取消或错误保留原平面。二维绝对输入由平面 U/V 转 WCS，三维绝对输入直接解释为 WCS；相对二维和极坐标位移沿 U/V，相对三维位移沿 WCS。取移动目标点时以基点为参考，三点平面的第二/三点以第一点为参考，其他首次取点以当前平面原点为参考。

`selection_input` 在活动取点步骤中截获画布点击，调用 `ViewFrame::ray` 将局部 Bevy 射线逆映射为 CAD WCS，并在 f64 中归一化方向。`DraftingAids::resolve` 先从领域模型取捕捉候选，通过 `ViewFrame` 投影限制屏幕距离，再按方向约束、网格和工作平面自由点回退；不能取合法交点时提示。选择步骤沿用点选和框选，取点阶段不再改变所选对象。渲染的青色预览、标记及平面不进入保存、拓扑或 CAM。

`snap_points` 从直线、多段线圆弧、圆、椭圆和有效样条求特征；开放样条端点由 de Boor 求值，不能计算时不使用控制点冒充端点。非直线近点采用 64 个参数区间的初始搜索与局部细化，未证明复杂样条全局最优。交点、垂足和切点按支持的线/圆弧组合计算；交点检查约 `1e-6 mm` 空间残差，排除异面直线的投影交点。邻近判断由几何计算，不依赖显示折线是否经过光标；交点限 24 个邻近图元，超出时提示。捕捉候选在约 `1e-6 mm` 内去重，Tab/Shift+Tab 循环；显式投影选项才改变捕捉点的法向位置。数值输入绕过辅助约束。

活动命令期间禁用其他 CAD 编辑和直接保存/导出，文本焦点保留文本快捷键；CAD 命令输入中的 Space 与 Enter 确认，其他文字输入保留空格。Esc 取消当前操作，连续绘图保留有效已取点部分；空闲且输入为空时再清除选择。右键菜单持有画布输入，菜单外点击只关闭菜单。切换工作区清除活动命令，成功替换文档时重置命令及工作平面。恢复快照不包含这些临时交互状态。

`SelectionFilter` 在 CAD 默认追加，Shift/Alt 移除、Ctrl 切换；命令后选阶段可在空输入框使用 Ctrl+A。CAM 的 Shift 追加和 Ctrl 重排沿用原逻辑。滚轮以实际画布中的鼠标偏移计算新旧正交比例的差，将差值沿相机右/上方向补偿到相机目标，保持鼠标下的世界位置；只修改视图，不修改图纸和 CAM 坐标。

### 画布与选择

`DisplayData` 保留全量路径及 visible/locked 元数据，显示/拾取/捕捉独立过滤隐藏层，CAM 继续使用全量路径；包围盒仍含隐藏对象。它还保存图元属性、图层，以及独立圆/圆弧的圆心和法向。样条使用 de Boor 求值，不完整数据可回退为控制多边形；显示路径过滤非有限坐标。

`CameraRig::target` 保持 WCS f64，相机在局部原点附近朝向零点。`ViewFrame::point` 先在 f64 中减去视图原点，再按 `(x,y,z) → (x,z,-y)` 转 f32；逆变换用于鼠标射线。适应视图时，包围盒角点先减去 f64 中心再参与投影范围计算。线框、预览、工作平面、拾取和 CAM 标签共用该转换，不更改领域坐标或加工轨迹。相机仍为 f32 正交相机，局部原点解决绝对大坐标过早截断，不保证任意跨度与极限尺度。网格按当前平面围绕视图投影中心绘制，过密时稀疏显示整数倍间距，不改变实际网格捕捉间距。

`SelectionState` 分别持有实体和加工单元 ID，并记录过滤和悬停候选。CAD 拾取按局部投影线段距离、视线深度及 ID 稳定排序；Tab 循环候选、橙色预选，选择支持四种方式及 Ctrl/Alt/Shift 临时覆盖。过滤按类型、图层、颜色属性限制新选择、框选和全选；反选仅作用于过滤范围，不自动清除其他已选对象。换图通过 `load_version` 清理旧选择和过滤。窗口/交叉框选使用蓝/绿反馈；CAM 保留整单元选择与 Ctrl 重排。`UiState` 与 egui 指针状态用于阻止界面操作透传；无候选时 Tab 保留普通焦点导航。

## CAM 拓扑与分析

### 加工单元

`build_cam_model` 从领域几何取端点，以 `1e-3 mm` 容差进行空间哈希焊接及并查集分组。完整圆、完整椭圆、闭合多段线及闭合/周期样条独立成单元；开放实体连通组的节点度全为 2 时标记闭合。

`MachiningUnit.members` 按实体 ID 排序，并非加工顺序。`UnitId` 是规范化成员集合的 FNV-1a 哈希；相同内部成员集合保持同一身份，不保证源文件实体顺序变化后仍对应原对象。

### 截面、断面、区间与区位

1. 从所有闭合单元的 YZ 包络估计管材中心、尺寸和圆角；当前至多生成一个候选，单一候选自动采用。
2. 将闭合路径投影到管材周界，检查表面偏差、周向覆盖和 `±1` 绕数；周界覆盖使用 512 个桶。
3. 最大偏差不超过 `0.05` 且缺口桶数不超过 1 的高置信候选自动成为加工断面；其他候选可手动应用，也可手动指定闭合单元。
4. 断面按轴向中心位置两两配对，也可手工指定；`MachiningGroup` 保存 `left_section/right_section`，由同一组生成 `MachiningInterval`。修边及未归属单元保留在独立组，断面不再按相同最小 X 去重。普通单元按全部路径采样与两侧局部边界比较归属；交叉、重叠或归属歧义进入 `grouping_errors`，轨迹与导出共用。
5. `UnitZoneProfile` 记录区位投影长度及经过标记，以最长投影选主区位。16 区位由 4 个面、4 个圆角、8 个过渡组成，界面方位名称以 `TubeZone::label` 为准。

### 计划、方向与起点

`CamPlan → PlanGroup → PlanUnit` 保存顺序、区位、断面标记、方向和起止点。

- 懒旋转按区位遍历，再按单元 X 中心排序；关闭后按单元最小 X 排序，以区位顺序和 ID 打破并列。顺逆时针影响区位顺序。
- 组外/修边组先执行；成品组固定为左端面、普通单元、右端面。`end_cut_side` 从成品组边界推导。普通单元支持组内上下移动和 Ctrl 点击重排，插入位置限制在两端之间。
- 普通单元统一按自身几何选入口，不依赖前一单元或前一断面的出口。非懒旋转选 X 最大点；懒旋转优先局部北极点，不可用于主区位时尝试南极点，再回退到主区位内的极值点。局部北向定义为区位转至朝上加工姿态后的横向 +Y，圆角采用区位中部的切平面方向。
- 闭合单元在显示路径采样点中选极点；开放单元只在两端选，避免从中间开切漏段。懒旋转优先选择初始切向朝 +X 的遍历方向；非懒旋转按顺逆时针选择初始局部周向切向。此规则不等于强制所有 A 轴运动单向。
- 完整计划重建、上下移动和 Ctrl 重排均调用 `refresh_plan_entries`，保留当前排序并统一刷新起止点和编号。普通单元不再做前后夹角、A 角变化及距离评分。
- 切断断面保留独立入口：首断面优先从上表面靠近配置初始位置处进入，末断面尝试承接前一区位；未命中特殊规则时按前一终点选择路径正反向。非懒旋转时断面参考状态可跨组传递，懒旋转在组首重置。
- 无截面时清除截面/区位分析，按最小 X 排序，以前一终点选择方向，生成单个回退加工组。

`ordered_unit_points` 从显示路径贪心拼接加工路径，`oriented_unit_path_from` 反向或旋转闭合路径起点；尚无独立的加工公差几何层。

## 四轴运动与 G-code

`MachineTrajectory` 保存运动段、单元运动范围、规则键、安全 Z、A 范围、统计及构建错误。运动类型为 `Rapid`、`Cutting`、带平面/圆心/方向的 `Arc`。

有截面时围绕截面中心生成绕 X 的旋转姿态，按面/圆角或径向模式求 A，支持角度展开、加工 Z 偏移和闭合路径切向过切。`flat_surface` 确认前后普通单元处于同一水平面、同区位且实际 A 不变时，由 `transfer_moves` 生成联动或旧离面转移；圆角、切断边界、跨面和旋转使用净空策略。安全 Z 包含截面/图纸 YZ 矩形半对角线及正加工 Z 偏移。无截面时使用原 XYZ 和固定 A 偏移，不应用过切或加工 Z 偏移。

未启用壁厚端面补偿的单元，Z 非零且 A 变化时，`section_cut_direction` 只用各圆角采样求 `x = a*y + b*z + c` 的方向，再验证一致性；直角使用顶点相邻边，恒 X 断面直接返回零斜率。其他跨区位单元由 `fit_cut_direction` 检查整体是否有可靠的平面方向。过切点不参与方向拟合。每个姿态按 `ΔX = machining_z_offset * (a*sin(A) + b*cos(A))` 修正 X，源点自身的曲线形状保留；Y/Z/A 继续使用原姿态解算。修正先于进场、圆弧压缩和单元转移，因此入口及实际过切末姿态一致。失败返回含具体原因的空轨迹，面板显示错误，渲染返回空文本，两个导出入口均通过校验拒绝输出。

`TransferConfig` 包含默认关闭的 `smooth_enabled` 和默认 0.05 的 `smooth_tolerance`。`transfer_moves` 在已有起点且启用平滑时调用 `cam_transfer::smooth_transfer`，失败回退原有生成路径。同面保持现有峰高/占比和恒 A，只有同面联动启用时平滑；跨区位先完成竖直净空抬升，再于净空上方增加 `total_height` 的过渡空间。所有跨区位 Bézier 控制点均在共同安全平面之上，A 使用统一五次参数渐变，末段在完成 A 转位后竖直落刀。初始未知姿态不参与平滑，已知的首尾转移共用此入口。

`cam_transfer` 使用分段五次 Bézier 的光顺参考曲线，不把成品切削轮廓纳入优化。控制点与同参数直线的差界约束整个曲线偏差；de Casteljau 二分至满足 XYZ 几何预算及独立的 A 角误差/步长要求，最多 12 层、每次转移约 4096 个中间点，达限回退。`RotaryConfig::output_decimals` 由配置精度传入，几何预算扣除三轴舍入误差界，竖直保护高度向上量化并留余量。`GCodeProfile::smoothing_validation_error` 在保存和导出时拒绝不足的精度预算。参考曲线光顺不代表离散输出或控制器执行具有连续速度/加速度。

单元内部的几何 A 始终连续展开，不受 ±180° 限制。`wrap_angle_180` 归一化几何方向及偏移，`unwrap_angle` 选择靠近前点的等价角度；`align_entry_angle` 在开启连续角度时将单元入口衔接至上一末姿态，即使关闭也不让精确等价的入口多转整圈。无截面回退使用同一入口规则。结束返回同样取靠近末姿态的等价 A。`transfer_moves` 消除等价角度差，真实旋转仍经净空；交界处不拆分切削、不插入回转。角度及姿态需为有限数值，A 范围和切削段数反映实际运动。

单实体圆/圆弧在 A 恒定且符合当前识别条件时尝试压缩为圆弧运动；其余输出切削折线。文本层处理文件/单元头尾、类型/图层/颜色规则、精度和换行；关闭圆弧输出时按 `arc_tolerance` 展开语义圆弧。初始位置、首个进场及结束返回均由轨迹层生成，属于单元运动范围；文本层不自动追加首尾移动；用户配置头尾中写入的移动指令按原样输出。`TransferConfig` 是 TOML 配置、剖面示意和实际轨迹共用的参数；示例距离和高度差只存于界面状态。

运动行不再自动输出 F；速度由用户在各层级头尾代码中设定，`GCodeProfile` 和 `RotaryConfig` 不再保存统一进给字段，旧 TOML 的 `feed` 被忽略。新默认文件头尾来自 `GCodeProfile::default`，已有自定义头尾保持原值。

文本层按连续切削段启停：切削转入 `Rapid` 时先输出单元结束及规则尾部，重新切削时输出规则头部和单元开始代码，保证默认 M03/M05 包围切削段。两个导出入口消费相同的连续角度轨迹，配置窗口不生成或显示 G 代码文本。

`build_trajectory` 先生成含机床 Z 偏移、X 仍为源点 X 的姿态。启用壁厚端面补偿时，`cam_wall::end_cut_allowance` 将该实际姿态反变换到工件坐标，沿激光方向取一个壁厚的候选点，再由 `project_inner` 直接投影到内轮廓；不执行射线穿透或相切判定。局部方向以源点为锚给出内壁期望 X 与源点 X 的差值，仅对这一差值应用左端非负、右端非正的限制。该路径沿用旧项目的统一修正方式，不再额外叠加 Z/X 联动；Z 高度在基础姿态中只施加一次。内圆角小于等于零时使用直角内轮廓。补偿只修改派生姿态，源 CAD 和组归属不变；几何采样修正后延伸过切，并保留闭合末端的累计 A。所有成品组完成后检查补偿后的左右空间，失败返回明确构建错误。

普通/快速导出均重建轨迹并执行基础校验，有问题则停止，通过后才调用文本渲染。校验范围和遗漏见[已知限制](已知限制.md)。

|---|---|
| 成功打开图纸 | 重建显示、拓扑、分析、初始位置参考和轨迹；清理旧选择、适配相机 |

| CAD 创建/移动/删除/变换及撤销 | 更新文档、显示、拓扑及分析，撤销几何时恢复原加工分析和选择 |

| 校验 / 导出 | 按当前内存配置重建轨迹并校验，导出通过后生成文本再写出；不自动保存配置 |

手动计划可写入 `.cadcam` 项目，尚无独立的 CAM 撤销栈；CAD 撤销会在恢复几何时恢复关联的旧加工分析。轨迹重建统一由 `rebuild_state_trajectory` 触发，不再保留文本预览缓存。顶部配置入口打开覆盖客户区的 `egui::Modal`，阻止底层画布交互；顶栏和底栏用独立 `Panel` 固定位置，`CentralPanel` 填充剩余区域，六个导航项按实际可用高度等分。中间页最多两栏，文件与规则页共享上下头尾编辑框及右侧底部横排说明框，文件级说明使用默认空值的 `GCodeProfile::comment` 持久化且不参与文本渲染；图层及颜色规则列表按现有颜色数据绘制实体色块。安全参数和剖面示意分列；不设整体嵌套滚动，仅保留实际溢出时的局部滚动。分类说明及字段说明使用悬停提示；顶栏规则顺序与 `push_rule_headers` / `push_rule_footers` 保持一致。配置加载与保存共享 `GCodeProfile::validation_error` 检查，导入/重载失败不替换当前状态；操作结果同时显示在弹窗和命令栏。


## 项目保存与工作区联动

`cad_project.rs` 持有版本化 JSON 项目及独立保存点，保存点对比文档 revision、来源、`MachiningSetup`、G-code 配置与排除集合；配置/安排修改也受关闭保护。`EditableDrawing::project_snapshot/from_project` 在核心封装原生 DXF 字节与稳定身份，Base64 保留旧代码页；读取不再次展开原来失败的 INSERT，校验当前句柄/ID/类型、图层与单位。源报告保留，遗漏确认不保存。写出前回读身份，成功原子替换才改变项目保存点。格式详见[项目文件格式](项目文件格式.md)。

`MachiningSetup` 只保存正式选择，不序列化拟合候选/路径/轨迹。打开先在候选数据中恢复文档、采样、排除后的拓扑、安排与配置，处理当前未保存工作后安装，再按当前版本重算。缺失来源仅提示；配置采用项目快照且不自动覆盖全局 TOML。新开清空旧轨迹查看缓存、选择版本和历史。

`ViewerState::excluded` 按稳定图元 ID 指定参考角色，`build_machining/build_cam_model` 接收集合并排除这些源图元；显示/DXF 仍保留全部原生对象。范围有独立版本，改变范围重建加工派生数据并迁移有效安排。复制/结构新增利用 `DrawingChange::created_sources` 继承角色，不按新数组次序猜测；混合角色合并在提交前要求统一。范围不进入 CAD 几何历史，几何撤销快照保留对应 CAM 身份及当时范围，用于按当前范围重整安排。

CAD/CAM 选择通过稳定 ID/单元成员双向转换，显式定位同时适配相机；加工顺序按单元身份定位源路径。`cam_view.rs` 缓存当前输入版本的语义机床运动线段，以独立 XY/XZ/YZ/等轴测投影显示切削/空移、XYZ/A 及 `TrajectoryUnitRange` 对应编号；当前运动可定位回 CAD 源单元。圆弧仅作显示离散，机床与工件坐标分开，未读取自定义 NC 或模拟实际机床。配置/范围过期时不使用旧缓存；未提交预览仍只属于命令状态。

## 测量、文字与常用工作流

`Geometry::Text` 保存 WCS 插入点、字高、单行内容及含基线方向的平面。转换只接受基础 TEXT 参数；`native_geometry` 处理 OCS/WCS 与源单位，编辑更新原生文字字段。显示使用文本包围框供拾取/适应视图，`cad_text.rs` 用应用字体投影绘制字形并提供内容/字高编辑；字体效果不是原始 SHX 渲染。CAM 拓扑、加工采样、曲线操作与诊断显式排除文字，不以矩形框冒充切割轮廓。

`drafting.rs` 构造空间角、文字、非关联对齐标注和孔模板；`cad_util.rs` 提供命令参数及测量结果。所选曲线长度复用解析公式/有标识的离散估长，按 revision/选择缓存。Utility/Paste/ArraySpacing 步骤复用捕捉和数值取点；测量/粘贴等按第三批在最后必要点后产生提交，文字保留显式确认。阵列动态数量由同一 `ToolOptions` 驱动预览与提交，夹点固定预览也可继续编辑位移/半径；提交产生 Report、Annotation、Paste 等意图；测量 Report 不进入文档事务。

标注一次创建专用层及独立 LINE/TEXT，不生成关联 DIMENSION。新标注、在专用层新建的对象及粘贴的参考对象使用已注册 `CADCAM_RUST` 应用的 XData 字符串 `REFERENCE_V1` 标记，转换到 `Entity.reference` 默认角色；首次打开据此初始化排除集合，原生复制/变换/改色/换层保留扩展数据。项目排除集合仍保存对默认角色的当前覆盖。文字为固有非切割类型；参考线可由用户显式纳入加工。文件读写仍依赖库保真范围。

`cad_clipboard.rs` 的版本化文字数据保留毫米解析几何/颜色/图层/当前角色，省略原生附属记录；`EditableDrawing::paste` 在候选原生文档中合并缺失层、转换源单位并提交一次事务。实际系统剪贴板由 EguiClipboard/egui 输出处理，保留文本框焦点语义。复制数据独立于原图纸，跨实例可读取；格式或预算错误不提交。

命令重复保存最近启动的工具名，空闲 Enter 使用当前选择及参数重新启动，历史命令不覆盖重复项。矩形阵列的间距拾取是临时步骤，环阵总角度决定整圆不重复/部分角包含端点；孔模板只生成解析圆/多段线，不引入约束求解器。旧项目若只新增识别此前未知的基础 TEXT，可分配新 ID 迁移并要求重新保存；原有身份、单位和其他类型仍严格核对。

## 后台调度、缓存及性能记录

`cad_jobs.rs` 使用单工作线程和有界请求通道，只保留最新等待意图；主线程在可派发时复制输入快照，线程不修改 `ViewerState` 或当前原生文档。读取任务拥有新候选，重算任务拥有领域文档或已应用加工快照及旧单元/人工安排。每个阶段用原子取消标记检查，第三方解析和阶段内部循环不可抢占。panic 转为任务错误，当前工作不被替换。

返回结果以会话、正式 revision 和 `cam_sync::Inputs` 的几何/属性/配置/安排/范围版本核对；过期或取消直接丢弃。属性刷新只在加工几何来源仍匹配时推进其属性版本，不能把旧几何标为新版本。CAD 几何历史恢复源安排/单元身份后，也以当前范围在后台重新迁移，不把旧派生路径直接当作新结果。

导出/校验/轨迹查看及项目保存通过受同一版本保护的续接操作完成。需要先保存再替换/退出的动作只有保存成功后继续；中途修改或取消会撤销续接。文件候选遇到未确认 CAD 命令时等待，新的正式输入使它失效。新建/安装/关闭取消旧任务并增加会话版本，安装已算候选不重复离散。

`cad_pick.rs` 将显示几何一次投影为屏幕线段和完整实体框，缓存键包含会话、几何/属性、浮动原点、相机和逻辑视口。64 像素网格只做候选粗筛；单段最多 4096 格、总格引用最多 1000000，超限放入全局候选，距离/深度精查保持原语义。框选窗口要求完整实体/单元可见路径都在框内；TEXT 投影框内部可拾取。相机/窗口/可见性变化使缓存失效。

世界相机只渲染自由画布，独立的全窗口 `PrimaryEguiContext` 相机只绘制 GUI（不渲染世界层），避免画布视口同时裁掉菜单或造成布局递归收缩。`UiState.canvas_rect` 经窗口缩放系数转为世界 Camera viewport，适应视图使用该自由区域；投影/射线继续使用窗口逻辑坐标，裁剪与浮动原点不修改正式几何。CAM 源过期时暂停其拾取、动作及编号；底栏提供阶段、取消和重算。手动截面草稿跨帧保留，仅正式截面改变或用户还原时重新初始化。

`cad_performance.rs` 被动记录阶段、快照、索引/查询和 CPU Gizmo 提交毫秒；核心 `ImportTimings` 分开原始图纸解析/转换。显示+加工点容量为明确的局部估算，不是进程内存。加工采样通过 `build_machining_from_metadata` 复用显示元数据，避免重复显示离散。没有自动基准或静态 GPU 缓冲；同步编辑/写出/部分捕捉及标签等剩余路径见[性能与后台任务](性能与后台任务.md)。
