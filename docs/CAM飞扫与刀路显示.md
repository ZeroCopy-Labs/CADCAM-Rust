# CAM 飞扫与刀路显示

[返回入口](../README.md) · [使用指南](使用指南.md) · [架构](架构.md)

本批于 2026-10-29 实现。用户确认的飞扫含义是：同区位一排孔，去程加工一侧，返程加工另一侧，孔间关光连续移动。

## 往返飞扫

在“G代码配置 → 加工安全”开启“沿 X 往返飞扫”，保存配置并重算。默认关闭，参数保存在 G-code TOML 和项目的配置快照中：

```toml
[fly]
enabled = false
row_tolerance = 0.5
max_gap = 100.0
link_tolerance = 0.02
```

三个距离参数单位均为 mm，依次表示孔列横向中心差容差、相邻孔沿 X 的最大间隔、关光连接在工件坐标中的离散弦差。

当前支持有管材截面时，四个平面区位中的闭合、平面、可沿 X 分为两条单向链的孔轮廓，例如成排圆孔、椭圆孔、矩形孔。使用现有独立加工采样，圆形的极点精度受该采样影响；矩形的极值直边补中点作为分界。先在同一断面组的连续可飞扫区域内按区位/平面集中，再按行分组、沿 X 排列；断面和不适用的单元会打断区域，切断边界之间不会合并。开启飞扫会改变该区域内的实际执行顺序，原规划编号用于源对象定位；实际去返顺序以刀路播放为准。整个区域未形成飞扫批次时保留原顺序。相邻轮廓 X 范围重叠、间隔过大或某排只有一个孔时使用普通加工。

每孔拆成去程、返程两条链，沿原来的轮廓方向依次覆盖全部源切削线段。最远端的孔在同一加工段内完成两侧，沿孔本身转向，不在其连接点额外关光、开光。其余孔在去返程各加工一侧，一个原加工编号可以对应两个加工段。“仅当前单元”同时显示该编号的去返两侧。

孔间连接使用两端切向控制的三次曲线，在工件坐标中自适应离散，再与切削链一起经过既有的懒旋转/非懒旋转四轴映射和修正。连续连接的 A 角保持连续展开。离散预算不足时整批回退普通加工。批次进出场、批次之间及非飞扫对象仍使用原来的安全转移；飞扫批内的关光连接是单独的加工策略，不执行逐孔抬落刀。设置了非零过切时保留普通路径，不丢弃原过切要求。

切削与关光连接在语义轨迹中分别标记为 `Cutting` 和 `FlyTransfer`；后者关光并用配置的切削运动代码输出离散线段，默认是 G01。实际开关光和类型/图层/颜色前后置代码沿用原配置，每个切削段会执行相应代码块；不自动输出 F，也不增加专用控制器指令。若代码块包含穿孔等待、暂停或轴运动，会影响连续性。控制器能否实现运动中开关光、延迟补偿及高速衔接，需要结合实际型号和指令配置确认，不能从刀路形状推导实际耗时。

厂商参考：[柏楚 TubesT FlyCut](https://www.bochu.com/tutorials/tubest-flycut/) 将规则排列孔和同方向轮廓连接列为飞切用途，并区分控制系统及软件版本的兼容性。本实现提供通用语义路径与可配置文本输出，没有套用其专用控制协议。

## CAM 主画布显示

进入 CAM 后，底部提供刀路显示、切削/空移开关、仅当前单元、仅已播放、播放/暂停、逐段、索引滑块、演示段速率和重算刀路。

| 颜色 | 含义 |
|---|---|
| 橙 | 切削 |
| 蓝 | 普通安全空移 |
| 紫 | 飞扫关光连接 |
| 黄 | 当前运动段 |
| 红色十字 | 当前已知刀头位置 |

主画布保持工件坐标，用实际 XYZA 姿态绕管材中心作 A 逆旋转，显示刀头相对工件的轨迹；Z/X 修正和抬落刀保留，不把机床 XYZ 原样叠到工件上。按相同版本的轨迹缓存线段；配置、图纸或加工安排使轨迹失效后隐藏旧结果，重算后更新。仅用于显示的圆弧及 A 变化会细分；不改写导出轨迹。

“机床轨迹查看”窗口继续显示 XY/XZ/YZ/等轴测机床坐标、XYZ/A 以及源单元定位，使用同一索引和过滤状态。主画布可用原有平移、缩放、三维旋转检查，无需导出后切换软件。

播放按“演示段/秒”推进，不估算实际进给时间。两种视图都来自生成的语义轨迹，不解析自定义程序头尾中的运动、M 指令或最终文本模态，不是完整 NC 解释器、材料去除或夹具碰撞仿真。首个已知姿态之前的未知机床移动不绘制。

## 构建与人工验收

按用户约定，本批执行工作区构建和静态核对，不运行功能测试、GUI 或实机加工验收。

建议人工检查：

1. 同一平面放置一排圆孔/矩形孔，比较关闭和开启飞扫后的橙色轮廓覆盖、紫色孔间连接与加工段数量。
2. 检查最远端孔的连续转向、其余孔的去返两侧，以及多排、间距过大、不同区位、断面及过切时的分批/普通回退。
3. 切换懒旋转、Z 修正及 A 边界，比较主画布相对刀路与机床 XYZ/A 窗口；核对 G-code 中每个关光连接前后的实际开关光代码。
4. 检查播放、逐段、仅当前单元、仅已播放；修改配置或安排并重算，确认旧轨迹被隐藏并更新。
