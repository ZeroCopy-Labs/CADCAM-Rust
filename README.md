# CAD/CAM Rust

基于 **Rust + Bevy + wgpu + egui** 的桌面 CAD/CAM 程序，读取 DXF/DWG，显示并编辑三维线框、导出 DXF，并生成加工计划、X/Y/Z/A 四轴轨迹和 G-code。当前管材分析以 **X 为轴向、YZ 为截面、A 绕 X 旋转**的方管及圆角矩形管为基础。

## 当前能力

- 导入模型空间中的直线、多段线、圆、圆弧、椭圆、样条及基础单行 TEXT，保留三维坐标、图层及颜色；支持基础几何块和嵌套 INSERT/阵列在导入时展开，记录源句柄映射，DXF 保存为独立实体。
- 正交轨道相机、视角魔方、CAD/CAM 空间切换、点选与框选、图元及加工单元信息面板；画布随面板调整，拾取投影和空间候选缓存按版本失效。
- 后台读取/加工计算、进度/取消与过期结果丢弃；导出、校验及需要等待重算的项目保存可在完成后继续，并提供被动性能记录。
- CAD 批量修改颜色、所属图层和圆/圆弧半径，三维平移、删除及撤销/重做；单/多选夹点点击激活后预览确认，支持重叠候选切换、直线中点平移、圆四象限半径、圆弧中点形状、单对象拉伸及选择集共同位移；超过 100 个对象时隐藏夹点，普通批量命令仍可用。
- 图层新建、改名、删除并迁移图元、当前层、颜色、显示及锁定；改名同步内存中的 G-code 图层规则，隐藏不改变 CAM 加工范围。
- 新建毫米图纸、保存/另存为 DXF、关闭保护、覆盖备份和恢复快照；工作区统一毫米，源单位单独保留，并提供导入报告。
- 独立 `.cadcam` 项目保存：内嵌原生图纸、稳定 ID、单位、人工加工安排、参考对象范围及工艺快照；重新打开后重算派生数据。
- 连续直线、多段线、对角点/长宽及旋转矩形、圆心半径/直径圆、两点/三点圆、三点或圆心方向/扫角圆弧、椭圆/椭圆弧和控制点样条绘制；指定新图元图层/颜色，椭圆范围箭头支持拖动或参数角编辑，保留原生曲线并保存 DXF。
- 空间距离、三点角度、坐标、半径及曲线长度测量；基础单行文字、非关联对齐长度标注，标注默认排除加工并保存 DXF。
- 指定基点的几何剪贴板复制/粘贴、Enter/Space 重复命令、圆孔/长圆孔模板；矩形阵列拾取间距，环形阵列支持部分角度分布。
- 基点移动、连续复制及命令内撤回、鼠标取角旋转、R 参照旋转/统一缩放、两点镜像及矩形/环形阵列；青色预览、确认/取消及整批撤销/重做。工作平面支持 XY/YZ/ZX、三点定义及绝对/相对/极坐标输入。
- CAD 默认功能区与可收起特性面板；光标旁命令候选、坐标/尺寸字段锁定、共享底部输入及 F12 开关；常用命令自动完成、共享草稿确认、显式坐标点击、连续绘图结束保留、右键选项与 CAD 追加/Shift 移除选择。
- 最底部单行绘图状态栏，实时坐标可切换 WCS X/Y/Z 与取点平面 U/V/N；捕捉类型、栅格间距及极轴角度可从按钮旁菜单配置，窄窗口使用溢出菜单，打开菜单时暂停 CAD 命令输入并保留草稿。
- 原始几何捕捉、十字光标自动吸附（含选中对象的夹点和控制点）、候选循环、网格/正交/极轴辅助；悬停高亮、选择增删/反选及过滤，栅格区分粗细主次线并按三维画布范围自适应覆盖，使用局部显示原点处理大坐标。
- 常用边界点选修剪/延伸、选侧偏移及共面直线圆角/倒角支持连续处理与命令内 U 撤回；阵列数量及夹点位移/半径动态输入，夹点支持拉伸/移动、单次副本、重选基点、直线端点最终长度和右键选项。
- 直线、圆/圆弧和多段线的打断、参数修剪、定长延伸、连接/闭合、倒角、圆角及偏移，支持结果预览、整批提交和撤销/重做；另有曲线反向。
- CAM 按原始几何独立采样：默认弦差 0.01 mm、曲线内转角 3°，支持正权重夹持非周期 NURBS；采样失败阻止 G-code 导出。
- 图纸诊断列出重复、零长、间隙、开放/分支轮廓和内部交叉，可定位/选择并预览单项修复，显示闭合、长度和可判断的平面方向。
- 导入报告记录未转换对象、块展开失败及解析恢复；有遗漏时，导出 G-code 前须明确确认仅加工当前已转换范围。
- 按端点连续性建立加工单元，识别管材截面和加工断面，按左右断面配对成品加工组，支持手动配对、修边标记及 16 区位分析。
- 加工排序、懒旋转与顺逆时针策略、组内手动重排、方向和起点选择、加工编号与起点箭头；同区位孔列沿 X 往返飞扫，孔间关光连接；CAM 主画布刀路与逐段播放，独立机床轨迹投影查看 XYZ/A。
- CAD 属性修改复用几何采样，几何编辑保留有效断面/配对/修边及相对顺序；失效安排明确提示，版本过期或失效项未核对时阻止导出旧轨迹。
- 四轴运动生成、A 轴连续展开与最短转位、跨区位 Z/X 联动修正、壁厚端面单向 X 补偿、同面联动抬落刀、径向净空转位、可选同面及跨区位空移平滑（离散线段）、过切，以及无管材截面时按 X 顺序生成轨迹的回退路径。
- 全屏 TOML 工艺配置、配置导入/导出/保存/恢复默认、按图元类型/图层/颜色插入头尾代码，以及导出前基础校验和两种导出入口。

当前处于功能开发与验证阶段。CAM 已使用独立加工采样，路径完整性和旋转安全校验尚不完整；详见[已知限制](docs/已知限制.md)。编译或基础校验通过不代表 NC 已经过机床验证。

## 构建与运行

需要 PowerShell 7、项目指定的 Rust GNU 工具链及相应链接环境，详见[技术栈](docs/技术栈.md)和[开发指南](docs/开发指南.md)。在仓库根目录执行：

```powershell
.\build.ps1
.\run.ps1
# 也可启动时打开指定图纸；run.ps1 会先构建。
.\run.ps1 "D:\CAD\sample.dxf"
```

构建产物为 `build/cargo/debug/cad-app.exe`。也可使用 `build.cmd`、`run.cmd` 包装脚本。

```text
README.md                项目入口
docs/                    项目文档
crates/
  cad-core/src/          解析边界、转换、独立 CAD 领域模型
  cad-app/src/           显示、CAM 分析、轨迹、G-code、Bevy/egui 应用
.cargo/config.toml       Cargo 产物目录
.vscode/settings.json    rust-analyzer 产物目录
rust-toolchain.toml      Rust 工具链约束
build.ps1 / build.cmd    构建入口
run.ps1 / run.cmd        构建后运行
```

`build/`、`target/`、`temp/` 和 `Cargo.lock` 当前由 Git 忽略；本地样本、截图、日志及生成的 NC 不属于已版本化的验收基线。
