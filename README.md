# CAD/CAM Rust

基于 **Rust + Bevy + wgpu + egui** 的桌面 CAD/CAM 程序，读取 DXF/DWG，显示并编辑三维线框、导出 DXF，并生成加工计划、X/Y/Z/A 四轴轨迹和 G-code。当前管材分析以 **X 为轴向、YZ 为截面、A 绕 X 旋转**的方管及圆角矩形管为基础。

## 当前能力

- 导入模型空间中的直线、多段线、圆、圆弧、椭圆和样条，保留三维坐标、图层及颜色。
- 正交轨道相机、视角魔方、CAD/CAM 空间切换、点选与框选、图元及加工单元信息面板。
- CAD 批量修改颜色和所属图层、三维平移、删除及撤销/重做；保留源文档记录并导出当前图纸为 DXF。
- 新建毫米图纸、保存/另存为 DXF、关闭保护、覆盖备份和恢复快照；工作区统一毫米，源单位单独保留，并提供导入报告。
- 基点/目标点批量移动、青色预览与确认/取消；命令栏支持 MOVE/UCS/撤销/重做，工作平面支持 XY/YZ/ZX、三点定义及绝对/相对/极坐标输入。
- 原始几何捕捉、候选循环、网格/正交/极轴辅助；悬停高亮、选择增删/反选及过滤，使用局部显示原点处理大坐标。
- 按端点连续性建立加工单元，识别管材截面和加工断面，按左右断面配对成品加工组，支持手动配对、修边标记及 16 区位分析。
- 加工排序、懒旋转与顺逆时针策略、组内手动重排、方向和起点选择、加工编号与起点箭头。
- 四轴运动生成、A 轴连续展开与最短转位、跨区位 Z/X 联动修正、壁厚端面单向 X 补偿、同面联动抬落刀、径向净空转位、可选同面及跨区位空移平滑（离散线段）、过切，以及无管材截面时按 X 顺序生成轨迹的回退路径。
- 全屏 TOML 工艺配置、配置导入/导出/保存/恢复默认、按图元类型/图层/颜色插入头尾代码，以及导出前基础校验和两种导出入口。

当前处于功能开发与验证阶段。CAM 仍使用显示折线，路径完整性和旋转安全校验尚不完整；详见[已知限制](docs/已知限制.md)。编译或基础校验通过不代表 NC 已经过机床验证。

## 构建与运行

需要 PowerShell 7、项目指定的 Rust GNU 工具链及相应链接环境，详见[技术栈](docs/技术栈.md)和[开发指南](docs/开发指南.md)。在仓库根目录执行：

```powershell
.\build.ps1
.\run.ps1
# 也可启动时打开指定图纸；run.ps1 会先构建。
.\run.ps1 "D:\CAD\sample.dxf"
```

构建产物为 `build/cargo/debug/cad-app.exe`。也可使用 `build.cmd`、`run.cmd` 包装脚本。

## 仓库布局

```text
README.md                项目入口
docs/                    项目文档
crates/
  cad-core/src/          解析边界、转换、独立 CAD 领域模型
  cad-app/src/           显示、CAM 分析、轨迹、G-code、Bevy/egui 应用
.cargo/config.toml       Cargo 产物目录
.vscode/settings.json    rust-analyzer 产物目录
rust-toolchain.toml      Rust 工具链约束
build.ps1 / build.cmd    构建入口
run.ps1 / run.cmd        构建后运行
```

`build/`、`target/`、`temp/` 和 `Cargo.lock` 当前由 Git 忽略；本地样本、截图、日志及生成的 NC 不属于已版本化的验收基线。
